    始めるのに必要なもの¶

    これから Signal Pilot のインジケーターに取りかかる前に、必要なものがそろっているか確かめてください。この一覧に沿えば、導入はすんなり進みます。

    ✅ 必要なもの一覧はじめての方にも¶

    💻 1. TradingViewのアカウント（必須）¶

    あるとよい条件

    最低でも TradingView Essential（有料プラン）

    有料の購読が要る理由 - Signal Pilot インジケーターは Pine Script の高度な機能を使います - 無料の TradingView アカウントはできることが限られます - 招待制の非公開スクリプトには有料の購読が要ります

    おすすめのプラン - 必須のもの（月14.95ドル）— インジケーターを動かす最低ライン - Pro （月29.95ドル）— よく取引する方に。アラートが増え、データも速くなります - Pro+（月59.95ドル）— 本腰を入れる方に。機能がさらに増えます

    有料プランで得られるもの - 非公開インジケーターを使えます - 同時に出せるアラートが増えます - データが速くなります - タブごとに複数のチャートを置けます - サポートで優先されます

    たいていの次の一歩 TradingViewのプランを上げる

    🔑 2. Signal Pilot 購読（必須）¶

    あるとよい条件

    購入と利用開始

    1. 購入するもの： Signal Pilot Suite
    2. こちらへ signalpilot.io/#pricing
    3. プランを選びます

    4. 支払いを済ませます

    5. 確認メールを探します

    6. 受信箱と迷惑メールを見てください

    7. 利用の手順が書かれています

    8. TradingViewのユーザー名を伝えます

    9. メールに返信するか、用意されたフォームを使ってください
    10. 大事なこと TradingViewのユーザー名は一字一句そのまま伝えてください

    11. 確認する場所：TradingView → プロフィール → 設定

    12. 利用の許可が下りるのを待ちます

    13. たいてい24時間以内です
    14. 確認のメールが届きます
    15. インジケーターがあなたの TradingView アカウントに現れます

    たいていの次の一歩購入を済ませ、利用を申し込みます

    📚 3. トレードの基礎知識（あるとよい）¶

    強くおすすめします

    わかっておきたいこと

    欠かせないもの - 支持と抵抗 - ローソク足の型の基本 - トレンドの見分け（上げ、下げ、もみ合い） - リスク管理の基本（損切り） - ポジションの大きさの決め方

    知っておくと役立つこと - 複数時間軸での分析 - 出来高分析の基本 - よくあるチャートの型 - リスクとリワードの比

    まったくの初めてなら - まずトレードの入門講座を受けてください - 1〜2か月は模擬で練習してください - ローソク足を覚えてください - リスク管理の基本を身につけてください

    はじめの一歩に - TradingView Education - Investopedia Trading Basics - Signal Pilot 学習ポータル

    たいていの次の一歩自分の理解を測り、足りないところを埋める

    🏦 4. 取引プラットフォームか証券会社（実際に取引するなら）¶

    実際に取引するなら

    模擬で取引するなら TradingView だけで足ります

    実際に取引するなら証券会社が要ります

    使える証券会社 - 狙う市場を扱っているところならどこでも - 暗号資産：Binance、Coinbase、Kraken など - 為替：OANDA、FXCM、Interactive Brokers - 株式：TD Ameritrade、Interactive Brokers、Fidelity - TradingView とつながるところもあります

    TradingView とつながる証券会社 - 一部の証券会社では TradingView から直に注文できます - 選択肢は TradingView の証券会社一覧をご覧ください

    たいていの次の一歩証券会社の口座を開く（実際に取引するなら）

    💰 5. 資金（実際に取引するなら）¶

    実際に取引するなら

    目安となる最低資金

    模擬なら0ドル（仮想の資金）

    実際に取引するときの最低額 - 暗号資産：最低500〜1,000ドル - 為替：最低500〜1,000ドル - 株式：最低2,000〜5,000ドル（証券会社や規制によります）

    念のため：これは業界でよく見る最低額であって、推奨ではありません。事情は人それぞれです。

    この最低額がある理由 - 1回あたり1〜2%のリスクで、まともに枚数を決めるため - 例：500ドルの口座 × 1% = 1回あたり5ドルのリスク - これを下回ると枚数の調整が難しくなります

    重要 - 失っても構わない資金だけで取引してください - まず模擬から始めてください - 模擬で安定して利益が出てから実際に移ってください - 家賃や貯金、借りたお金は決して使わないでください

    たいていの次の一歩資金が見合っているか確かめる（あるいは模擬から始める）

    ⏰ 6. かかる時間¶

    時間の見通しを立てる

    どれくらい時間がかかるか

    学ぶ時期（最初の2〜4週間） - インジケーターを覚えるのに1日1〜2時間 - シグナルの種類を調べる - 見分ける練習をする - 模擬で取引してみる

    日々かかる時間

    デイトレード - 場中に4〜6時間 - 寄り前の準備：30分 - 引け後の振り返り：30分 - 合わせて1日5〜7時間

    スイングトレード - 1日2〜3回チャートを見る（1回30分） - 週末の分析：1〜2時間 - 合わせて週3〜5時間

    ポジショントレード - 1日1回の確認：15〜30分 - 週ごとの分析：1〜2時間 - 合わせて週2〜3時間

    たいていの次の一歩自分の使える時間に収まるやり方を選ぶ

    7. 機材¶

    最低限の環境 - パソコンかノートパソコン - 途切れない回線 - 新しめのブラウザ（Chrome、Firefox、Edge）

    おすすめの環境 - メモリ8GB以上のパソコン - 画面2枚（片方はチャート、片方はウォッチリスト） - 速い回線（ケーブルか光） - アラート用の携帯端末

    ブラウザに必要なこと - 新しめのブラウザ（この1年で更新されたもの） - JavaScript を有効に - クッキーを有効に - TradingView のポップアップを許可

    携帯からの取引 - TradingView のアプリ（iOS・Android） - 見張りとアラートには向きます - じっくり分析するには向きません - スイングやポジションのほうが相性がよいです

    たいていの次の一歩手元の環境で足りるか確かめる

    8. 市場の選び方¶

    扱う市場を選ぶ

    Signal Pilot はどの市場でも使えます - 暗号資産（年中無休） - 為替（平日は24時間） - 株価指数（取引時間内） - 個別株（取引時間内） - 商品（時間はまちまち）

    経験に応じた例

    はじめのうちは - ビットコインか主要な暗号資産（年中動き、値幅があり、出来高もある） - 為替の主要通貨ペア（EUR/USD、GBP/USD） - 主要な株価指数（SPY、QQQ）

    中くらいの段階 - 複数の暗号資産ペア - 複数の通貨ペア - 大型株

    進んだ段階 - 出来高のある市場ならどこでも - 複数の市場を同時に

    たいていの次の一歩はじめは1〜3の市場にしぼる

    🚫 要らないもの¶

    よくある思い違い

    ❌ 要りませんプログラミングの知識 ✅ 実際：インジケーターはそのまま使えます。コードを書く必要はありません

    ❌ 要りません自動売買や自動化（はじめのうちは） ✅ 実際：まず手で取引してください。自動化はあとからでもできます

    ❌ 要りません高額な講座や「先生」 ✅ 実際： Signal Pilot このドキュメントと練習で足ります

    ❌ 要りません初日から7本すべて ✅ 実際： Pentarch から始めて、慣れるにつれて足していってください

    ❌ 要りません多額の元手 ✅ 実際：模擬は無料です。実際には500〜1,000ドルから始められます

    ❌ 要りません仕事を辞めること ✅ 実際：片手間で始めてください。スイングなら勤め人でも続けられます

    前提条件の一覧

    先へ進む前に、次がそろっているか確かめてください

    • ✅ 有効な TradingView の有料購読（Essential 以上）
    • ✅ Signal Pilot のインジケーターを使える状態
    • ✅ チャートを読む基礎（支持と抵抗、ローソク足）
    • ✅ 習得にかかる時間の見当（日ではなく週の単位）

    すべて印がついたら次ははじめの一歩ガイドまたは7日間の導入
    抜けがあるなら始める前に上の条件を見直してください。あとで困らずに済みます。
