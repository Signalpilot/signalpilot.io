マーカス・チェン（合成した事例）

マーカスは値動きとRSIだけでSPXを売買していました。2023年9月-10月：SPXが4,550から4,200へ下げる（-7.7％）あいだに、14回の買いエントリーで8,400ドルを失いました。指標は何度も「売られすぎ」を示し、それでも価格は下げ続けました。

見落としていたもの： 米10年債利回りは4.2％から4.9％へ跳ね上がりました（6週間で+70bp）。DXYは3.8％上げて107へ。クレジットスプレッド（HYG/TLT）は12％拡大。三つともこう警告していました——「リスクオフ、流動性の引き揚げが来る」。

2023年11月： マーカスはインターマーケットの監視を始めました。10月27日の時点で、SPXがまだ安値をつけている最中に三つが向きを変えていました。10年債利回りは23日に日中5.02％をつけたあと新高値を作れず、DXYは10月3日の107近辺の高値から反落し、ハイイールド債（HYG）は下げ止まっていたのです。確認しなかったものにも注目してください。銅はその月、横ばいでした。五つそろうことはめったにありません。

彼の取引： 11月1日、FRBが金利を据え置いた日に、SPXを4,238で買い。根拠はインターマーケットの一致——利回りが5％で失敗、ドルが反落、クレジットが安定。12月15日まで保有。手仕舞い：4,719。利益：+11.3％＝30万ドルのポジションで3万4,050ドル。

通算成績（9月-12月）： -8,400ドル ＋ 3万4,050ドル ＝ インターマーケット分析を学んだ結果の2万5,650ドルの利益。正直なところを言えば、10月27日の安値は取れていません。確認に120ポイント払い、それでも四半期を勝ちで終えました。

「私はチェス盤の駒を一つ（SPXを）見ていましたが、機関投資家は盤全体を見ていました。安値を教えてくれたわけではありません——確認のぶんは払いました。ただ、その前の14回の押し目を買わずに済んだのです」

💸 インターマーケットのシグナルを見落とした28億ドルのファンド

2022年初め、あるマクロヘッジファンドは増益と低ボラティリティを根拠に、SPXの買いに大きく傾いていました（ハイテク強気）。インターマーケットの警告は無視しました。

彼らが見落としたもの：

  • 米10年債利回り： 1.6％から2.5％へのブレイク（2022年1月-3月）＝明確な引き締めシグナル
  • DXY（ドル）： 1月初めの95.7から4月末には103.5へ、+8％＝リスクオフと流動性の引き揚げ
  • クレジットスプレッド（HYG/TLT）： 12週連続で拡大＝クレジット市場のストレス

結果： SPXは1月3日の4,796から6月16日の3,666まで下げ——23.6％のdrawdown——利回りは急騰しました。年央時点でファンドは-22％でした。 金利のシグナルは1月の第1週からチャートに出ていました。

教訓： 引き締め局面では金利が先に動き、株式はしばらくそれと言い争います。これは市場の法則ではありません——株式のdrawdownの多くは、まさに株式から始まります——が、利回り、クレジット、ドルがそろって同じ方向を指しているとき、その三つすべてに逆らった株式のポートフォリオは、意図の有無にかかわらずマクロに賭けているのです。

パート1：インターマーケットの因果の連鎖

資産はどう互いを動かすのか

一次のドライバー → 二次の効果 → 株式への影響

連鎖の例： FRBが利下げ → ドルが弱くなる → コモディティが上昇 → インフレ期待が上がる → グロース株が劣後する（割引率が上がるため）

インターマーケットの因果の連鎖は、株式がまだ織り込んでいない文脈を与えてくれます。時計としてではなく、緩く可変の遅れを伴う順序として読んでください。

主要な因果の連鎖

連鎖#1：ドル → コモディティ → インフレ → 株式

仕組み：

  • ドルが下落（DXYが低下） → USD建てのコモディティが上昇（原油、銅、金）
  • コモディティ価格が上昇 → 投入コストが上昇 → インフレが加速
  • インフレが上昇 → FRBが引き締め → 株式のバリュエーションが圧縮

先行指標： DXYがサポートを割る → 2-4週間でコモディティの上昇を想定 → 1-2か月でインフレ統計が確認 → その後に株式への圧力が来る

トレード： DXYが下抜けたら、デュレーションの長いハイテク（ARKK、QQQ）から出て、コモディティ（XLE、XLB）へ入る

連鎖#2：クレジットスプレッド → リスク選好 → 株式

仕組み：

  • ハイイールドのスプレッド（HYG対TLT）が拡大 → クレジット市場が景気後退リスクを織り込む
  • クレジットが引き締まる → 企業が安く借り換えられなくなる → デフォルトが増える
  • リスクオフ → 株式が売られる。1-3か月という先行は教科書の数字です。実際には、クレジットは2007年と2020年初めにははっきり先行し、2018年と2022年には後れを取りました

先行指標： 先行指標：HYG/TLTの比率が下抜けること。HYG単体ではなく比率を使ってください——組み合わせの意味はまさにそこにあります。HYGはデュレーションを抱えているので、スプレッドが動かなくても金利が上がれば下がります。TLTで割ればその大部分が落ち、スプレッドの話だけが残ります。

トレード： SPXが新高値を更新しているのにクレジットスプレッドが拡大している場合 → SPXを売る（ダイバージェンス＝警告）

連鎖#3：利回り → グロース対バリュー → セクターローテーション

仕組み：

  • 10年債利回りが上昇 → 将来利益の割引率が上がる
  • グロース株（高PER、遠い将来のキャッシュフロー）は、バリュー株（低PER、近いキャッシュフロー）より痛手を受ける
  • ローテーション：グロース（QQQ、ARKK）から出て、バリュー（XLF、XLE、XLI）へ

しきい値について： 「10年債利回りが4％を超えるとグロースからバリューへのローテーションが起きる」というルールを目にすることがあります。ルールではありません。10年債利回りは2023年と2024年のほとんどで4％を超えていましたが、そのあいだグロースはバリューを圧倒しました。デュレーションの長い株式に本当に効くのは動きの速さ——数週間で60-80bpの再評価——であって、最終的に落ち着く水準ではありません。

トレード： 10年債利回りがひと月で60bp以上上がったら、いちばん痛手を受けるのは市場のデュレーションの長い側だと考えてください。QQQショート／XLFロングのレラティブバリューです。ただし、この関係は何四半期も黙り込むことを織り込んでサイズを決めましょう。

パート2：相関分析の応用

ローリング相関（動的な関係）

問題： 相関は静的ではありません（SPXとTLTの相関はレジームによって変わります）

レジーム SPXとTLTの相関 読み方
平常時（2010-2019年） -0.4～-0.6（逆相関） リスクオン＝株高・債券安
危機時（2008年、2020年） -0.8～-0.9（強い逆相関） 安全資産への逃避が極端に出る
QE環境（2020-2021年） +0.2～+0.4（プラス！） FRBが両方を買う → 両方が上がる

肝心なのは： SPXとTLTがそろって上がるとき（正の相関）＝FRBが緩和している（強気）。そろって下がるとき（相関は正のままで、向きだけ逆）＝強制的な手仕舞い（パニック）。

先行と遅行の関係

考え方： ある資産が先に動き、別の資産が遅れて追う

主張：銅は株式に1-3か月先行する

  • 銅が上昇 → 産業需要が強い → 世界の成長が加速している
  • 1-3か月後、利益が強い経済を反映して株式が上昇する

これが仕組みで、実在します。実在しないのは「信頼性」です。いまの銅を動かしているのは主に中国の不動産と送配電網、それに数か所の鉱山での供給障害であり、S&Pの企業利益とはあまり関係がありません。下の例は、銅がはっきりと先行しなかったケースです。使ってかまいませんが、目の前の動きで確かめてください。

トレード： SPXが横ばいのあいだに銅がブレイクした（6か月の新高値）場合 → 買いを探す理由になります。ただし、その銅の動きが需要の話なのか供給の話なのかを確かめてから。鉱山の停止は世界の成長について何も語りません。

実例：2023年のラリー前に、本当に最初に向きを変えたもの

場面： 2023年10月——SPXは27日に安値をつけます。教科書は銅が先行すると言います。市場が実際にやったことは、こうです。

時系列とインターマーケットのシグナル：

日付 銅（HG） SPX DXY（ドル） 10年債利回り シグナル

実際に進んだ順序：

  1. 10月3日——ドルが高値： DXYが107近辺で引け、反落を始める
  2. 10月23日——利回りが失敗： 10年債利回りが日中5.02％をつけ、5％を下回って引ける。以後そこまで戻ることはない。全体のなかで最も重要な一本であり、SPXの安値の4日前に出ている
  3. 10月26-27日——クレジットが下げ止まる： HYGが年間安値をつけて上向きに転じる。27日、SPXは4,117で引ける
  4. 11月1日——FRBが据え置き： FRBは金利を据え置き、市場はハト派と受け止める → ドルが下げ、債券が買われる
  5. 11月3日——雇用統計が失望： 10年債利回りが大きく低下。SPXはその年最良の週になる
  6. 12月13日——FRBのドットプロット： 2024年に3回の利下げが描かれる。10年債利回りは4.05％を割り、SPXは4,707
  7. では銅は？ 10月3日からSPXの安値までほぼ横ばい、12月半ばまでにおよそ6％高、そして1月にはSPXが上げ続けるなかで再び値を戻しました。この局面で先行したのは銅ではありません。利回りとクレジットでした。

この最後の一行をよく読んでください。 「銅は株式に1-3か月先行する」はインターマーケット分析で最も繰り返される主張の一つですが、ここでは通用しませんでした。枠組みの正直な言い方はこうです——先行するものは複数あり、順番に入れ替わる。あなたの仕事は、この局面でどれが先行しているのかを見極めることであって、序列を暗記することではありません。

その取引（インターマーケットのシグナルを拾えていたら）：

とるべき行動 日付 価格 根拠
買いシグナル 10月27日 SPX 4,117 10年債利回りが5％で失敗、DXYが反落、HYGが上向きに転換
買い増し 11月1日 SPX 4,238 FRBが据え置き、利回りが崩れ、クレジットが確認
利益確定 1月8日 SPX 4,764 ドルが落ち着き、利回りはもう下がらず、ラリーが伸びきった

トレードの結果：

  • 平均建値： SPX 4,178（10月27日と11月1日を同額で）
  • 決済： SPX 4,764
  • 利益： +586ポイント（+14.0％）
  • 保有期間： 10週間
  • リスク： ストップは4,050、10月27日の日中安値4,104の下＝-128ポイント（-3.1％）
  • R:R（実績）： 586 ÷ 128 ＝ 4.6:1。注意してください。これはうまくいった取引の実績値であって、期待値ではありません。同じストップが刈られていれば3.1％の損失であり、この枠組みはどちらになるかを事前に教えてはくれません。

インターマーケット分析が効いた理由：

  1. 利回りが最初に転換した： 10月23日の5％での失敗は、SPXの安値より4セッション早かった
  2. クレジットが確認した： HYGは10月26-27日に安値をつけ、二度と振り返らなかった——全体で最もきれいな単独の確認
  3. ドルの反転： この期間でDXYは-4％＝コモディティと新興国にとっての追い風
  4. 重い仕事をしたのは金利の動き： 4.93％から4.03％は大きな再評価であり、市場のデュレーションの長い側がこれを最もうまく吸収しました——同じ期間でQQQはおよそ+18％、SPXは+14％です

重要な教訓： ここでの先行は週ではなく日の単位で、しかも銅ではなく金利とクレジットから来ました。それがインターマーケット分析の現実的な主張です——株式のチャートが認めるより先に、たいていは数セッション早く、風向きを教えてくれる。そしてどの先行指標を信じるべきかは、いま実際にどれが先行しているかを確かめたあとで初めて分かります。

パート3：インターマーケットのダイバージェンス（上級シグナル）

💀 サラ・チェンの4万2,800ドルのインターマーケット盲点（3か月）
2023年8月-10月： サラは値動きとRSIだけでSPXを売買し、「売られすぎの反発」のたびに買っていました。リスクオフを叫ぶインターマーケットのシグナルは無視しました。
惨事の一例（2023年8月）： RSIが28（売られすぎ）をつけたあと、SPXを4,420で買い。日足では完璧なセットアップでした。
彼女が見落としたもの： （1）10年債利回りが2週間で3.8％から4.2％へ急上昇（+40bp＝相当な引き締め）、（2）DXYが2.1％上げて104.5へ（ドル高＝リスクオフ）、（3）クレジットスプレッド（HYG/TLT）が8週連続で拡大（クレジットの緊張）、（4）VIXは18で上昇中。四つのインターマーケット指標がそろって「リスクオフ、流動性が枯れる、株は下げる」と叫んでいました。
彼女は無視しました： 「RSIが売られすぎだから買う」。2日後SPXは4,370で引け、9月末には4,200になりました。ストップは4,360——エントリーの1.36％下——で刈られ、22万5,000ドルのポジションで -$3,060。3か月の14回すべてがこの形で、14 × 3,060ドルが $42,800 の損失になります。
対処： すべての株式取引の前に、インターマーケット指標を3つ以上確認しましょう（DXY、10年債利回り、HYG/TLT、VIX）。3つ以上がリスクオフを示していたら、買いは見送るかサイズを50％落とします。これが買ってくれるのは予知能力ではありません。自分のチャートだけがその取引を擁護している、と気づくための規律です。ルール：株式のテクニカル＋インターマーケットの一致＝取引。株式のテクニカルがほかのすべてと言い争っている＝手数料まで払うコイン投げ。

ダイバージェンス#1：運輸対工業（ダウ理論）

理屈： ラリーが有効であるためには、運輸株（DJT）が工業株（DJI）を確認しなければならない

ここでちょうど折り返し地点です。重要な戦略はすでに学びました。

順調ですね！ 必要なら軽く伸びをして、そのあと先の応用的な内容に進みましょう。

ダイバージェンスの形： DJIが新高値を更新し、DJTがついてこない（確認しない）

読み方： モノは作られている（工業）が運ばれていない（運輸）＝偽物のラリー、在庫の積み上がり

トレード： 弱気ダイバージェンス → 株式のエクスポージャーを落とす理由にはなりますが、それ単体でシグナルではありません。この指標の戦績には正直でいましょう。DJTは2015-16年の長い期間、そして2019年にもDJIを確認しませんでしたが、理論が示唆する暴落は来ませんでした。しかも現在の指数は航空会社と宅配業者が中心で、その利益は工業生産と同じくらい燃料価格と消費者向け配送に左右されます。数ある入力の一つとして扱い、プットに金を払う前に、そのダイバージェンスの背後に物語があるかどうかを確かめてください。

ダイバージェンス#2：小型株対大型株（IWM対SPY）

理屈： 小型株はサイクルの転換点で先行する（景気に敏感なため）

強気ダイバージェンス： SPYがまだ下げているのにIWMが底を打って上げる → 景気後退が終わり、リスク選好が戻ってくる

弱気ダイバージェンス： SPYが新高値を更新するのにIWMが確認しない → サイクル終盤、機関投資家がリスクを落としている

ダイバージェンス#3：地域別の株式市場

考え方： 景気循環に応じて、地域ごとに先行したり遅行したりする

先行する市場 シグナル SPXにとっての意味
中国（FXI、MCHI） SPXが横ばいのなか上昇 世界の成長が再加速（強気）
欧州（EZU、VGK） SPXが強いなか下抜け 地域的な緊張（ユーロ危機、エネルギーショック）
新興国（EEM） SPXを上回る ドル安、コモディティの上昇（リスクオン）

パート4：コモディティ複合の分析

コモディティのカーブ：バックワーデーションとコンタンゴ

コンタンゴ（通常）： 先物価格 > 現物価格（保管コストが織り込まれている）

バックワーデーション（需要の急増）： 現物価格 > 先物価格（足元の品薄）

トレードへの示唆：

  • 原油がバックワーデーション → 供給がタイトで需要が強い → エネルギー株（XLE）に強気
  • 原油がコンタンゴ → カーブの通常の状態であり、それ自体はほとんど何も語りません。弱気版は、在庫が積み上がるなかでコンタンゴが急になっていく形です

コモディティ同士の関係

金と実質金利（逆相関）

計算式： 実質金利 ＝ 名目10年債利回り − 期待インフレ率

関係： 実質金利が上昇 → 金は下落（金を持つ機会費用が増える）

実質金利が低下 → 金は上昇 （実質金利がマイナス＝金が魅力的になる）

トレード： 実質金利の低下は金にとって追い風ですが、水準は引き金ではありません——10年の実質金利は2021年のほとんどで-1％を下回っていましたが、金はその年をマイナスで終えました。実質金利は、ドルや中央銀行の買いと並ぶ入力の一つとして扱ってください。実質金利がはっきりプラスだった2023-24年に金を支えたのは、まさにその二つでした。

銅／金レシオ（成長の指標）

レシオが上昇： 銅が金を上回る → 成長が加速（銅＝産業需要、金＝安全資産）

レシオが低下： 金が銅を上回る → 成長が鈍化、ディフェンシブへのローテーション

トレード： 銅／金レシオがブレイク → 景気敏感株（XLI、XLB）を買い、ディフェンシブ（XLP、XLU）を売る

パート5：為替市場から読み取れること

💀 テイラー・ロドリゲスの2万8,400ドルのドル無視の惨事（2か月）
2か月にわたって： テイラーは15分足で株式のブレイクアウトを売買し、ドルのチャートを一度も開きませんでした。セットアップはどれもきれいでした。そこへ持ち込んだ相場のほうが、きれいではなかったのです。
惨事の一例： 15分足のブレイクアウトでNVDAを125.60ドルで400株購入——5万240ドル。完璧なテクニカルのセットアップでした。
見落としていたもの： DXYはちょうど上放れし、2週間で2.8％上げていました。この速さのドル高は、コモディティ、新興国、そして株式のリスクの高い側から同時に流動性を吸い上げます。良いセットアップを悪いセットアップに変えるわけではありませんが、ポートフォリオのすべての買いに対して同時に分を悪くします。26連敗の見た目とは、まさにこういうものです。
NVDAは反転： ブレイクアウトは失敗し、3日後に122.80ドルで手仕舞い。ポジションに対して-2.2％： -$1,120。この形が2か月で26回繰り返されました——平均-1,092ドルの負けが26回です。 損失合計：2万8,400ドル.
対処： その日の最初の株式取引の前にDXYを見ましょう。（1）50 EMAの上か下か。（2）直近5日で上げているか下げているか。（3）今週1.5％以上動いたか。DXYの週間1.5％の動きは、ざっと二標準偏差の出来事です。年に数回しか起きませんから、日々のフィルターではなく、めったに引かない非常ブレーキとして扱ってください。日常版はもっと単純です——直近1週間でドルがどちらへ向かったかを把握し、それに合わせてサイズを決める。

リスクの体温計としてのEUR/USD

EUR/USDが上昇： ドル安 → コモディティが上昇、新興国が優位、SPXにも追い風（USD安は多国籍企業の利益を押し上げる）

EUR/USDが下落： ドル高 → コモディティが下落、新興国が劣後、SPXには向かい風

安全資産としての円

USD/JPYが下落（円高）： リスクオフ、安全への逃避 → SPXはおそらく下落

USD/JPYが上昇（円安）： リスクオン → SPXはおそらく上昇

キャリートレードの巻き戻しを察知する

キャリートレード： 低金利通貨（JPY）で借り、高利回り資産（株式、新興国債券）に投資する

巻き戻しのシグナル： 円が突然強くなる＋VIXが急騰＋新興国通貨が下落 → 大規模な手仕舞い（2008年、2015年8月、2020年3月）

取るべき行動： すべてのリスク資産から直ちに退避する（キャリーの巻き戻しは荒く、そして速い）

⚡ 明日からできること（クリックで展開）

抱え込みすぎないこと。まずはこの3つから：

  1. 今夜、5分でできるインターマーケットのダッシュボードを作る — 6列の表を作ります：日付、DXY、10年債利回り、HYG/TLT、銅、VIX。ルールも書き添えます——「3つ以上がリスクオフを示していたら買いは見送るか、サイズを50％落とす」。すべての取引の前に確認します。サラ・チェンは $42,800 を3か月で失いました。RSIだけでSPXを売買し、14回の「売られすぎの反発」が失敗したのです。そのあいだ10年債利回り、DXY、クレジットスプレッド、VIXはすべて逆を向いていました。ダッシュボードは反転がいつ来るかを教えてはくれません。教えてくれるのは、あなたの株式のセットアップだけがその取引を擁護している瞬間です。
  2. 明日、インターマーケットのダイバージェンス警告を3つ設定する — TradingView（無料）を開きます。警告を設定：（1）HYG/SPYが5日で-3％下落、（2）10年債利回りが5日で+20bp上昇、または4.0％を上抜け、（3）DXYが直近のレジスタンスを上抜け。行動計画：警告1＝株式のエクスポージャーを30-50％落とす、警告2＝グロースからバリューへ入れ替える、警告3＝景気敏感株を減らしディフェンシブを足す。下に出てくるマクロファンドは、まさにこれらのシグナルに逆らって2022年上期に22％を失いました（利回り1.6％→2.5％、DXYは4月末までに+8％、クレジットスプレッドは12週にわたり拡大）。警告は予測しません。ただ、1週間遅れて気づく事態を防ぐだけです。
  3. 毎日「ドルが先」のチェックを使う — 最初の株式取引の前にDXYを見ます。（1）50 EMAの上か下か。（2）直近5日で上げているか下げているか。（3）今週+1.5％以上動いたか。DXYが週間で+1.5％以上上げている＝買いのサイズを半分にするか見送る。下げている＝買いを優先する。テイラー・ロドリゲスは $28,400 を2か月で失いました。DXYを見ずに株式のブレイクアウトを売買した結果です——平均-1,092ドルの負けが26回、いずれもドル高に向かって取った、きれいなテクニカルのセットアップでした。ルール自体への注意を一つ。DXYが1週間で1.5％以上動くのは年に数回しかありません。日々のフィルターではなく、めったに引かない非常ブレーキと考えてください。

クイズ：理解度を確認しましょう

Q1: DXYが主要なサポートを割った（ドル安）。あなたのインターマーケットの取引は？

解答を表示

解答： コモディティ（GLD、USO、COPX）と新興国（EEM）の買いです。ドル安＝コモディティの上昇（USD建てだから）＋新興国に有利（債務負担が軽くなる）。ドルに敏感なセクターから素材・エネルギーへ入れ替えることも検討しましょう。

Q2: SPYが新高値を更新しているのにHYG（ハイイールド債）が下げている。何が起きている？

解答を表示

解答： 真剣に受け止めるべきダイバージェンスです。ただし言い伝えに一点修正を。クレジットは常に株式に先行するわけではありません。2007年と2020年初めにははっきり先行し、2018年と2022年には後れを取りました。そしてHYGは純粋なクレジットの読み取りではありません。実際のデュレーションを抱えているので、HYGの下落はデフォルトの話ではなく金利の話でありうるのです。同じ時間にTLTが何をしているかを見てください。TLTも下げているなら見ているのは金利です。TLTが横ばいか上昇しているのにHYGが下げているなら、それは本物のスプレッド拡大で、弱気の読みに値します——株式のエクスポージャーを落とし、みんなが欲しがる前にプットを買っておきましょう。

Q3: 銅／金レシオが6か月の新高値へブレイクした。マクロのシグナルは？

解答を表示

解答： 成長の再加速です。銅（産業需要）が金（安全資産）を上回る＝リスクオン、景気拡大。景気敏感株（XLI、XLB、XLE）を買い、ディフェンシブ（XLP、XLU）から出ます。小型株（IWM）も優位になるはずです。

実践チェックリスト

日々のインターマーケット点検（5分）：

  • DXYを見る：サポートやレジスタンスを抜けているか（コモディティ、新興国、多国籍企業の利益に効く）
  • 10年債利回りを見る：速く上がっているか（週で>20bp）（グロース株を圧迫する）
  • HYG/SPYの比率を見る：乖離しているか（クレジットが株式を下へ引っ張る＝警告）
  • 銅を見る：トレンドの向きと、その動きが需要か供給か（SPXへの先行は本物だが当てにはならない）
  • VIXとUSD/JPYを見る：両方が急変しているか（キャリートレードの巻き戻し＝全部売る）

週次のインターマーケット精査：

  • 90日のローリング相関を計算する：SPX対TLT、SPX対DXY
  • ダイバージェンスを探す：運輸対工業、IWM対SPY
  • コモディティのカーブを見直す：バックワーデーション（現物がタイト）か、在庫が積み上がるなかで急になっていくコンタンゴか
  • Signal Pilot Janus Atlasで複数資産を重ねる（ダイバージェンスの目視確認）
  • Pentarch Pilot Lineで機関投資家の流れを追う（リスク資産へ入っているか、出ているか）

要点

  • 因果の連鎖： ドル → コモディティ → インフレ → 株式（順序を理解する）
  • クレジットは株式に先行することが多い： HYG/TLTのダイバージェンスは株式のリスクを削る理由になります。HYG単体ではなく比率を使い、2018年と2022年にはクレジットが後れを取ったことを忘れずに
  • 銅／金レシオ＝成長の指標 （上昇＝リスクオン、低下＝ディフェンシブ）
  • 相関はレジームとともに変わる： SPX/TLTは-0.6（平常）にも+0.3（QE）にもなりうる
  • キャリートレードの巻き戻し＝全部売る： 円の急騰＋VIXの急騰＝荒い手仕舞い

インターマーケット分析はあなたを予言者にはしてくれません。それがしてくれるのは、ほかのあらゆる市場が反対している株式の取引を取らせないことであり、ときには2023年10月末のように、株式のチャートが何かを認めるより数セッション早く正しい側に立たせてくれることです。一つの駒ではなく盤全体を見て、枠組みは握りしめずに持ちましょう。先行するものは順番に入れ替わり、遅れの長さは図が示すほど整っていません。
