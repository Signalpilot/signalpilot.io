先月まであなたのトレンドフォロー戦略は札束を刷っていた。今月は？　こま切れにされている。

覚えがありませんか。

居心地の悪い真実がある。相場はレジームのあいだを行き来する——トレンド、平均回帰、高ボラティリティ。そして昨日通用した戦略が、明日にはあなたを壊しうる。

🚨 本音を言えば

たいていのトレーダーは戦略を1つだけ持ち、それをあらゆる相場環境に押しつけようとする。テニスラケットを持ってナイフファイトに現れるようなものだ。道具が違い、時が違い、結果も違う。

🎯 このレッスンで得られること

読み終えたときには、次のことができるようになります。

  • 4つの基本レジームをリアルタイムで見分ける
  • 複数の指標でレジーム検出システムを組む（ADX、ATR、ボリンジャーバンド幅）
  • こま切れにされる前に戦略の選択を切り替える
  • レジームフィルターをJanus AtlasやVolume Oracleと組み合わせる

パート1：4つのレジーム（そして、なぜ間違ったレジームばかり触ってしまうのか）

相場には機嫌がある。それを読むことは必須だ

相場を天気だと思ってほしい。吹雪の日に短パンでは出かけないはずだ。

それなのにトレーダーは毎日それと同じことをしている。往復するレンジでブレイクアウトを買い、止まらないトレンドに逆らい、爆発的なボラティリティのなかでスキャルピングをする。

そこを直そう。

🚀 トレンド（方向性あり）

どう見えるか：

  • 切り上がる高値と安値がはっきりしている（上昇トレンド）
  • 価格が平均（VWAP、EMA）から離れたまま推移する
  • ADX > 25（強いトレンド）
  • トレンド方向の動きで出来高が増える

最適な戦略： 押し目でのエントリー、ブレイクアウトの継続、動きに乗る

避けるべき時間帯： トレンドに逆らう（モメンタムと戦う）、レンジ用のスキャルピング

プロのコツ： 強いトレンドでは、RSIが何週間も「買われすぎ」（>70）のままになりうる。逆らうな。乗れ。

↔️ レンジ（平均回帰）

どう見えるか：

  • 価格が明確なサポートとレジスタンスのあいだで往復する
  • 端から何度も跳ね返される
  • ADX < 20（トレンドが弱い、またはない）
  • レンジの端で出来高が跳ねる

最適な戦略： 端に逆らう（高値を売り、安値を買う）、VWAPへの回帰

避けるべき時間帯： ブレイクアウトのトレード（だましが多い）、トレンドフォロー

注意： レンジはいずれ壊れる。5回目のブレイクアウト挑戦に意地で逆らってはいけない。

💥 高ボラティリティ（混沌）

どう見えるか：

  • 値幅が大きく、どこでも往復ビンタが起きる
  • ATRが通常の2-3倍に跳ねる
  • VIX > 25-30（恐怖が高まっている）
  • ニュース主導（FOMC、決算、地政学イベント）

最適な戦略： 静観する（資金を守る）か、サイズを50-75 %削る

避けるべき時間帯： 通常のポジションサイズ（危険すぎる）、スイングトレード（オーバーナイトのリスクが極端）

率直に言おう： ときには最良のトレードは「トレードしない」ことだ。資金が生き残れば、別の日にまた戦える。

🔒 圧縮（低ボラティリティ）

どう見えるか：

  • 狭いレンジ、短い足
  • ATRが数週間ぶりの低水準
  • ボリンジャーバンドがきつく締まる
  • レジーム転換の前触れ（拡大が来る）

最適な戦略： ブレイクアウトを待て。ノイズをトレードするな

避けるべき時間帯： トレードを無理に作る（狭いレンジではR:Rが低い）、スキャルピング（スプレッド負けで利益が消える）

注意： 圧縮は拡大へと解ける——ここはかなり信頼できる。ボラティリティは平均に回帰するからだ。予測できないのは、時期と方向である。スクイーズが教えてくれるのは大きな動きが来るということであって、どちらへ行くかではない。だからこそ、トレードするのはブレイクそのものであって、その先回りではない。
パート2：レジームを数値化する（勘に頼るのは終わり）

レジーム検出システムを組み立てる

測れないものは管理できない。

「なんとなくトレンドっぽい」という曖昧さを、正確で数値化できるシグナルに変えよう。

指標1：ADX（トレンドの強さ）

ADXが測るのはトレンドの強さであって、方向ではない。

ADXの値レジーム手法
< 20トレンドが弱い、またはない平均回帰、端に逆らう
20-25形成中のトレンドトレンドへの早めのエントリー
25-40強いトレンドトレンドフォロー、押し目
> 40非常に強いトレンドに乗る、逆張りは避ける
> 50極端ストップを引き上げ、分割で利確する（息切れリスク）
要点： ADX > 25はトレンド戦略の青信号だ。ADX < 20なら？　平均回帰に切り替えるか、静観する。
指標2：ATR（ボラティリティ）

ATRはボラティリティ（1本あたりの平均値幅）を測る。

ATRによるレジーム分類：
現在のATR：2.50ドル
20期間のATR平均：2.00ドル

ATR比：2.50ドル / 2.00ドル ＝ 1.25（平均より25 %高い）

解釈：
< 0.8x ＝ 低ボラティリティ（圧縮）
0.8-1.2x ＝ 通常のボラティリティ
1.2-1.5x ＝ やや高いボラティリティ
> 1.5x ＝ 高ボラティリティ（サイズを50 %以上削る）

ATRが平均の1.5xを超えて跳ねたら、危険地帯にいる。ポジションサイズを削るか、完全に静観すること。

指標3：ボリンジャーバンド幅

ボリンジャーバンド幅は、値幅の拡大と収縮を測る。

BB幅 ＝ （上のバンド - 下のバンド） / 中央のバンド

解釈：
BB幅 < 4 % ＝ 狭いレンジ（圧縮、ブレイクアウトが控えている）
BB幅 4-8 % ＝ 通常のレンジ
BB幅 > 8 % ＝ 広いレンジ（高ボラティリティ）

スクイーズはあなたの早期警報だ。 相場は圧縮されており、圧縮は遅かれ早かれ拡大へと解けます。ただし、いつ、どちらへ解けるのかは分かりません。

まとめる：複数指標によるレジームスコア

3つを組み合わせてレジームの「スコア」にする：

レジーム検出チェックリスト：

1. ADXスコア：
   ADX > 25 → +1（トレンド）
   ADX < 20 → -1（レンジ）

2. ATRスコア：
   ATR > 平均の1.5x → +1（高ボラ）
   ATR < 平均の0.8x → -1（圧縮）

3. ボリンジャーバンド幅：
   BB幅 > 8 % → +1（拡大）
   BB幅 < 4 % → -1（圧縮）

4. 価格とVWAPの関係：
   価格 > VWAP + 0.5 % → +1（上昇トレンド）
   価格 < VWAP - 0.5 % → -1（下降トレンド）
   VWAPから0.5 %以内 → 0（レンジ）

5. 出来高の傾向：
   方向性のある動きで出来高が増える → +1（トレンド）
   出来高が横ばい → 0（レンジ）

合計スコア：
+4〜+5 ＝ 強いトレンド（押し目とブレイクアウトを取る）
+2〜+3 ＝ 弱いトレンド（サイズを落とす）
-1〜+1 ＝ レンジ（平均回帰）
-4〜-2 ＝ 圧縮（ブレイクアウトを待つ）
このスコアには、使う前に直しておくべき欠陥がある。 ボラティリティとトレンドは同じ軸ではないのに、このチェックリストは同じ軸であるかのように両者を足し合わせている。ニュースに振り回される混乱した一日は、 ADX が25超、 ATR が平均の1.5倍超、 BB Width が8%超という状態を容易に生む。 VWAP と出来高の項目を数える前に、すでに+3である。つまり、このレッスンが「休め」と言っているまさにその日に、「強いトレンド」という読みが出てしまう。あとの実践演習が「高ボラティリティのオーバーライド」を後付けして、これを打ち消さなければならないことに注意してほしい。そのオーバーライドこそ、単一の数字では機能しないという告白なのだ。二つの軸は別々に採点すること。 ADX と VWAP と出来高をトレンド・スコアとして走らせ、 ATR と BB Width はその横にボラティリティの読みとして置く。そしてサイズを上げるのは、トレンド・スコアが高く、かつボラティリティが平常のときに限る。 そのうえで、ルールはこうなる： すべてのトレードの前に、両方を確認する。どちらかがノーと言うなら、無理をしない。
パート3：リアルタイムでの運用

実際の姿：負け続けた四半期にレジーム規則を当てる

この枠組みを、実際の負けが続いた期間に当ててみよう。サラ（合成事例）はスイングトレーダーで、口座は7万5000ドル、戦略は1つだけ——トレンド内の押し目エントリーだ。2024年第1四半期の8週間で38トレードを行い、3万9,300ドルを失った。戦略が効かなくなったからではない。相場がまだトレンドかどうかを、一度も確認しなかったからだ。それぞれのレジーム規則が防げたものを見てほしい。

直後の対応（第9-10週、2024年3月）：

  • 第9週： サラは取引をやめ、つらい検死に取りかかった。38トレードすべてを、 ADX を重ねたチャートの上に並べたのである。浮かび上がった型は容赦のないものだった。38トレードのうち34回（89%）が、 ADX が20を下回るか（レンジ）、 ATR が平均の1.5倍を超える（高ボラティリティ）状況で取られていた。彼女の戦略が要求するのは ADX が25を超えることである。 ADX が25を超えていた4トレードのうち3勝、下回っていた34トレードのうち7勝だった。 この二つの数字のうち、前者にどれだけ重みを置くかには注意してほしい。 四回のうち三回は、勝率75%ではない。四回のトレードである。そして四回であれば、その偏りは偶然でも十分な頻度で現れるから、エッジとコイン投げの区別はつかない。ここで本当に仕事をしている数字は、34回中7回のほうだ。34回のトレードで4万1,700ドルを失うのは、運の悪さでは届かない結果だからである。彼女の検死が立証したのは否定形の主張であり、そしてそれが役に立つほうだ。彼女の戦略は、ある特定の条件下で成績が悪かった。そして彼女は、その条件下に89%の時間いた。
  • 第10週： サラはTradingViewで「レジーム・ダッシュボード」を作った。（1）ADX指標（トレードするには25超が必要）、（2）ATR比（現在値 / 20期間平均、0.8-1.3xでなければならない）、（3）Volume Oracle（緑、つまりトレンドでなければならない）、（4）BB幅の％（圧縮の確認）。そして規則を決めた：「4つの指標がすべてトレンドのレジームを示さないかぎり、トレードしない。」リプレイのデータで2週間検証した。

彼女が変えたこと：

  • 彼女はサイズを半分にして戻り、すべてのトレードの前にダッシュボードを確認した。 続く四週間で、彼女が取ったのは6トレードだった。その前の八週間が38トレードを生んでいたのに対して、である。この回数こそが眼目であり、この話のなかで実際に数えられる部分でもある。フィルターは彼女のトレードを良くしたのではない。その大半を取り除いたのだ。
  • トレンドが戻ってきたとき、彼女はそれを取りにいった。 ADX が二十台後半から三十台にあった三週間、11トレード、そのすべてが彼女の戦略のために作られた条件下でのものだった。この数週間のリターンは示していない。11トレードではリターンなど出せないし、ここに数字を置けば、それは証拠の衣を着た当て推量になる。
  • そしてまた消えたとき、彼女は手を止めた。 ADX は18に戻り、ダッシュボードは黄色、そして三週間、トレードはゼロ。これはこの手法全体のなかでもっとも難しい部分であり、唯一まったく費用のかからない部分でもある。
  • その後の三か月について、回復の数字は示していない。 口座ひとつの三か月では、フィルターが機能するかどうかは分からない。そして口座の建て直しをルールの証拠として引くことこそ、規律についての話を、リターンについての約束にすり替えるやり方である。言えるのは行動の変化のほうだ。八週間で38トレードだったものが、十二週間で17トレードになり、その17すべてが、あらかじめ自分で定義した条件下にあった。
  • 追跡する価値のある唯一の指標： レジーム一致率 % =（自分の戦略のレジームで取ったトレード数 ÷ 総トレード数）× 100。これが勝率より価値を持つ理由はひとつだ。完全に自分の統制下にあるものを測っており、五百回ではなく五回のトレードのあとに計算できるからである。勝率には、一年かけても手に入らない標本が要る。自分のルールを守れたかどうかは、今夜わかる。

サラの振り返り — サラは合成された教材上の事例であり、Signal Pilotの顧客ではありません。以下の数字は説明のためのものです。

「勝てる戦略を持っていた。実証済みで、 backtest 済みで、収益も出ていた。それなのに、8週間で3万9,300ドルを失った。あらゆる相場環境にそれを押しつけたからだ。トレンド、レンジ、高ボラティリティ、圧縮——どこでも同じプレイブックを使った。正気じゃない。押し目買いの戦略はトレンドを必要とする。トレンドがなければ、エッジもない。その前の四半期、指数はほとんどの日でトレンドを描いていて、私は稼ぎまくった。続く八週間、トレンドだったのは一週間ほどで、私は叩き潰された。38トレード中10勝、-3万9,300ドル。ここで暦の四半期を挙げないのは意図してのことだ。この種の話に日付をつけた瞬間、誰かがチャートを引っぱり出せてしまう。そして、この論点の誠実な形に日付は要らない。同じ戦略。違うレジーム。まずレジームを確認するようになってから—— ADX 、 ATR 、出来高の読み、毎日——自分の戦略がそもそも想定していなかったトレードを取らなくなった。戦略を変えたのではない。レジームが合うときだけ使うようにしただけだ。今の私は取引の回数がずっと少なく、そして取ったものより、見送ったもののほうが効いている。先に確認するのに十秒かかり、たいていは『何もするな』と告げてくる。だからこそ、ほとんど誰もやらないのだ」

教訓——勝てる戦略を持っていることには、間違ったレジームで使うのなら何の意味もない。サラは ADX 25を超える局面での4トレードのうち3勝、下回る局面での34トレードのうち7勝だった。前者は四回のトレードであって何も証明しない。後者は34トレードと4万1,700ドルであり、そちらが発見である。彼女が3万9,300ドルを失ったのは、戦略が悪かったからではない。それがこれまで一度も機能したことのない条件下で、89%の時間それを使ったからだ。レンジでのトレンドフォロー＝ダマシによる死。高ボラティリティでのフルサイズ＝ストップの虐殺。圧縮局面でのトレード＝狭いレンジにエッジなし。プロは単に「ひとつの戦略」を持っているのではない。まずレジームを判定し、そのうえで戦略を選ぶのだ。 ADX を見る（25超＝トレンド、20未満＝レンジ）。 ATR 比を見る（1.5倍超＝高ボラティリティ、0.8倍未満＝圧縮）。 Volume Oracle を見る（緑＝トレンド、黄＝レンジ、赤＝高ボラティリティ）。レジーム ≠ 自分の戦略の要件 → トレードしない。サラにおいて変わったのはトレードの数であって、質ではない。八週間の38回が、十二週間の17回になった。エントリー前のダッシュボード確認ひとつが、残りの21回を取り除いたのである。レジーム判定は「あれば良いもの」ではない。マスタースイッチだ。レジームが違えば戦略を切る。合っていればゴーサイン。プロの取引と、目隠しのギャンブルとを分けるのは、そこである。

パート4：レジームに合わせた戦略の選択

相手に合わせて武器を選ぶ

レジームを見分けられるようになったところで、それをどう使うかを見ていこう。

レジーム 最適な戦略 避ける

パート5：Signal Pilotとの統合

レジーム検出 + Janus Atlas ＝ 不公平なほどの優位

ここから強力になる。レジーム検出を単体で使うのではなく、機関投資家のシグナルに重ねるのだ。

Volume Oracle：レジームの自動検出

Volume Oracleがレジームをリアルタイムで分類してくれる。

Volume Oracleのシグナル：
- 上昇トレンド：緑（押し目のロングを取る）
- 下降トレンド：赤（戻りのショートを取る）
- レンジ：黄（端に逆らう）
- 高ボラ：赤の点滅（静観する）

統合：
Volume Oracle ＝ トレンドのときだけトレードする
レンジなら → サイズを50 %削り、目標を浅くする
高ボラなら → 新規のトレードはしない

Volume Oracleはレジームの副操縦士だと考えよう。緑なら離陸許可。黄や赤なら？　地上で待機だ。

Janus Atlas：レジーム別の読み方

トレンドのレジーム + Janusのスイープ：
- スイープ ＝ 機関投資家の吸い上げ
- 押し目が完了したあとの継続が高確率
- 攻めてトレードする（リスク2 %）

レンジのレジーム + Janusのスイープ：
- スイープ ＝ ストップ狩り、レンジの継続
- 確度は低い：スイープはレンジが自分の端を守っている姿だ
- 慎重にトレードする（リスク1 %）か見送る

高ボラのレジーム + Janusのスイープ：
- どちらとも取れる（反転もありうるし、激しく継続もありうる）
- 見送る（リスクが高すぎる）

同じセットアップでも、レジームが違えばエッジも違う。そこを軽く見ないこと。

Plutus Flow：VWAPとレジーム

トレンドのレジーム：
- 価格がVWAPまで落ちる ＝ 買い（機関投資家が吸い上げている）
- POC ＝ 強いサポート（ポジションを積み増す）

レンジのレジーム：
- 価格がVWAPより上 ＝ 逆らう（VWAPへの平均回帰）
- 価格がVWAPより下 ＝ 買い（VWAPへの平均回帰）

トレンドではVWAPはサポートだ。レンジではVWAPは磁石だ。その違いを知っておこう。

📉 ケーススタディ：レジームへの盲目でマーカスが4万3,000ドルを失った話（3か月）

トレーダー： マーカス・チェン（複数の事例を合成した例）、34歳、専業トレーダー（12万8,000ドルの口座）。日付は示さない。ここでの数字は説明のためのものであり、日付のついた合成例は、けっして一致しないチャートと照合してみたくさせるからだ。

彼が変えたこと： すべてのエントリーの前にレジームを読むこと（ ADX 、 ATR 比、 BB Width ）。ポジションサイズはそれに合わせて調整する——トレンドでは1.5%、レンジでは0.5%、高ボラティリティではゼロ。そして戦略もそれに合わせて選ぶ。トレンドでは押し目、レンジでは端をフェード、どちらでもないときは休む。その後の数か月の回復の数字は示していない。ひとつの四半期で建て直された口座が語るのは、その四半期のことである。挙げる価値があるのは回数のほうだ。レンジだった最初の一か月、彼が取ったのは4トレードで、それに相当する以前の期間は15トレードを生んでいた。

マーカスの教訓： 「4万3,000ドルを失ったのは、市場がいまも自分の戦略の必要とすることをやっているのか、と一度も問わなかったからだ。すべてのトレードの前に ADX を見ること。25を超えていればトレンドのセットアップは取る価値があり、20を下回っていればたいていはない。そして、自分の数字が何を証明していて何を証明していないのかについて、正直であること。俺の良かった期間と悪かった期間は連続していた。二つを並行して走らせたわけではない。だから本当に学んだのはこういうことだ——戦略には条件があり、俺の条件は満たされなくなり、そして俺は三か月それに気づかなかった。行動に移すにはそれで十分だ。だがそれは、両者を分けたのが ADX だったと証明したことにはならない」

ケーススタディの問題：マーカスはトレンドフォローの押し目で、2か月（2023年9-10月）に勝率75 %、＋1万8,420ドルを稼いだ。その後、同じ戦略で3か月（2023年11月〜2024年1月）に4万3,280ドル（-29.4 %）を失った。11月：勝率33 %、-6,840ドル。12月：勝率20 %、-1万8,920ドル（リベンジトレード）。1月：勝率28 %、-1万7,520ドル（サイズを2 %に上げた）。ADXが32から17へ崩れるあいだ、彼は「ツキのなさ」のせいにしていた。パターン：押し目はどれも跳ね返り、そのあとレジスタンスで失速した（レンジでのだましのブレイクアウト）。口座：14万7000ドル → 10万4000ドル。マーカスの致命的な誤りは何か。

A) トレンドフォロー戦略が効かなくなった（押し目はもう機能しない）
B) 損失のあとにリベンジトレードをした（11月の損失のあとで休むべきだった）
C) ストップが狭すぎた（高ボラの局面ではストップを広げるべきだった）
D) 相場レジームを一度も確認しなかった。相場がトレンド（ADX 28-35）からレンジ（ADX 15-18）に移ったあともトレンド戦略を使い続けた。同じ戦略でもレジームが違えば勝率は75 % → 27 %。彼がトレンドフォローをしていた11週間、SPYは横に往復していた

正解：D。 マーカスの惨事はレジーム盲だった。市場がまだトレンドを描いているのかを、一度も確認しなかったのである。良かった期間——方向性のある相場、 ADX 28から35、24トレード中18勝、+1万8,420ドル。彼はそれを「コードを解読した」と読んだ。正しい戦略が正しい条件下にあり、そのどちらの効果かを切り分ける手立てはなかった。そのあと市場は十一週間にわたり狭い帯のなかを横ばいで進み、 ADX は32から17へ落ちた。それでも彼は確認もせず、同じやり方を続けた。押し目はいちいち反発し、そしてレンジの上限で失速した。続く45トレードのうち勝ちは12回、-4万3,280ドル。下げの途中でリベンジ・トレードに走り、リスクを2%に引き上げてもいる。見落としたものは目の前にあった。良かった期間の32に対し、 ADX は15から18だったのだ。レンジのなかでは、トレンドの押し目はだましのブレイクの罠に変わる。彼の処方箋は、すべてのエントリーの前にレジームを読むことだった——25を超えていればトレンドのセットアップはフルサイズに値し、20を下回っていればたいていは値しない——そして目に見えた効果は、トレードの回数が大きく減ったことである。彼自身の数字が示すものと示さないものに注意してほしい。良いトレード24回と悪いトレード45回。その順序で、ひとつの口座で、ひとつの市場で起きたことだ。彼の戦略には条件があり、彼はそれを確認するのをやめていた、と結論するにはそれで足りる。 ADX の統制された検証には、ならない。

🎓 要点

  • 4つのレジーム： トレンド、レンジ、高ボラ、圧縮——それぞれに違うやり方が要る
  • ADX + ATR + BB幅： レジーム検出の道具箱（勘ではなく数値化する）
  • レジームスコア： +4〜+5 ＝ トレンド戦略を取る、-2〜-4 ＝ ブレイクアウトを待つ
  • ポジションサイズは適応する： トレンドではフルサイズ、レンジでは縮小、 ATR が高いときは半分、そしてコンプレッションではゼロ——このゼロが属するのはコンプレッションであって、ボラティリティではない点に注意してほしい。高いボラティリティは小さくする理由であり、方向のない圧縮されたレンジは、そもそもそこにいない理由だ。第3部が実際に示しているのはこの段階だ
  • Volume Oracleを重ねる： レジームとフローの両方がそろったときだけトレードする
  • 同じセットアップ、違うレジーム： どちらの事例も、条件によって勝率に大きな開きがあることを示している。ただし、どちらも連続した期間どうしの比較である。だからこの差は、測定された効果ではなく、検証を続けるべき仮説として扱うこと

🎯 実践課題：自分のレジーム分類システムを作る

目的： リアルタイムのレジーム検出ダッシュボードを作り、分類の正確さをbacktestで確かめる。

パート1：レジームのスコアカードを作る

主力銘柄（SPY、ES）について、4つの指標を並べた表を作る。各指標を採点する： ADX（14）： >25 = +1, <20 = -1. ATR比： >1.5× = +1, <0.8× = -1. BB幅： >8% = +1, <4% = -1. 価格とVWAPの関係： >0.5 % ＝ +1、<-0.5 % ＝ -1。点数を合計する。 分類： +4 ＝ 強いトレンド | +2〜+3 ＝ 弱いトレンド | -1〜+1 ＝ レンジ | -4〜-2 ＝ 圧縮。

パート2：10日間のレジーム分類backtest

10営業日さかのぼり、寄り付き（9:30）時点のレジームを分類する。そのうえで検証する：

  1. 9:30時点のレジームスコアを計算する
  2. 予測したレジーム：トレンド / レンジ / 圧縮
  3. その日の実際の値動き：トレンドになったか。レンジか。往復か
  4. 正確さ：分類は正しかったか。はい／いいえ

自分を採点する前に、まずベースレートを出しておくこと。 もし十日のうち七日がレンジの日で、指標を一切見ずに全部の日を「レンジ」と分類していたなら、それだけで10問中7問正解になる。したがって重要なのは正答率そのものではなく、「いちばん多い答えを always 選び続けた場合」を上回った分の正答率である。十日では、どちらにせよ決着はつかない。やってみて、そして続けること。最初の一か月は、この分類が合格できる試験としてではなく、この分類がどうふるまうのかを知るための期間として扱うこと。

パート4：レジーム転換の検出

レジームの変化をリアルタイムで追う。レジームが変わったとき、どう適応するか。

  • シナリオ1： トレンドのレジーム（スコア+4） → 圧縮（スコア-2）へ2時間で移行
  • よくある向き合い方： トレンドのポジションを50 %閉じ、ストップを引き締め、新規エントリーを止める
  • シナリオ2： 圧縮（スコア-3） → ブレイクアウト後にトレンド（スコア+4）
  • よくある向き合い方： これこそ最も確率の高いセットアップだ。ブレイクアウト後の最初の押し目で攻めて入る

アラートを作る： レジームスコアが+4を超えたとき（攻めに転じる）と-2を割ったとき（守りに入る）にアラートを設定する。

パート5：レジーム別の成功率の分析

直近20トレードを見返す。エントリー時点のレジームを分類し（トレンド+4〜+5、弱いトレンド+2〜+3、レンジ-1〜+1、圧縮-4〜-2）、レジームごとにトレード数と勝ち数を数え、成功率を計算する。 何を見るべきか、そしてそこにある罠： あるレジームでの勝率が別のレジームより大きく高いなら、それは行動に移す価値がある。ただし、レジームが原因だと結論づける前に、日付を見てほしい。レジームは数週間単位の塊でやってくる。だから、自分の「トレンドのトレード」と「レンジのトレード」は、たいてい自分の履歴の連続した二つの区間なのだ。そして、良い時期と悪い時期をまたいで比べれば、どんな戦略でもこの差は現れる。レジームがそれを生んだかどうかとは関係なく、である。決着をつける方法は、記録を取り続け、次にレジームが入れ替わったときに同じ型が繰り返されるかを見ることだ。それまでは、証明された filter ではなく、有力な仮説として扱うこと。

実行の目標： このシステムを3日で作る。21営業日続けて使う。すべてのトレードの前にレジームスコアを記録する。スコアが戦略を支持しないなら、トレードしない。期待値ははっきり改善する。

⚡ 明日からできること（クリックで展開）

抱え込みすぎないこと。まずはこの3つから：

  1. 今夜TradingViewでレジーム・ダッシュボードを作る — 指標を4つ追加する。（1）ADX（14期間）に20（レンジ）と25（トレンド）のラインを引く、（2）ATRの％に平均線を引く（SPYなら1.5-2.5 %）、（3）ボリンジャーバンド（20, 2）で幅が4 %未満か8 %超かを見る、（4）出来高バーに20日移動平均を重ねる。チェックリストを作る：「すべてのトレードの前に確認：ADX [___]、ATR比 [___]、BB幅 [___]、出来高レジーム [___]。」確認例：ADX = 18（レンジ）、ATR = 1.8（高ボラ）、BB = 9 %（拡大）＝レジームスコア：トレンド戦略はトレードしない。マーカス・チェンは $43,000 を三か月で失ったのは、一度もレジームを確認しなかったからだ。相場がトレンドだったあいだは24トレード中18勝、それが止まったあとは45トレード中12勝。ダッシュボードを作るのに20分、確認するのに10秒。マスタースイッチ——レジームが違えば、戦略を切る。
  2. 直近20トレードをレジーム分類つきでbacktestする —— それぞれのトレードについて、エントリー時点で記録すること。(1) ADX の値（25超＝トレンド、20未満＝レンジ）、(2) ATR 比（1.5倍超＝高ボラティリティ）、(3)戦略の種類、(4)結果。表を作る：トレード番号｜日付｜ ADX ｜ ATR ｜レジーム｜戦略｜一致したか｜結果｜ R 。そして、レジームが戦略と一致していたときと、していなかったときの勝率を計算する。ここで期待される数値を示さないのは意図してのことだ。何が見つかるかを先に告げてしまうのは、それを見つけさせる確実な方法だからである。マーカス自身の内訳は、一致した24トレードで18勝、一致しなかった45トレードで12勝だった。これについて二つ。実在する差であり、真剣に受け止める価値がある。そして同時に、レジームが戦略の質に勝ることの証明にはならない。その24回と45回は、ひとつの市場でひとつの口座に連続して起きた区間であって、統制された比較ではないからだ。20トレードでも、あなたのために決着はつかない。それでも記録を始めること。標本を手に入れる道は、それしかない。
  3. 次の10トレードのためにレジーム別のポジションサイズ規則を作る —— 基準リスク＝2%。レジームごとの倍率：(1)強いトレンド（ ADX 30超、 ATR 平常）：1.0倍＝フルの2%、(2)弱いトレンド（ ADX 20から25）：0.75倍＝1.5%、(3)レンジ（ ADX 20未満）：0.5倍＝1%、(4)高ボラティリティ（ ATR 1.5倍超）：0.5倍＝1%、(5)圧縮（ ADX 15未満、 ATR 0.8倍未満）：0倍＝トレードなし。ルールは付箋に書いておくこと。例：月曜、 ADX 28（トレンド）＝フルの2%リスク。火曜、 ADX 17（レンジ）＝1%リスク、あるいは見送り。水曜、 ATR 1.7倍（ FOMC ）＝0.5%リスク、あるいは休み。トレンドのレジームがレンジのレジームよりどれだけ優れているか、その倍率はここでは示さない。それは完全にあなたの戦略次第であり、あなたの戦略について誰も測ってなどいないからだ。争いのないのはボラティリティのほうの半分である。 ATR が二倍になれば、同じ株数のポジションが負うリスクはおおよそ二倍になる。だからドル建てのリスクを一定に保つとは、サイズを半分にするということだ。これは算数である。トレンドでサイズを上げるのは判断であり、レッスンに書かれた数字ではなく、自分の記録に従うべきものだ。
