🎯 学べること

このレッスンを終えると、次のことができるようになります：

  • slippageは測れる：（約定価格 - 仲値）／仲値を、すべてのトレードで
  • 指値注文は成行注文に勝つ。約定を数回逃す代わりに、平均価格がよくなる
  • ひとつの価格で一度に約定させるのではなく、2〜3回のトランシェに分けて建てる
  • 枠組み：自分のslippageを測る → 指値注文とストップ・リミット注文に切り替える → 最初と最後の15分を避ける

勝率70 %、平均3R。本来なら圧勝しているはずだ。

なのに口座はやっと10 %のプラス。どういうことだ？

執行だ。あなたはslippageとスプレッドのコストで1トレードあたり0.15 %を流している。200トレードなら？　リターンの30 %が消えている計算だ。

🚨 本音を言えば

どう入るかは、何に入るかと同じくらい重要だ。成行注文＝即座の満足＋即座のslippage。指値注文＝忍耐＋よりよい約定。その差は？　年10〜15 %。

🎯 このレッスンで得られること

読み終えたときには、次のことができるようになります。

  • 指値注文、ストップ・リミット注文、アイスバーグ注文でslippageを最小化する
  • 平均建値をよくするために分割して建てる
  • slippageの大きい時間帯（9:30〜9:45、15:45〜16:00）を避ける
  • 実効スプレッドコストを計算して追跡する

💡 腑に落ちる瞬間

執行こそがエッジだ。1トレードあたり0.1 %節約 → 100トレードで年10 % → 5年で60 %超に複利で積み上がる。ほとんどのトレーダーはセットアップに集中する。勝つ者は執行に集中する。

⚡ 明日からできること（クリックで展開）

抱え込みすぎないこと。まずはこの3つから：

  1. 今夜、slippageの実コストを計算せよ — 直近20トレードを開く。それぞれについて、(1) 意図した仕掛け価格、(2) 実際の約定、(3) その差を記録する。計算する：1トレードあたりの平均slippage、合計コスト、粗利益に対するslippageの割合。サラ・マルティネスは $14,237 を2024年第1四半期だけで執行コストとして失った（約90トレード）——その四半期の潜在利益の33 %が、成行注文と拙いタイミングによって消えた。1トレードあたりのslippageが0.1 %を超える、あるいは粗利益の10 %を超えるなら、あなたは毎年数千ドルを流している。測っていないものは改善できない。
  2. 次の10トレードは指値注文に切り替える — 成行注文はもう使わない（緊急時を除く）。買いならビッド、売りならアスクに指値を置く。30秒で約定しなければ1ティック動かす。ストップにはストップ・マーケットではなくストップ・リミットを使う。1トレードあたり0.05〜0.15 %の節約＝100トレードで年5〜15 %。成行注文＝即座の満足＋即座のslippage。指値注文＝価格の主導権。トレードの5〜10 %は逃すが、取れた90〜95 %で0.05〜0.15 %を節約できる。差し引きプラスだ。約定率とslippageを記録して裏を取れ。
  3. slippageの大きい時間帯に「トレード禁止ゾーン」を作る — 避ける時間帯：9:30〜9:45（スプレッドが最も広く、約定が最悪）、12:00〜13:30（薄商い、広いスプレッド）、15:45〜16:00（荒い値動き、リバランスの混乱）。サラは9:35に取引していた：1株あたり平均0.18ドルのslippage。9:50まで待つようにしたら1株あたり0.06ドル——1株あたり0.12ドル×100株×50トレード＝年間600ドルの節約。これらの時間帯ではスプレッドが2〜5倍に広がる。「寄り付きで取引したかったが待って、X ドル節約した」という例を10件記録せよ。忍耐が金になる証拠だ。

🎮 執行品質のチェック

1. 戦略は backtest では小さなプラスのエッジを示すのに、実弾では一貫して結果が悪い。疑わしいのは執行コストだ。まずどこを見るべきか？

A）手数料。請求書が来る唯一のコストだから
B）slippage — 1トレードあたり数分の1パーセントでも、取るトレードすべてに積み上がる
C）取引所手数料。取引所ごとに異なる
D）どこも見なくていい — 実弾と backtest の差は必ずレジームの変化だ
正解：B。 slippage は請求書の来ないコストであり、だからこそ検証されずに残る：明細に項目として並ばず、約定価格のなかに埋もれているからだ。100回のトレードにわたれば、片側あたり数分の1パーセントがリターンの大きな部分を持っていく。A と C は実在するコストだが、目に見えるうえ、たいてい backtest にすでに入っている。D はありうるが、市場構造の説明に手を伸ばす前に、機械的な説明を消しておくべきだ。

2. アスクに見えているサイズより大きなポジションを買う必要がある。レッスンは何を勧めているか？

A）1本の成行注文で送り、約定を受け入れる
B）分割して出し、アイスバーグを使って板に自分の全サイズを見せない
C）出来高が最も多い引けまで待つ
D）誰かが反応する前に約定するよう、スプレッドを積極的に越える
正解：B。 大きな見えている注文は情報であり、板はあなたが約定する前に不利な方向へ値を付け直す。分割して残りを隠せば、サイズは視界の外にとどまる。A はまさに、この節が防ごうとしている間違いだ。D は焦りを優位性と読み違えている — 高値づかみは、その値幅で最悪の価格を確定させる。C は出来高については半分正しいが、引けは一日でもっともスプレッドが広い時間帯のひとつだ。

3. サイズに敏感なエントリーにとって最悪の時間帯はどれか？

A）寄り付き直後と引け直前の15分間
B）寄り付きのレンジが解けたあとの午前中盤
C）出来高が細るランチタイム
D）指値注文を使うなら違いはない
正解：A。 寄り付きと引けはスプレッドがもっとも広く、参加者ももっとも攻撃的だ。だから出来高が多くても、そこに置いた注文は取引に最も高い代償を払う。C は魅力的な選択肢だ。出来高が薄いのは危なそうに聞こえるし、非常に大きなサイズでは実際に効く。しかしスプレッドのコストは寄り引けより小さい。D は特定の意味で誤っている：指値は価格を決められても、約定するかどうかは決められない。速い時間帯では、約定しなかった指値そのものがコストになる。

🎓 要点

  • slippageは1トレードあたり0.1〜0.5 %のコスト： 100トレードならリターンの10〜50 %が消える
  • 成行注文＝即座の満足： 指値注文＝よりよい約定（忍耐が金を守る）
  • 分割して建てる： 大きな注文を2〜3トランシェに分けて平均価格を改善する
  • slippageの大きい時間帯を避ける： セッションの最初と最後の15分＝最も広いスプレッド
  • サイズにはアイスバーグ注文を使う： order bookで手札を全部見せるな
  • 実効スプレッドコストを追跡する： すべてのトレードで（約定価格 - 仲値）／仲値を測る

実行の目標： これらの執行の改善を30日間実行せよ。前後のslippageを記録せよ。目標の例：slippageを30〜50 %減らす。往復0.3 %なら1トレードあたり0.09〜0.15 %の節約、つまり年100トレードでおよそ9〜15 %になる。執行こそがエッジ——いまやあなたはそれを流すのではなく、取り込んでいる。

あなたはいま、ヘッジファンドが何百万ドルも払って手に入れるものを学んだ。執行アルゴリズムだ。分割して建て、指値を使い、読まれる時間帯を避ける。小さな優位は積み上がる。年に百トレードなら、これだけで10〜15 %の価値になりうる。
