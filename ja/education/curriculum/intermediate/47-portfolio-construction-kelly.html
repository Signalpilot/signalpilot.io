パート1：なぜ多くのトレーダーはポートフォリオの組み方を間違えるのか

単一戦略の罠

個人トレーダーの多くは1つの完璧なセットアップを磨き上げる。ブレイクアウト戦略のbacktestingに何か月もかけ、R:R 2:1で勝率55%に到達し、「これで勝った」と思う。

問題点： 単一戦略のトレーダーは、レジームが1回変わるだけで口座を吹き飛ばす距離にいる。

📉 実例：ブレイクアウトトレーダーのエッジが1四半期で消えた話

場面： このトレーダーには実績のあるモメンタム・ブレイクアウトのシステムがあった。2022年の成績：勝率58%、平均利益580ドル、平均損失320ドル。期待値は1トレードあたり+202ドル。233トレードで15万ドルの口座に4万7,000ドル（+31%）を積み上げ、年末は19万7,000ドルだった。

2023年1月〜4月： FRBがタカ派に転換する。市場はトレンド（ブレイクアウトが効く）から荒れたレンジ（ブレイクアウトが伸びない）へ移る。

結果： 勝率は58%から38%へ落ち、平均利益はブレイクアウトが伸びなくなったせいで580ドルから310ドルへ縮んだ。期待値は1トレードあたり+202ドルから-80ドルへ反転した。それでも彼は取引を続け、3月には取り返そうとサイズを倍にした。190トレードで-2万ドル（積み上げた19万7,000ドルの-10%）。そしてより高くついたのは、新しいレジームで稼ぐための平均回帰戦略がゼロだったせいで、1年のうち4か月を無収入で過ごしたことだ。

教訓： 1つの戦略＝1つの単一障害点。レジームの変化は彼の口座を吹き飛ばしたのではない。彼のエッジを消したのだ。単一戦略のトレーダーにとって、それは同じことだ。機関投資家が5〜15の相関の低い戦略を回すのは、死んだレジームのコストを1つのスリーブに収め、1年まるごとにしないためである。

ポートフォリオ構築の3本柱

プロのポートフォリオ構築は3本の柱の上に立つ。

柱 個人のやり方 機関投資家のやり方
1. 分散 ひとつの「完璧な」戦略 レジームをまたぐ5〜10の戦略（トレンド、平均回帰、ボラティリティ、相関）
2. ポジションサイズ 1トレード固定1〜2%（エッジを無視） 一律のルールではなく、エッジの強さに応じてサイズを決める。ケリーの一定割合を、エッジの推定が変わるたびに計算し直す
3. 相関の管理 無視される（すべての戦略が相関） 相関した戦略への配分を減らす（同じ賭けを二重に張らない）

エッジ基準の配分と均等配分

均等配分： 各戦略に同じ%を割り当てる（例：3戦略ならそれぞれ33%）

エッジ基準の配分（ケリー）： エッジの強い戦略にはより多く、弱い戦略にはより少なく配分する

例：均等配分がテーブルに金を置き去りにする理由

3つの戦略： A（勝率65%、1.2:1 → フルケリー35.8%）、B（52%、1.5:1 → 20.0%）、C（48%、1.3:1 → 8.0%）。 均等配分： リスク予算をそれぞれ33%ずつ。エッジがAの4分の1しかないCに同じ額を張ることになる。 ケリー配分： エッジに比例して配分する — 56% / 31% / 13%。成長はおおむねリスク加重の平均エッジに比例する。均等配分なら (35.8 + 20.0 + 8.0) / 3 = 21.3、エッジ配分なら 0.56 × 35.8 + 0.31 × 20.0 + 0.13 × 8.0 = 27.3 だ。同じ総リスクでおよそ28%多い期待成長になる。CからAへ移した1ドルは、四倍半のエッジを稼ぐからだ。均等ではなくエッジで配分しよう。

レジーム耐性を持たせて組む

市場は4つの主要レジームを巡る。ポートフォリオにはそれぞれに対応する戦略が必要だ。

レジーム 特徴 機能する戦略のタイプ
上昇トレンド 高値切り上げ、低ボラティリティ、QEの環境 モメンタム・ブレイクアウト、押し目買い、BTFD戦略
下降トレンド 安値切り下げ、上昇するボラティリティ、QTの環境 Breakdownのショート、戻り売り、プットスプレッド
レンジ 荒れて、サポートとレジスタンスの間を往復する 平均回帰、サポート/レジスタンスでのトレード、シータの減価（オプション売り）
高ボラティリティ VIX > 25、往復ビンタ、不確実性 ボラティリティ売り（急騰の後）、ストップを広く取る戦略、サイズの縮小

💡 プロのヒント：「2-2-1」のポートフォリオ構成

機関投資家はしばしば「2-2-1」の分散モデルを使う。

  • トレンド戦略2つ （ロング寄りとショート寄り）— 方向性のある動きから取る
  • 平均回帰戦略2つ （サポートでの反発とレジスタンスでのフェード）— レンジで稼ぐ
  • ボラティリティ戦略1つ （VIX急騰のトレードまたはプレミアム売り）— 混乱に対するヘッジ

これで複数のレジームに同時にエクスポージャーを持てる。トレンドが死ねば平均回帰が動き出す。ボラティリティが爆発すれば、ボラティリティ戦略が他をヘッジする。

パート2：ケリー基準 — 最適サイズの数学

ケリー基準とは何か

この ケリー基準 は、たった1つの問いに答える数式だ。 「自分のエッジ（勝率とリワード/リスク比）を踏まえて、長期の複利成長を最大化するには口座の何%を1トレードでリスクに晒すべきか」

1956年にベル研究所のジョン・ケリー・ジュニアが考案し、以来こうした人々に使われてきた。

  • エド・ソープ： カードカウンティングでブラックジャックを攻略し、その後1969年から1988年までプリンストン・ニューポート・パートナーズをフラクショナル・ケリーで運用した。投資家の手取りで年およそ15%、手数料控除前でおよそ19%、230か月のうち227か月がプラスだった。彼について普段引かれる数字は控除前のほうであり、控除後の数字こそ、投資家が実際に複利で積み上げたものだ
  • ウォーレン・バフェットとチャーリー・マンガー： 2人とも、固定の配分比率ではなくエッジの強さでサイズを決めると語ってきた。式こそ使わないがケリーの論理だ
  • Renaissance Technologies： ジム・シモンズのMedallionファンドは、まさにこの形で三十年にわたり手数料控除後で年率およそ39%を複利で積み上げた。小さく相関の弱いエッジを数多く持ち、そのそれぞれを快適さではなく成長に合わせて張ったのだ

ケリーの式（簡略版）

ケリー % = (勝率 × 平均利益 - 負率 × 平均損失) / 平均利益

あるいは数学的な表記では：

f* = (p × b - q) / b

ここで：

  • f* ＝ リスクに晒す資金の最適な割合（ケリー %）
  • p ＝ 勝率（勝つ確率）
  • q ＝ 負率（1 - p）
  • b ＝ 利益/損失比（平均利益 / 平均損失）

ケリーの計算をステップごとに

例： 勝率60%、平均利益500ドル、平均損失300ドル。変数：p = 0.60、q = 0.40、b = 500ドル/300ドル = 1.67。 計算式： f* = (0.60 × 1.67 - 0.40) / 1.67 = 0.60 / 1.67 = 0.359 = フルケリー35.9%. クォーターケリーを使う： 35.9% / 4 = 1トレードあたり9%.

✅ 実務での意味

口座10万ドル、この勝率60%のシステムなら：

  • フルケリー（35.9%）： 1トレードで3万5,900ドルをリスクに晒す — 自殺行為だ（1週間悪ければ口座は消える）
  • クォーターケリー（9%）： 1トレードで9,000ドル — 成長と生存の最適なバランス
  • よくある1〜2%： 1トレードで1,000〜2,000ドル — 安全だが、エッジを大量に眠らせている

肝心なのは： 勝率60%、R:R 1.67:1が実証されているなら、1〜2%しかリスクを取らないのはエッジの大半を眠らせることだ。成長最適な数字は35.9%、実際に張る数字はその4分の1。次のセクションで、なぜ全部ではなく4分の1を取るのかを正確に示す。

なぜフルケリーは危険なのか（分散の問題）

フルケリーが最適化するのは 最大の幾何平均成長 だが、無視しているのは 心理的な生存.

数学的な問題： 勝率60%でも、必ず連敗は来る。5連敗の確率はこうだ。

0.40^5 = 0.01024 = 1.024%

言い換えると： 年間100トレードなら、5連敗にはおよそ年1回出くわす。

ケリーの分数 1トレードあたりのリスク 5連敗後の損失 必要な回復
フルケリー（35.9%） $35,900 -89.2%（口座は1万800ドル） 元に戻すには+824%（不可能）
ハーフケリー（18%） $18,000 -62.9%（口座は3万7,100ドル） 元に戻すには+170%（かなり厳しい）
クォーターケリー（9%） $9,000 -37.6%（口座は6万2,400ドル） 元に戻すには+60%（達成可能）
固定2% $2,000 -9.6%（口座は9万400ドル） 元に戻すには+11%（簡単だが成長は遅い）

結論： ケリーの分数fにおける成長は最大値の(2f − f²)だ。ハーフケリーは半分のボラティリティで最適成長率の75%を保ち、クォーターケリーは4分の1のボラティリティで44%を保つ。フルケリーは成長率を100%保ち、上の表のdrawdownを手渡してくる。成長の4分の1を差し出して振れ幅を半分にするのは、ほとんど誰もが受けるべき取引だ。

なぜエド・ソープは分数ケリーを使ったのか

ソープ——ブラックジャックを攻略し、その後二十年にわたってプリンストン・ニューポートを手取り年およそ15%で運用した数学者——は、フラクショナル・ケリーを神経の問題としてではなく算数として擁護した。ケリーの割合fにおける成長率は最大値の(2f − f²)であり、一方でボラティリティはfに比例して増える。ハーフ・ケリーなら、成長率の2(0.5) − 0.25 = 75%を保ったまま、振れ幅は半分になる。クォーター・ケリーなら、2(0.25) − 0.0625 = 44%を保って、振れ幅は四分の一になる。成長率の四分の一を払ってドローダウンを半分にするのは、メニューの中で最良の取引だ。そして56%を払って四分の一にするのも、たいていの人は取るべき取引である。実際に自分が生きて通り抜けるドローダウンこそが、そもそも複利を積み上げる場に残っていられるかを決めるからだ。 ルール： 実際のトレードではケリーの25〜50%を使おう。

そして、精神面よりも重い第二の理由がある。 ケリーは、あなたがpとbを知っていることを前提にしている。知らない。あなたはそれを自分の有限なトレード記録から推定したのであって、その推定には、式がけっして目にしない誤差の幅がついている。勝率をほんの少し楽観的に入れれば、出てくる割合は「ほんの少し大きすぎる」のではなく、かなり大きすぎるものになる。上の60% / 1.67の例を取ろう。フル・ケリーはおよそ36%と言う。勝ちが60%の100トレードは、通常の信頼水準で真の勝率を50%から70%あたりに置く。p = 0.55なら式は28%と言い、p = 0.50なら20%と言う。100トレードでは決着のつかない勝率の差によって、あなたのポジションサイズは二倍近く揺れるのだ。しかも、その誤りは結果において対称ではない。ケリーを超えて賭けることが成長を壊す速さは、控えめに賭けることが失わせるものよりはるかに大きい。だから、高すぎる推定は、同じだけ間違った低すぎる推定よりずっと痛い。フラクショナル・ケリーが本当に買っているのはこれである。測定したエッジが見かけの半分でもおかしくないのなら、測定値が示す量の四分の一で張ることは臆病ではない。標本がたまたま見せたエッジではなく、自分が実際に持っているかもしれないエッジに合わせてサイズを決める、ということだ。

💰 検討例：ケリー比率は50万ドルの資金に何をするか

50万ドルのブックを持つプロップトレーダー：勝率58%、平均利益450ドル、平均損失300ドル。 旧（固定2%）： 年間+14万ドル（+28%）、シャープ1.2、drawdown 15%。 計算： b = 450/300 = 1.5、したがってフルケリー = (0.58 × 1.5 − 0.42) / 1.5 = 30.0%。彼が決して張らない数字だ。彼はその十分の一、1トレードあたり3%にした。 新（3%）： 年間+21万ドル（+42%）、シャープレシオは1.2のまま、DDは22%。サイズを上げてもリスク調整後リターンは良くならない。リターンもドローダウンも、そろって約1.5倍になっただけだ。ケリーが彼にもたらしたのは、3%が上限には程遠いという確信であり、それによって、実証されたエッジの三分の二を使わずに放置するのをやめられた。

📉 ケーススタディ：フルケリーがLisaに11万4,000ドルを払わせた

場面： Lisa Chang（合成事例）、クレジットスプレッドで勝率68%のオプショントレーダー。クレジットスプレッドが実際に持つ形そのもので、利益は小さく損失は大きい（平均利益250ドル、平均損失400ドル、R:R 0.63:1）。期待値は1トレードあたり+42ドル、本物のエッジだ。フルケリー = (0.68 × 0.625 − 0.32) / 0.625 = 1トレードあたり16.8%。口座18万5,000ドル、2024年4月〜6月。

惨事： 第1〜2週：フルケリーで+7,500ドルの利益、口座は19万2,500ドル。第3週：6連敗（0.32^6 = 0.1%の確率）。1回の損失で16.8%が飛び、複利で効くと0.832^6 = 0.332、つまり-66.8%のdrawdownになる。口座は1週間で19万2,500ドルから6万4,000ドルへ落ちた。彼女は残りの四半期を小さく張り、6月末を7万1,000ドルで終えた。3か月で-11万4,000ドル、-62%。エッジそのものは一度も疑われていない戦略でだ。

何が変わったか： 彼女はクォーター・ケリー、1トレードあたり4.2%に移した。その後の数か月のリターンは示していない。口座ひとつの6か月では、サイジングのルールが機能するかどうかは分からないからだ。分かるのは算数のほうであり、この事例がここにある理由もそこにある。同じ6連敗を4.2%で走らせてみればいい。0.958^6 = 0.773、つまり19万2,500ドルは6万4,000ドルではなく14万9,000ドルになる。同じエッジ、同じ連敗、同じ不運で、差は8万5,000ドル。そしてその1ドルに至るまで、すべては割合が生んだものであって、その間に彼女が相場について学んだ何かが生んだものではない。

教訓： フルケリーは理論上の最適解であり、同時に破滅的な分散を連れてくる。クォーターケリーは理論上の成長率のおよそ44%を保ちながら、drawdownを67%ではなく12%に抑える。そして生き延びられる成長率の44%は、生き延びられない成長率の100%に勝つ。フルケリーを計算し、その数字の25〜50%を使おう。

ケーススタディの確認問題：Lisaは利益の出る戦略（勝率68%、R:R 0.63:1、期待値は1トレードあたり+42ドル）を持ち、最適なケリー基準を1トレードあたり16.8%と計算した。彼女はフルケリーを使い、プラスのエッジがあったにもかかわらず3か月で11万4,000ドル（-62%）を失った。致命的なミスは何だったか。

A) フルケリーは成長には数学的に最適だが破滅的な分散を生む。6連敗（確率0.1%）が-67%のdrawdownを招き、何年分ものエッジを1週間で消し飛ばした
B) ケリーの計算方法が違っていた。16.8%という数字が誤りだった
C) 勝率の計算が間違っていた。68%はサンプルが小さすぎて過大評価だった
D) 1つの戦略ではなく複数の戦略に分散すべきだった
正解：A。 フル・ケリーの罠。リサの計算そのものは正しかった（成長にとって16.8%は最適だ）。だがフル・ケリーは、無限の資金と、感情がないことと、エッジが永遠に安定していることを前提にしている。現実には、6連敗（0.32^6 = 確率0.1%）が一週間で-66.8%のドローダウンを生んだ。0.832^6 = 0.332、つまり19万2,500ドルが6万4,000ドルになったのである。フル・ケリーは、エッジがプラスであっても40-70%のドローダウンを生む。彼女は1/4ケリー（4.2%）に切り替えた。同じ6連敗をその割合で走らせると0.958^6 = 0.773、ドローダウンは-22.7%（19万2,500ドルが6万4,000ドルではなく14万9,000ドル）。割合には8万5,000ドルの価値があったわけだ。ただしこの数字は、実際に起きた連敗に対する算数であって、その後いくら稼いだかという主張ではないことに注意してほしい。ケリーの割合fにおける成長率は最大値の(2f − f²)だから、クォーター・ケリーはボラティリティを四分の一にしたうえで成長率のおよそ44%を保つ。ケリーが示すのは理論上の上限であって、実務上の目標ではない。
パート3：複数の戦略にケリーを適用する

マルチ戦略ポートフォリオの配分

現実のポートフォリオに戦略は1つではない。モメンタム・ブレイクアウト、平均回帰、オプションのインカムを同時に回すこともある。

問い： エッジの異なる複数の戦略に、どう資金を配分するか。

ステップ1：各戦略のケリー%を個別に計算する

3つの戦略を持つポートフォリオの例：

手法 勝率 平均利益 平均損失 利益/損失比 フルケリー % クォーターケリー %
A：ブレイクアウト 45% $600 $200 3.0 26.7% 6.7%

合計配分（戦略が独立だった場合）：6.7% + 8.95% + 5.0% = 20.65%

ステップ2：相関を調整する

問題点： あなたの戦略が相関している（一緒に勝ち、一緒に負ける）なら、実際には同じ賭けを何度も張っていることになる。

相関係数は-1から+1までの範囲を取る。

  • +1.0: 完全な相関（常に一緒に動く）— 同じ戦略だ、配分を二重にしてはいけない
  • +0.6〜+0.8： 高い相関（しばしば一緒に動く）— 配分を30〜50%減らす
  • +0.2〜+0.4： 低い相関（ある程度独立）— 配分を10〜20%減らす
  • 0.0: 相関なし（本当に独立）— 調整は不要
  • -0.5〜-1.0： 負の相関（逆方向に動く）— 合計配分を増やせる（ヘッジが効いている）
戦略間の相関を計算する方法（Excel/Python）

Excel： 日次のP&Lを列に書き出す（日付、戦略A、戦略B）。そして =CORREL(B:B, C:C) で相関係数を出す。

Python： df[['Strategy_A', 'Strategy_B']].corr() で相関行列が得られる。

読み方： 0.15 = ほぼ独立 ✅。0.60 = 重なりが大きい ⚠️（配分を減らす）。0.05 = 独立 ✅。

ステップ3：相関の調整を適用する

3戦略の例を続けて、次の相関を仮定しよう。

  • 戦略AとB：0.15（低い相関）
  • 戦略BとC：0.60（高い相関）⚠️
  • 戦略AとC：0.05（独立）

調整ルール： 相関したペアの配分を30%減らす（相関0.60の場合）

手法 クォーターケリー % 相関の問題 調整後の配分
A：ブレイクアウト 6.7% なし（独立） 6.7%（変更なし）
B：平均回帰 8.95% Cと0.60 8.95% × 0.70 = 6.27%
C：ボラティリティ 5.0% Bと0.60 5.0% × 0.70 = 3.5%

新しい合計配分：6.7% + 6.27% + 3.5% = 16.47%

結果： BとCの相関を織り込むため、20.65%から16.47%へ引き下げた。これで、その2つが一緒に負けたときの過度な集中を防げる。

⚠️ 「分散しているという錯覚」の罠

多くのトレーダーは「株、暗号資産、為替」を扱っているから分散できていると思い込む。しかし3つともリスクオン資産であり、FRBがタカ派になれば一緒に崩れる。

  • ロングのブレイクアウト（QE下の強気相場で稼ぐ）
  • ショートのフェード（QT下の弱気相場で稼ぐ）

  • ボラティリティ売り（VIXが急騰して崩れるときに稼ぐ）

ステップ4：ポートフォリオ負荷の上限を決める

ポートフォリオ負荷 ＝ 同時に持つ全ポジションのリスク合計

個人トレーダーの標準： ポートフォリオ全体の負荷は6％を決して超えないこと。多くの場所で引用される10〜15％という数字は機関投資家のデスクの上限であり — トレーダー種別ごとの幅はレッスン46にある — そこにはあなたが持っていないヘッジと自己資本の厚みが前提になっている。

例：

  • 戦略A：ポジション1つ、口座の1.0％をリスクにさらす → 負荷1.0％
  • 戦略B：ポジション2つ、それぞれ1.0％をリスクにさらす → 負荷2.0％
  • 戦略C：ポジション1つ、1.5％をリスクにさらす → 負荷1.5％

ポートフォリオ全体の負荷：1.0％ + 2.0％ + 1.5％ = 4.5％ — 上限の内側で、1％のポジションをもう1つ入れる余地がある。負荷とは何かを押さえておこう：すべてのストップが同時に刺さったときに失う金額であって、割り当てた資金のことではない。ある戦略に6.7％を配分していても、その建玉で1％しかリスクを取っていないなら、負荷は1％であって6.7％ではない。

どこで壊れるか： 1.5％のポジションをさらに4つ足すと、負荷は10.5％に達する。これは個人向けの上限を超えているし、その銘柄同士が相関しているなら、算術が示すより悪い。まとめてストップに刺さるからだ。負荷が6％を下回るまで、新しいトレードは取らないこと。

パート4：動的なポジションサイズ

固定比率と動的ケリー

固定比率： 常に同じ%をリスクに晒す（例：1トレードあたり1%）

動的ケリー： 直近のパフォーマンスに応じてサイズを調整する

資産曲線でトレードする

考え方： 勝っているときはサイズを上げ、負けているときは下げる

やり方：

  • 資産曲線の20日移動平均を計算する
  • 資産曲線が移動平均を上回っていればポジションサイズを25%増やす（読み方は「エッジが機能している」）。ただし、これが依拠している前提に注意してほしい。このレッスンはすでにそれに反論している。20日間の資産平均は、第1部が「勝率を50〜70%より細かくは決められない」と述べた100トレードよりもさらに小さいサンプルだ。トレードが独立なら、その平均の上にいるか下にいるかは次の一回について何の情報も持たない。そしてこのルールが確実に保証するのは、回復局面であなたが小さいままになることのほうである。ドローダウンのせいで自分の取引が乱れるなら使えばいい——それは本物の理由であり、エッジについてではなく、あなたについての言明だ
  • 資産 < 移動平均なら：ポジションサイズを50%減らす（エッジが壊れたかレジームが変わった）

利点： リスクをパフォーマンスに自動で合わせる（勝ちを複利で伸ばし、負けを抑える）

例：資産曲線によるサイズ調整

基準： 口座10万ドル、リスク1% = 1トレードあたり1,000ドル。 好調期（資産 > 移動平均）： 口座10万8,000ドル、リスク1.25% = 1トレードあたり1,350ドル。 不調期（資産 < 移動平均）： 口座9万7,000ドル、リスク0.5% = 1トレードあたり485ドル。勝っているときは多く、負けているときは少なくリスクを取る。

機能： すべての稼働中の戦略を同じチャート上で可視化する（相関を見つけるため）

⚡ 明日からできること（クリックで展開）

まずはこの3つから：

  1. いちばん良い戦略のケリー%を計算する。必要な数字は3つ。(1)勝率（勝ちトレード ÷ 全トレード）、(2)平均利益、(3)平均損失。式は、ケリー % = (勝率 × (平均利益 ÷ 平均損失) - (1-勝率)) ÷ (平均利益 ÷ 平均損失)。例：勝率58.3%、平均利益360ドル、平均損失200ドルなら、フル・ケリーは35.1%。1/4ケリー、つまり1トレードあたり8.8%を使うこと。エド・ソープは二十年にわたり、フラクショナル・ケリーでプリンストン・ニューポート・パートナーズを手数料控除後で年およそ15%で運用した。

あなたのシステムはこうだ：勝率60%、平均利益400ドル、平均損失200ドル。正しいケリー%はいくらで、実際には1トレードでいくらリスクを取るべきか。

正解：B。 ケリーの計算：p=0.6、q=0.4、b=400ドル/200ドル=2.0。式：f* = (0.6 × 2.0 - 0.4) / 2.0 = 0.8 / 2.0 = 0.4 = フルケリー40%。しかしフルケリーは5連敗で92%のdrawdownになる（0.60^5は口座の7.8%しか残さない）。クォーターケリー（10%）なら同じ連敗で41%のdrawdown（0.90^5は59%を残す）で、生き延びられる。フルケリー：1トレード4万ドルのリスク、5連敗で残り7,800ドル。クォーターケリー：1トレード1万ドルのリスク、5連敗で残り5万9,000ドル。クォーターケリーは理論上の成長率のおよそ44%を取り込み — f = 0.25における(2f − f²) — フルケリーの70%超ではなく10〜20%のdrawdownで済む。

あなたは3つの戦略を持ち、フルケリー%はそれぞれ：戦略A = 20%、戦略B = 25%、戦略C = 30%。3つの平均相関は0.80。ポートフォリオ全体の配分はいくらになるか。

B) 合計18.75%（それぞれクォーターケリー：5% + 6.25% + 7.5%、相関の調整なし）

B) 何もしない — 資産曲線でのトレードは疑似科学だ、固定2%のままでいい
C) 資産が回復するまで完全に取引をやめる — これは連敗だ
正解：A。 資産が20日移動平均を下回る＝平均以下のパフォーマンス。原因は分散かもしれないし、レジームの変化かもしれないし、執行の悪さかもしれない。どれであっても答えは同じだ。リスクを減らすこと。資産が移動平均を上抜けるまでサイズを半分（2% → 1%）にする。10連敗で計算してみよう。固定2%なら0.98^10 = 0.817、つまり10万ドル → 8万1,700ドル（-18.3%）。資産曲線でサイズを決めるなら、2%で2回負け、資産が移動平均を割った時点から残り8回は1%にする。0.98² × 0.99^8 = 0.886、つまり10万ドル → 8万8,600ドル（-11.4%）。同じ連敗で被害はおよそ38%少なく、しかもエッジが働いていない可能性がもっとも高いときに小さく張っている。ルール：移動平均より下ならサイズ半分。上なら通常サイズ。大きく上なら25%増し。

ポートフォリオ構築の手順：

  • 各戦略をbacktestする：勝率と利益/損失比を計算する
  • 各戦略のケリー%を計算する（クォーターまたはハーフケリーを使う）
  • 戦略間の相関を特定する（一緒に勝ち、一緒に負けるか）
  • 相関が高い戦略への配分を減らす（相関 >0.6）
  • ポートフォリオ全体の負荷は6％で頭打ちにする — そして配分と負荷は別物だと忘れないこと
  • 資産曲線の追跡を導入する（20日移動平均）
  • 資産と移動平均の関係でサイズを調整する（上なら増やし、下なら減らす）

トレード前のケリー・チェック：

  • このセットアップがどの戦略に属するかを特定する
  • その戦略の残りの配分を確認する（ケリーの上限に達していないか）
  • ポートフォリオ・ヒートを確認する。建玉すべてを合わせたリスクは、自分の上限6%の内側に収まっているか。
  • Signal PilotのPentarch Pilot Lineでエッジを確認する（機関投資家のフローは同じ方向か）
  • エッジが確認できたらフル（クォーター/ハーフ）ケリーを使う。確認できなければ0.5×ケリーか見送り

要点

  • ケリー基準はサイズを数学的に最適化する エッジ（勝率 × 利益/損失比）に基づいて
  • フルケリーは絶対に使わない （ボラティリティが高すぎる）— 0.25〜0.5×ケリーを使う
  • 相関は重要だ： 相関した戦略への配分を減らす（それらは同じ賭けだ）
  • 動的サイジング は直近の成績に応じてリスクを増減させる。持つ価値があるのは、ドローダウンが自分の取引の質を変えてしまう場合だけだ。トレードが独立なら期待値は増えず、回復局面で小さいままにされるだけになる
  • ポートフォリオ負荷の上限： 個人口座なら、すべての建玉を合わせた総リスクで6%。ほぼどこでも引かれる10〜15%という数字は機関のデスク向けの上限であり、あなたが持っていないヘッジとバランスシートの厚みを前提にしている
  • 自信過剰は命取り： 勝率60% + R:R 2:1 = フルケリー40%。7連敗（0.4^7 ≈ 0.16%の確率、およそ600トレードに1回）はフルケリーなら-97%、クォーターケリーでも-52%まで沈める。ケリーが示すのは天井であって目標ではない。多くのプロはクォーターケリーよりかなり低く張り、その上で総負荷にも上限を置く。

ケリー基準は数学を与え、分数ケリーは生存を与える。破産リスクなしに着実に増えるポートフォリオを組もう。
