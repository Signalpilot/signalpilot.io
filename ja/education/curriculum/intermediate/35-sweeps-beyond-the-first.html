1回目のスイープ：100ドル → 99.50ドル → 100.50ドル。あなたは買いで入る。ストップに刈られる。

2回目のスイープ：同じ水準。100ドル → 99.00ドル → 102.50ドル。

1回目で刈られたあなたは、2回目の上昇を置いてけぼりで眺めることになる。

🚨 本音を言えば

1回目のスイープが外れると、たいていのトレーダーはあきらめる。Janusは「効かない」と思い込む。

だが、彼らが知らないことがある。 損切りが置かれているのは二度目のスイープのほうです。 1回目のスイープは、目に見えるストップを刈っただけ。では2回目は？そこで機関投資家が仕込んでいる。

スイープを数えていなければ、餌と入り口の区別がつきません。

このレッスンで学ぶこと：

  • なぜダブルスイープはシングルスイープを圧倒するのか（そして見分け方）
  • 複数時間軸にまたがるスイープの重なり（桁違いの流動性狩り）
  • 「スイープからの回復」のパターン（反転の即時確認）
  • 失敗したスイープ（そして逆方向へどう取るか）
  • スイープで振り落とされた動きを基準に測ったRの倍数が見返りではない理由と、2度目のスイープを耐えるところまで損切りを広げると何がかかるのか

パート1：応用的なスイープのパターン
📖 さらに詳しく：どのトレードの前にも問うべき3つの問い →

パターン1：ダブルスイープ（最も多くの損切りを拾う型）

場面： 価格は反転する前に、流動性の水準を2度刈っていく。機関投資家には、1回のスイープで得られる以上の流動性が要る。

🎯 ダブルスイープの仕組み

流れ：

  1. 1回目のスイープ：100ドル → 99.50ドル（目に見えるストップを刈る）
  2. だましの反発：99.50ドル → 100.80ドル（新しい買い手を誘い込む）
  3. 2回目のスイープ：100.80ドル → 98.80ドル（1回目で入った建玉と新しいストップを刈る）
  4. 本当の反転：98.80ドル → 103ドル超（機関投資家は仕込み終え、動きが始まる）

なぜ機能するのか： 2回目のスイープは、1回だけの場合より2〜3倍の流動性を集める。機関投資家には大きな数量が要り、それを与えるのが2回目だ。

見分け方：

  • Janusが同じ重なりの帯で両方のスイープを示す
  • 2回目のスイープは、たいてい1回目より0.5〜1 ATR深い
  • Plutusを見る：二度目のスイープでデルタが+8K以上なら、その流動性は買われたのであって、水準がただ崩れたのではありません
  • スイープ同士の間隔：5〜30本のローソク足（5分足〜1時間足）

執行：

  • エントリー： 2回目のスイープのあと、出来高を伴って1回目の水準を上抜けるのを待つ
  • ストップ： 2回目のスイープ帯の下（2つのスイープの間ではない）
  • 目標： 次の構造の水準まで2〜4R
  • フィルターが与えてくれるもの： HTFのトレンドが一致していること、order flowの裏づけがあることを条件にすると、トレンドに逆らって起きるスイープが落ちます。この型が崩れるのは、まさにそこです。勝率を掲げるつもりはありません

パターン2：複数時間軸のスイープの重なり

場面： HTFとLTFのスイープが同じ価格帯で起きるということです。4時間足と15分足の損切りの塊を一度にさらう流動性の取り込みです。それがどれだけの規模なのかは外からは見えませんし、そこに数字を置けばそれは作り話になります。

🎯 HTF／LTFの重なりの組み立て

例：

  • 4時間足：5,000ドルに主要なサポート（当日安値、VWAPの起点）
  • 15分足：4,998ドルにLTFのスイング安値
  • スイープ帯：4,995〜4,997ドル（両方の時間軸を刈る）

なぜ強力なのか： 機関投資家はHTFのストップ（大口）とLTFのストップ（個人）をまとめて刈る＝ひとつの価格に流動性が最大化する

執行：

  • エントリー： HTFでの回復と、LTFでの出来高急増（両方の時間軸が転換した確認）
  • ストップ： スイープ帯の下（例：4,990ドル）
  • 目標： HTFの目標（例：5,080ドルのレジスタンス）＝3〜5R
パート2：執行の枠組み

枠組み1：スイープからの回復で入る

🎯 回復を確認するルール

基本の考え方： スイープだけではトレードのシグナルにならない。出来高を伴う回復こそが確認になる。

エントリーの条件：

  1. サポート下へのJanusのスイープ（例：100ドル → 99.40ドル）
  2. 価格が刈られた水準を取り戻す（再び100ドルの上へ）
  3. 回復の足の出来高 > 平均の1.5倍
  4. Plutusがプラスのデルタを示す（最低+5K）
  5. HTFのトレンドが方向を支える（買いなら4時間足が上昇トレンド）

執行：

  • エントリー： 100.20ドル（回復の上、例）
  • ストップ： 99.20ドル（スイープの下）
  • 目標： 103.50ドル（次のレジスタンス）＝3.3R
  • 時間の区切り： 5本以内に回復がなければ、そのセットアップは無効

これが上位に来る理由： リクレイムは、すでに起きた確認です。反転を予想するのではなく、示されるのを待つ。その代わり、入り値は悪くなります。

枠組み2：失敗したスイープを逆に取る

🎯 スイープのあとに回復が来ないとき

場面： スイープは起きたのに回復がない＝買い手あるいは売り手が弱い。逆方向にトレードする。

条件：

  1. 100ドルを割って99.50ドルまでスイープ
  2. 5本以内に回復がまったくない
  3. Plutusが売りの継続を示す（デルタ−3K以上）
  4. 価格がスイープの安値（99.50ドル）を下抜ける

執行：

  • エントリー： 99.20ドル（下抜け確認）
  • ストップ： 100.50ドル（失敗したスイープと構造の上）
  • 目標： 96.50ドル（次のサポート）＝2.1R

位置づけ： スイープ＆リクレイムより弱い。リクレイムがあることではなく、続きがないことを取引しているからです。

枠組み3：失敗したスイープからの継続

🎯 スイープが反転しないとき

条件：

  1. 100ドルを割って99.50ドルまでスイープ
  2. 5本以内に回復がまったくない
  3. 98.50ドルまで下げが続く（下抜け）
  4. Janusが失敗したスイープを示す
  5. HTFの下降トレンドが下抜けを支える

執行：

  • エントリー例： 98.30ドル（下抜け確認）
  • ストップ例： 99.80ドル（失敗したスイープの上）
  • 想定される目標： 95.00ドル（次のサポート）＝2.2R

位置づけ： 三つのうち最も弱い。スイープが失敗したのだから水準は本当に失われた、という賭けです。しかし水準は、本当に失われていても跳ね返ることがあります。

パート3：Janusを他のインジケーターと組み合わせる
Janus ＋ Plutus Flow （完璧な組み合わせ）

スイープ＋吸収： 流動性が取られ、そしてそれを誰かが買った

  • 100ドルでのJanusのスイープ
  • Plutusがスイープでプラスのデルタを示す（+8,000）
  • 結果：強い買い手が売りを吸収 → 上向きの反転が示された

スイープ＋枯渇： 失敗したスイープの公算が大きい

  • 100ドルでのJanusのスイープ
  • Plutusがマイナスのデルタを示す（売りが優勢）
  • 結果：吸収なし → 下抜けの公算が大きい
Janus ＋ Volume Oracle （相場の状態との整合）

スイープ＋トレンド状態： 押し目のスイープをトレンドに沿って取る

  • HTFが上昇トレンド
  • サポートでのJanusのスイープ
  • プロなら回復のところで買いを検討するかもしれない

スイープ＋レンジ状態： 両端を逆に取る

  • HTFがレンジ
  • レンジ下限でのJanusのスイープ
  • レンジの中央や上限へ戻すのを取る
Janus ＋ Harmonic Oscillator （極端な場面での確認）

スイープ＋売られすぎ（7/7の一致）： 互いに無関係な二つの方法が同じ方向を指している

  • Harmonicが売られすぎで7/7の一致を示す
  • サポートでのJanusのスイープ
  • 結果：この道具立てがロングについて与えられる、独立した一致としては最大のもの

スイープ＋ダイバージェンス： 追加の確認

  • 価格は安値を切り下げ、デルタは安値を切り上げる（ダイバージェンス）
  • ダイバージェンスの水準でのJanusのスイープ
  • 結果：三重の重なり（スイープ＋ダイバージェンス＋ハーモニック）

⚠️ Janusでよくある失敗

失敗1：スイープのたびにトレードする

「Janusがスイープを出した、すぐ入るぞ！」

改善策： 回復と出来高、そしてorder flowの確認を条件にする。すべてのスイープが反転するわけではない。

失敗2：失敗したスイープを無視する

スイープが回復しなかったのに買いを持ち続ける。

改善策： 5本以内に回復がなければ手仕舞う。逆方向のトレード（売り）を検討する。

失敗3：スイープのあとHTFに逆らう

LTFの反転で買うが、HTFは下降トレンド。

改善策： HTFの方向と一致するスイープだけをトレードする。トレンドに逆らわないこと。

📉 ケーススタディ：ジョーダンがシングルスイープの罠で失った6万4,000ドル（6か月）

トレーダー： ジョーダン・ウィリアムズ（複合的な事例）、33歳、スイングトレーダー（Janus Atlas歴2年、口座資金10万8,000ドル）、2023年4〜10月

戦略： 流動性狩りの直後、1回目のスイープをすぐ取っていた。2023年1〜3月：勝率66％、+1万4,800ドル、基本のパターン（スイープ → エントリー → 反転）で。

致命的な欠陥： 理解していたのは、シングルスイープの基本パターンだけ。2回目を待ったことは一度もなかった。荒れた相場で機関投資家が使うのはダブルスイープだ。1回目で目に見えるストップを刈り、2回目で早く入った買い手を刈り、それから本当の動きが来る。ジョーダンは毎回1回目のスイープのあとに入り、2回目の燃料になっていた

結果： 54回の取引、勝ち7回、64,000ドルの損失（-59%）。彼は、自分が刈られたあとに走った値動きの一覧も付けていました。その欄は疑ってかかってください。どの建玉も最後まで持ち続けていたはずだ、という前提が入っているからです。そしてそれは、刈られたトレーダーがいちばん置きたがる前提です。64,000ドルは実際に起きたこと。残りは、彼が自分に語っていることです。

そのパターン（54トレード中47回、87％）： 1回目のスイープ → ジョーダンが入る → 小さな反発（10〜30分の手応え） → 2回目のスイープに刈られる → 大きな動きは彼を置いて進む。例：(1) 4月3日 NVDA：サポート270ドル、1回目のスイープ268.50ドル、エントリー269.20ドル、ストップ268ドル。271.40ドルまで反発。2回目のスイープ267.20ドルで刈られる。NVDAは278.60ドルまで急騰。9ドル超の値幅を逃し、600ドルの損失。(2) 5月8日 BTC：サポート2万7,000ドル、1回目のスイープ2万6,750ドル、エントリー2万6,850ドル、ストップ2万6,600ドル。2万7,400ドルまで上昇。2回目のスイープ2万6,350ドルで刈られる。BTCは2万8,800ドルまで爆発。2,000ドル超の値幅を逃し、1,250ドルの損失。(3) 7月10日 AMD：サポート110ドル、1回目のスイープ108.50ドル（50％）、2回目のスイープ107.80ドル（さらに50％）、そして3回目のスイープ106.50ドルで両方とも刈られた。AMDは116.80ドルまで上げ、1,800ドルの損失。限界を迎えた日（8月21日）：「54回のうち47回が、まったく同じ形をなぞっていた。基本のパターンは分かっていたが、応用が分かっていなかった。1回目のスイープ → だましの反発 → 2回目のスイープ → 本当の反転。おれは狩る側ではなく、流動性そのものだった」

📈 彼の記録がうまくいくはずだったのに、いかなかった理由

挙げられている株とクリプトの例は、どちらも入り、損切り、2度目のスイープを備えているので、位置関係を測れます。それぞれ1回ずつ計算してみましょう。

                        入り        損切り     リスク   2度目      損切りの先
NVDA      269.20ドル 268.00ドル  1.20ドル  267.20ドル   0.80ドル
BTC       26,850ドル 26,600ドル   250ドル  26,350ドル    250ドル

彼が挙げた動きを、彼自身のリスク単位で
NVDA      278.60 - 269.20  =  9.40ドル   /  1.20ドル  =  7.8R
BTC       28,800 - 26,850  =  1,950ドル  /   250ドル  =  7.8R

7.8対1での損益分岐   1 / (1 + 7.8)  =  11.3%
彼の実際の勝率                          13%

最後の2行をもう一度読んでください。おかしなことを言っているからです。紙の上では、この記録は わずかに黒字です。 7.8対1で勝率13%なら損益分岐を上回っています。それでも彼は口座の59%を失いました。

この2つの事実は矛盾していません。そして矛盾しない理由が、このレッスンのすべてです。7.8Rは、彼が乗っていなかった動きを基準に測られています。値が付く前にスイープで振り落とされた目標から計算したRの倍数は、見返りではありません。チャートの説明です。彼が実際にいくら受け取ったのかを教えてくれるのは7回の勝ちのほうで、それが何であれ、7.8Rではありませんでした。

では、直し方に値段をつけましょう。ただではないからです。2度目のスイープを耐える損切りは、その上ではなく下に置かれます。

NVDA   損切り 267.00ドル  リスク 2.20ドル   9.40 / 2.20  =  4.3R
BTC    損切り 26,300ドル  リスク  550ドル   1,950 / 550  =  3.5R

4.3対1での損益分岐    1 / (1 + 4.3)  =  19.0%
3.5対1での損益分岐    1 / (1 + 3.5)  =  22.0%

つまり広い損切りは距離をおよそ倍にし、ドル建てのリスクを一定にすれば建玉を半分にし、見返りを7.8から4程度まで落とします。その結果、必要な勝率は11%からおよそ20%に上がります。これがダブルスイープの規則が越えなければならない基準であり、彼の記録はそれを越えているかどうかを教えてくれません。54回の負けのうち47回が同じ壊れ方を共有していることは、余地があると言っています。彼がそこに届くとは言っていません。

立て直し（2023年10月〜2024年3月）： ダブルスイープの新しい手順：(1) まず相場つきを確かめる（トレンド相場なら一度目のスイープでも可、レンジなら二度目を待つ）。(2) 荒れた相場では二度目のスイープを待つ（一度目よりATRの0.5〜1倍深いもの）。(3) HTFとLTFの重なりを要求する（両方の時間軸が同じ価格に流動性を示していること）。(4) 二度目のスイープでフットプリントに+10K以上のデルタのアブソープションを確認する。(5) ストップは二度目のスイープの下（あいだではない）。(6) 取るセットアップの数を大きく減らす。変わったことは、たった一つの数字で測れます。以前は54回取っていたところを23回にした、つまりエントリーが60%減ったということです。その期間の勝率も利益も口座残高も書きません。23回の取引ではフィルターは測れませんし、そのフィルターこそが変化のすべてです。彼はチャートを上手に読むようになったのではなく、より多くを断るようになったのです。

ジョーダンの学び： 「一度目のスイープで入り、二度目のスイープに刈られること47回（87%）で、64,000ドルを失いました。基本のJanus（スイープ→反転）は分かっていましたが、荒れた相場での応用形が分かっていませんでした。一度目のスイープが分かりやすい損切りを刈る → ダマシの戻りが新しい損切りを作る → 二度目のスイープが両方の層をさらう → そこから本物の動きが始まる。私はダマシの戻りで入り、二度目のスイープの燃料に「なって」いたのです。NVDAは一度目が268.50ドル（私は269.20ドルで入りました）、二度目の267.20ドルで刈られ、その後278.60ドルまで。BTCは一度目が26,750ドル（26,850ドルで入りました）、二度目の26,350ドルで刈られ、その後28,800ドルまで。47回です。今はレンジ相場では二度目のスイープを待ちます。HTFとLTFの重なり。スイープでの+10Kのデルタのアブソープション。取るセットアップの数は以前よりずっと減りました。取っているものが良いのかどうかは、まだ分かりません。分かっているのは、自分から燃料になるのをやめたということだけです。荒れた相場では、二度目のスイープが本当の入り口です。早すぎるというのは、間違っていることの一つの形です。」

ケーススタディの確認問題：ジョーダンはJanusのスイープを取って6か月で6万4,000ドル（−59％）を失い、勝率はわずか13％だった。彼のパターン（54トレード中47回、87％）：1回目のスイープ → 入る → 小さな反発で手応えを感じる → 2回目のスイープに刈られる → 大きな動きは彼を置いて進む。例：NVDAは1回目のスイープ268.50ドル（エントリー269.20ドル）、271.40ドルまで反発（「効いている！」）、2回目のスイープ267.20ドルで刈られ、NVDAは278.60ドルまで急騰（9ドル超の値幅を逃した）。BTCは1回目のスイープ2万6,750ドル（エントリー2万6,850ドル）、2万7,400ドルまで上昇、2回目のスイープ2万6,350ドルで刈られ、BTCは2万8,800ドルまで爆発（2,000ドル超の値幅を逃した）。以前の好成績（勝率66％、+1万4,800ドル）は、基本のシングルスイープで得たものだった。ジョーダンの致命的な過ちはどれか。

A）ストップが近すぎた（1回目のスイープの外側まで広げるべきだった）
B）理解していたのはシングルスイープの基本パターンだけだった。2回目を待ったことが一度もなかった。荒れた相場で機関投資家が使うのはダブルスイープで、1回目で目に見えるストップを刈り、2回目で反発に乗った早い買い手を刈り、それから本当の動きが始まる
C）取引回数が多すぎた（6か月で54回——もっと勝率の高いセットアップを待つべきだった）
D）スイープの地点で出来高の確認をしていなかった（平均の3倍を条件にするべきだった）

正解：B。 ジョーダンの惨事は、基本のJanus（スイープ → 反転）だけを理解し、荒れた相場での応用であるダブルスイープを見抜けなかったことにある。基本はトレンドでは通用する。スイープが1回あり、反転が始まる。ところが荒れた相場では、機関投資家は流動性を2つの層で狩る。1回目のスイープ（268.50ドル）が個人の目に見えるストップを刈る。そこで反発が生まれる。ジョーダンは反転が始まったと思って入る。だがその反発は、早く入った買い手の新しいストップを生む。2回目のスイープ（267.20ドル）が、もとのストップと早いエントリーのストップをまとめてさらう。ジョーダンは2回目の燃料になる。そこでようやく本当の反転が始まる（278.60ドル）が、彼はもう刈られている。これが54回中47回（87％）で彼を壊した。BTCの例：1回目のスイープ2万6,750ドル → ジョーダンは2万6,850ドルで入る → 2万7,400ドルまで上昇（手応え） → 2回目のスイープ2万6,350ドルで刈られる → BTCは2万8,800ドルまで爆発。1,250ドルを失い、2,000ドルの値幅を逃した。6万4,000ドルの損失は、実際に起きた部分です。その横に積み上げていた「逸失利益」のほうは、どの値動きも最後まで持ち続けていたはずだ、という前提の上に成り立っています。刈られたトレーダーに、それを正直に主張することはできません。立て直し：(1) 相場の状態を確認する（トレンドなら1回目でよい、レンジなら2回目を待つ）、(2) 2回目のスイープを待つ（0.5〜1 ATR深い）、(3) HTFとLTFの重なりを条件にする、(4) +10K以上のデルタ吸収を確認する。教訓：荒れた相場では、本当のエントリーは2回目のスイープだ。1回目は餌、2回目が罠である。 この四つはどれも、エントリーを良くするのではなく、エントリーを引き算します。そこが要点です。

⚡ 明日からできること（クリックで展開）
  1. スイープを数える ——荒れた相場では一度目で入らないこと。今どの層の損切りが取られているのか分かるよう、回数をチャートに書き込んでおきます。
  2. 回復による確認を取る — スイープのあとは、価格が刈られた水準を取り戻すまで待つ。回復のないスイープはトレンド継続であって、反転ではない。
  3. スイープの向きを上位の時間軸に合わせる ——日足のサポートでの強気のスイープは、トレンドを背にしています。同じスイープでも日足の抵抗でなら、壁に向かっての反転の試みです。
理解度の確認

🎮 理解度チェック（気楽にどうぞ）

1回目のスイープ：100ドル → 99.50ドル → 100.50ドル。2回目のスイープ：100ドル → 99.00ドル → 100.30ドル。フットプリントは99.00ドルで+10kのデルタを示している。ここでのトレードは？

A) ロング——ダブルスイープとアブソープション。ここで得られる最大の一致
B）見送る——1回目のスイープで一度失敗している
C）売り——サポートは明らかに割れている
Aが正解の理由： これは、同時に一致している要素がいちばん多い形です。 ダブルスイープがすべてのストップを刈った（1回目のスイープに加え、反発で早く入った買い手も）。+10kのデルタは大きな吸収だ。エントリー例：100.40ドル、ストップ：98.80ドル、ターゲット：HTFのレジスタンス。 確率は付けません。98.80ドルの下にストップがあるのは、二度のスイープと大きなデルタのあとに、三度目のスイープが来ることがあるからです。

99.50ドルまでのスイープ。5本以内に回復なし。価格は98.50ドルまで下げ続ける。このシグナルは？

A）回復を待つ——時間がかかっているだけだ
B）失敗したスイープ——下抜けが確認できれば売りを検討しうる
C）手を出さない——シグナルが噛み合っていない
Bが正解の理由： 5本のローソク足のあいだに奪還がなければ、スイープの失敗です。サポートは本当に割れています。98.30ドルでのショート、ストップ99.80ドル、次のサポートを目標にする——それがこの型の描くトレードです。確率は付けません。この枠組み自身が言うとおり、これは三つのなかで最も弱い形です。水準は本当に失われていても、なお跳ね返ってくることがあるからです。

あなたはESの先物を見ている。日足は5,000ドルにサポートを示す（当日安値）。15分足は5,002ドルにスイング安値を示す。価格は4,997ドルまでスイープしたあと、出来高2.5倍とフットプリントの+12Kデルタを伴って5,005ドルを取り戻した。HTFは上昇トレンド。あなたのトレードは？

A）見送る——価格は両方のサポートを割った。下降トレンドが確定した
B）パターンを確かめるため、2回目のスイープを待つ
C) 積極的にロング——複数時間軸のスイープの重なり、強い奪還、アブソープション、HTFのトレンド。四つが同時に一致している
Cが正解の理由： これは絶好の場面だ。時間軸をまたいだ重なり（日足と15分足が同じ帯で刈られた）が、桁違いの流動性をさらった。出来高2.5倍で両方の水準を上抜けた回復が、反転を裏づける。+12Kのデルタは機関投資家の吸収だ。HTFの上昇トレンドが買いの方向を支える。この形に勝率は書きません。過去のものであれ何であれ、名に値する標本でこれを測った人はいませんし、教材のために作った数字は、数字がないことより悪いからです。言えるのは、独立した四つのことが一致しなければならなかったということ、そしてこの方法が生み出せるのはそこまでだということです。エントリー：5,008ドル、ストップ：4,990ドル（スイープの下）、ターゲット：次のレジスタンス5,080ドル以上＝最低4R。完璧な場面で考えすぎないこと——重なりを待つのは、まさにこのためだ。

ここで効いてくる区別は小さく、実行にほとんど手間がかかりません。反転が始まったと決める前に、スイープを数えること。本物の反転に早すぎたのと、単に間違っていたのとは、最初の三十分は見分けがつきません。

🎯 練習：先週のスイープを分類する（クリックで開きます）

すでに見たことのあるチャートを三度なぞります。あとから型に名前を付けられることが、それを実況で見つけるための前提です。

  1. 先週のスイープを1枚のチャートに印を付ける — 直前の高値や安値を取ってすぐ反転したセッションをすべて探します。水準を取り返したかどうか、そこまでにどれくらいかかったかを記録しましょう。
  2. そのうち5つを分類する — ダブルスイープ、マルチタイムフレームのコンフルエンス、失敗スイープのフェード、失敗スイープの継続。後から型を言えることが、ライブで見つけられるための前提です。
  3. 自分のリクレイム条件を書き出す — 何をもってリクレイムとするか（水準を超えた終値か、決めた本数のバーか）を先に決めておき、足が動いている最中に判断せずに済むようにします。

🎓 重要ポイント

  • ダブルスイープは二層の損切りをさらう ——分かりやすいものと、そして一度目のスイープを取引した人たちが置いたもの。だから待つ値打ちがあるのであって、確率の話ではありません
  • 時間軸をまたぐコンフルエンスが、意味のある水準を示す — 日足と日中足が同じゾーンをさらったなら、そこの流動性は取りにいく価値があった
  • スイープ・アンド・リクレイムにはリクレイムが要る — スイープ単体はエントリーではなく、水準を抜け返す動きこそがエントリー
  • 失敗したスイープはフェードすることも、継続することもある — どちらになるかは、価格がレンジ内への復帰を受け入れるか拒むかで決まる
  • 振り落とされたRの倍数は見返りではない — ジョーダンが挙げた取引は、彼自身の損切りから測れば7.8対1で、勝率13%なら損益分岐を上回っています。それでも口座の59%を失いました。その目標は、はじめから彼のものではなかったのです
  • 2度目のスイープの下に置く損切りは、見返りのおよそ半分を代金にする — 7.8対1がおよそ4対1になるので、出さなければならない勝率は11%からおよそ20%へ上がります。待つことはただではなく、別の取引になるということです
  • 流動性イベントを待ち、その反応を取引する — 先回りするのではなく
