アジアセッションのレンジ。ロンドンのスイープ。ニューヨークの反転。これが循環であり、自分がそのどこにいるかを知っているかどうかで、7時にすることが変わります。

東部時間の2時と8時と14時で同じ戦略を回していたら、負けます。市場はどのセッションが動いているかで、まったく違う振る舞いをします。

このレッスンでは、機関投資家が時間帯をまたいで価格を動かすために使う、セッション別の流動性戦略の取引を学びます。

🎯 習得すること

  • スイープそのものではなくスイープ後の反転を取引する理由と、セッションの重なりが最良の流動性を与える時間帯

パート1：セッション別の流動性を理解する

3つのセッションという構造

世界の市場は週5日24時間、アジア・ロンドン・ニューヨークという3つの大きなセッションで動いています。それぞれ参加者も、出来高の性質も、機関投資家の振る舞いも異なります。

セッションが重要な理由

機関投資家はでたらめに取引しません。彼らが従うのは セッション流動性のサイクル:

  1. アジアセッション がレンジを作る（低出来高、保ち合い）
  2. ロンドンセッション がそのレンジをスイープする（高出来高、流動性の刈り取り）
  3. ニューヨークセッション がロンドンの動きを確認するか反転させる（最大の出来高、トレンド継続か反転）

このサイクルを理解すれば、機関投資家の手を 事前に 読めるようになります。

日々の流動性サイクル

例：典型的な一日のEUR/USD

  • アジアセッション（東部時間19時〜2時）： 価格は1.0500〜1.0520で保ち合い（20 pipsのレンジ）
  • ロンドンの寄り付き（東部時間3時）： 価格は1.0500を割って1.0495までスイープし、損切りを誘発
  • ロンドンの継続（東部時間3時〜5時）： 1.0535まで鋭く反転（流動性の刈り取り完了）
  • ニューヨークの寄り付き（東部時間9時30分）： 上昇を確認 → 1.0560まで上伸、あるいは否定 → 1.0510まで戻す

型はこうです： アジアレンジ → ロンドンのスイープ → ニューヨークの確認。これが為替でも指数でも商品でも探す形です。きれいに出る日もあります。片方の脚がついに来ない日もたくさんあり、それを早いうちに見抜いて見送るのが腕の見せどころです。

セッション取引の4つの局面

24時間のサイクルはどれもこの構造をとります：

局面1：アジアセッション（レンジの形成）

時間： 東部時間19時〜2時（レンジができあがる時間帯）

振る舞い： 低出来高、狭いレンジ、保ち合い

何が起きているか：

  • 米国と欧州のトレーダーは就寝中で、動いているのはアジア市場だけ
  • 流動性が薄く、値動きは小さい（為替で10〜30 pips）
  • レンジの高値と安値ができる——これが流動性プールになる
  • プロはこの水準をロンドンのスイープ目標として引いておく

トレード戦略： 暗号資産やアジア株をスキャルピングするのでない限り、アジアセッションは取引しないでください。代わりにレンジの高値と安値を引いておきます。ロンドンの時間にスイープされます。

時計についての注記： 東京は東部時間4時まで動くので、アジアセッションが19時〜4時と書かれているのも見かけます。あなたが引くレンジは狭いほうの19時〜2時です。キルゾーンが開く前に終わっている時間帯だからです。3時に付いた高値はスイープの窓の外ではなく中で作られたもので、スイープが狙っているものではなく、スイープが生み出したものになります。

例： アジアセッション中、EUR/USDは1.0800〜1.0820で保ち合います。この水準を引いておきましょう。ロンドンは反転する前に、どちらか一方（たいていは1.0800の安値）をスイープする公算が大きいです。

局面2：ロンドンの寄り付き（流動性スイープ）

時間： 東部時間2時〜5時（ロンドンのキルゾーン）

振る舞い： 高いボラティリティ、ストップ狩り、仕組まれた反転

何が起きているか：

  • ロンドンの銀行とヘッジファンドが市場に入る
  • 出来高が急増する——機関投資家が建てるのはここ
  • 価格がアジアレンジ（高値または安値）をスイープし、個人の損切りを誘発する
  • 機関投資家はその強制的な売り買いに自分の注文をぶつけて約定させる

ロンドンのキルゾーン（LKZ）戦略：

  1. アジアレンジを特定する（例：1.0800〜1.0820）
  2. ロンドンが片側をスイープするのを待つ（例：1.0800を割って1.0795へ）
  3. 反転のローソク足＋Plutus Flowの吸収を確認する
  4. 反転でロングに入る（機関投資家の仕込みは終わっている）
  5. 目標：レンジの反対側＋20〜30 pips（例：1.0850）

ツールが足してくれるもの： Janus Atlasがスイープを示し、Plutus Flowがその反転を吸収しているのか無視しているのかを見せます。どちらも勝率をくれるわけではありません。くれるのは、出来高のないスイープのときに手を出さない理由です。このセットアップが失敗する日の大半が、まさにそれです。

局面3：ロンドンとニューヨークの重複（確認）

時間： 東部時間8時〜12時

振る舞い： 一日で最も流動性が高い

何が起きているか：

  • ロンドンとニューヨークのトレーダーが同時に動いている
  • 出来高もボラティリティも最大
  • ロンドンの方向が確認されるか否定される
  • 大きなブレイクアウトや反転が起きるのはここ

重複時間帯の取引：

  • ロンドンが安値をスイープして上げたなら、9時30分の寄り付きを見る
  • ニューヨークが確認＝ロングを継続（機関投資家の足並みが揃っている）
  • ニューヨークが反転＝ロンドンの動きに逆らって取引する（機関投資家の見方が割れた）
局面4：ニューヨークの午後（勢いの減退）

時間： 東部時間12時〜16時

振る舞い： 荒れていて、確信が乏しい

何が起きているか：

  • ロンドンは閉じ、残っているのは米国のトレーダーだけ
  • 出来高が減り、レンジが縮む
  • VWAPやセッションの中値への平均回帰がよく見られる
  • 一日で最も優位性が小さい（機関投資家は建て終えている）

望ましいやり方： 数日にまたがるポジションを持つ場合を除き、東部時間14時までに手仕舞いましょう。午後の荒れ相場は、その心労に見合いません。

パート2：ロンドンのキルゾーン戦略

東部時間2時〜5時の時間帯を取引する

ロンドンのキルゾーン（LKZ）は、富が築かれ、個人の口座が壊される場所です。プロはこう取引します：

セットアップの条件

LKZセットアップの完全チェックリスト

ロンドンの前（東部時間2時まで）：

  • [ ] アジアセッションの高値を引く（19時〜2時で最も高い価格）
  • [ ] アジアセッションの安値を引く（19時〜2時で最も安い価格）
  • [ ] 上位足のバイアスを確認する（日足・4時間足のトレンド方向）
  • [ ] どちら側がスイープされそうかを見極める（同値の高値・安値があるか）
  • [ ] アジア高値＋10ティック、アジア安値−10ティックにアラートを置く

キルゾーン中（東部時間2時〜5時）：

  • [ ] スイープを見る（価格がアジア高値または安値をヒゲで抜く）
  • [ ] 出来高の急増で確認する（Plutus Flowが吸収を示す）
  • [ ] アジアレンジ内への素早い反転を待つ
  • [ ] 反転のローソク足の確定で、根拠が重なった状態で入る

LKZの3つの型

型1：アジア安値のスイープ → 上への反転

場面：

  • アジアセッションのレンジ：4500（安値）〜4540（高値）
  • ロンドンは東部時間3時00分に開く
  • 価格はただちに4495まで下げる（4500のアジア安値をスイープ）
  • Plutus Flowで出来高が急増（損切りが発動）
  • 価格は素早く4500の上へ反転する

エントリー： 4505でロング（アジア安値を取り返した上）

ストップ： 4490（スイープされた安値の下）

目標1： 4540のアジア高値（35ポイント＝2.33R）

目標2： 前日高値または4560（55ポイント＝3.67R）

なぜ機能するのか： ロンドンはアジア安値の下で流動性を取り、いまロングで建っています。あなたは彼らに逆らうのではなく、彼らと一緒に入るのです。

型2：アジア高値のスイープ → 下への反転

場面：

  • アジアセッションのレンジ：4500（安値）〜4540（高値）
  • ロンドンは東部時間3時00分に開く
  • 価格はただちに4545まで上げる（4540のアジア高値をスイープ）
  • Plutus Flowで出来高が急増（損切りが発動）
  • 価格は素早く4540の下へ反転する

エントリー： 4535でショート（アジア高値を割った下）

ストップ： 4550（スイープされた高値の上）

目標1： 4500のアジア安値（35ポイント＝2.33R）

目標2： 前日安値または4480（55ポイント＝3.67R）

型3：両側スイープ → 方向を選ぶ

場面：

  • アジアセッションのレンジ：4500〜4540
  • ロンドンはまず安値をスイープし（4495）、反転する
  • 次に高値をスイープし（4545）、反転する
  • 両側とも損切りが払われた状態になる

両側スイープの取引：

  • 最初のスイープは取引しない（撒き餌かもしれない）
  • 両方のスイープが終わったら、価格がどちら側へ寄っていくかを見る
  • 価格が4520（レンジ中央）より上で落ち着けば、ロング寄り
  • 4520より下で落ち着けば、ショート寄り
  • ニューヨークの寄り付き（9時30分）の確認で入る

注意： 両側スイープは扱いが難しいものです。ポジションを小さくし、損切りを広めに。これは上級者向けの型の見極めです。

パート3：ニューヨークの反転パターン

9時30分の寄り付き——確認か、拒否か

東部時間9時30分のニューヨークの寄り付きは、一日で最も重要な時刻です。なぜか。最大の参加者、つまり米国の機関投資家、ヘッジファンド、年金基金がこのとき入ってくるからです。

ニューヨークの寄り付きの仕組み

最初の30分（9時30分〜10時00分）

見るべきもの：

  • ニューヨークはロンドンの方向を確認しているか （上昇したロンドンのあとに上昇＝強いトレンド）
  • ニューヨークはロンドンの方向を反転させているか （上昇したロンドンのあとに下落＝罠）
  • ニューヨークは横ばいか （迷い＝はっきりするまで待つ）

見るべき重要な水準：

  • 前日の高値・安値
  • オーバーナイトの高値・安値（アジアとロンドンを合わせたもの）
  • プレマーケットのVWAP

ニューヨークの反転セットアップ

典型的な型：

  1. ロンドンがアジア安値をスイープし、4540まで上げた
  2. プレマーケット（9時00分〜9時30分）：価格は4535〜4540で保ち合う
  3. 9時30分：ニューヨークが開き、価格はただちに4530を割る
  4. 10時00分までに：価格は4500へ戻る（ロンドンの動きをすべて打ち消した）

何が起きたのか： ロンドンのスイープは罠でした。ニューヨークの機関投資家は同意しなかったのです。本当の動きは下向きです。

ニューヨークの反転を取引する

🎯 ニューヨークの反転で入るためのチェックリスト

条件：

  • ロンドンが大きく動いた（ESで30ポイント超）
  • プレマーケット（9時00分〜9時30分）が弱さを示す（ロンドンが上昇なら、切り下がる高値）
  • 9時30分の寄り付きがオーバーナイトの安値を割る（ロンドンが下落なら高値を抜く）
  • 9時30分の後の最初の5分足が、オーバーナイトのレンジの外で確定する

エントリー： 9時35分にショート（下への反転が確認できた場合）

ストップ： オーバーナイト高値の上

目標： アジア安値または前日安値

ジェイソンの3万1000ドルのセッション盲点：4か月間、間違った時間に取引し続けた

ジェイソン・ウェルズ（合成事例） ——9万5000ドルの口座と2年の経験を持つデイトレーダー。戦略：東部時間6時から10時までのES先物スキャルピング。問題：すべての時間帯を同じものとして扱っていた。

2023年10月： ジェイソンは「早い時間の動きをつかみたい」という理由で東部時間6時から取引していました。セッションを問わず、あらゆるブレイクアウト、あらゆるセットアップに手を出しました。1月には3万1200ドルの負けになっていました。

📉 ジェイソンの4か月にわたるセッションの失敗：2023年10月〜2024年1月

総トレード数 168
勝率 38%
損失合計 -31,200ドル
平均の勝ち 325ドル
平均の負け 500ドル
6時〜8時の取引 勝率24%
致命的な誤り： 168回の取引のうち72回が東部時間6時から8時、ロンドンのあとニューヨークの前に入っていて、勝ったのはそのうち17回でした。ジェイソンはCHOPゾーンで取引していたのです—ロンドンは終わり、ニューヨークはまだ始まっていない。同じセットアップ、同じルール、悪い時間帯。

📈 記録を時計で分ける

4つの数字がこの4か月を説明します。勝ち64回、負け104回、325ドル、500ドル。これで口座が再現でき、そのうえでこのケーススタディが本当に問うていることを聞けます — 原因は時間帯だったのか。

全体            勝ち64回 x 325ドル  -  負け104回 x 500ドル  =  -31,200ドル

6時〜8時のみ    勝ち17回 x 325ドル  -   負け55回 x 500ドル  =  -21,975ドル
その他の時間帯  勝ち47回 x 325ドル  -   負け49回 x 500ドル  =   -9,225ドル

これはセッションのタイミングを支持する論拠であり、しかも強い論拠です。72回の取引、記録の43%が、31,200ドルのうち21,975ドルを生みました。デッドゾーンの外では96回中47回勝っていて、これは49%です。中では72回中17回、つまり24%。同じセットアップ、同じルール、勝率は半分。

ここで最後の行をもう一度読んでください。立ち直りの物語なら省くところだからです。残る96回の取引でも9,225ドルを失っています。勝率49%では足りず、理由は時計ではなく2つの平均のほうにあります。彼はES2枚で取引していたので、500ドルの負けは5ポイント、325ドルの勝ちは3.25ポイント。20ティックのリスクで13ティックを取る形です。この比率での損益分岐は20 /（13 + 20）、つまり61%で、1日のどの時間帯でもそこには遠く及びませんでした。

ですからこのレッスンが正直に主張できるのは、狭いほうの主張です。記録を時間帯で分けると、そもそも取るべきでなかった取引が見つかります。残った取引の見返りが直るわけではありません。下のルールはジェイソンの成績表から6時〜8時の取引を外します。彼にとっては21,975ドルぶんです。いまも61%を必要とする0.65対1という見返りは、別の問題であり別のレッスンです。

📉 11月14日7時22分：荒れ相場に捕まる

セッション デッドゾーン
セットアップ ブレイクアウトのロング
結果 -1,000ドル

ESが7時22分に4,420を上抜けました。ジェイソン：「ブレイクアウトだ！」現実は、出来高なし、ロンドンは閉場、ニューヨークまで2時間以上。価格は90分にわたって4,418〜4,425を行き来し、ニューヨークの寄り付きがレンジ全体を反転させる前に、ジェイソンの損切りを2度つけました。いずれも2枚で5ポイントずつです。500ドルの損切り2回は平均の負けのちょうど2回ぶんで、この出来事はすべて7ポイントのレンジに収まりました。

🔄 立て直し：2024年2月〜6月

新しいルール：
  1. 東部時間8時30分より前は取引しない（重複時間帯の出来高を待つ）
  2. 毎朝アジアレンジを引く（スイープの目標）
  3. 9時30分の寄り付きで方向の確認を見る
  4. 11時30分で終える（昼の荒れ相場を避ける）

💡 ジェイソンの最後の教訓

「私は『なぜ』を理解せずに『いつ』を取引していました。6時から8時はデッドゾーンです。ロンドンは閉じ、ニューヨークは開いていない。同じ戦略を8時30分から11時30分に移し、誰も後ろにいない値動きにスプレッドを払うのをやめました。」

パート4：セッション別トレードの完全な枠組み

すべてを組み合わせる

日々のセッション・プレイブック

日々の手順を一つずつ

東部時間18時00分（夕方の準備）：

  • 日足を見直し、トレンド方向と重要な水準を書き留める
  • 翌日の指標について経済カレンダーを確認する
  • 前日の高値・安値を押さえる

東部時間1時30分（ロンドン前）：

  • アジアセッションの高値と安値を引く（19時〜2時のレンジ）
  • スイープのアラートを置く（レンジの外±10ティック）
  • どちら側に同値の高値・安値があるかを書き留める（スイープの標的になりやすい）

東部時間2時00分〜5時00分（ロンドンのキルゾーン）：

  • アジアレンジのスイープを見る
  • 出来高の急増と素早い反転で確認する
  • 反転で入り、損切りはスイープされた水準の向こう側に置く
  • 目標：アジアレンジの反対側＋その延長

東部時間9時00分〜9時30分（プレマーケット）：

  • 夜間の値動きを見直す
  • ロンドンの動きが強く見えるか弱く見えるかを確認する

  • セッションのパターンは約束されたものではない： アジアレンジが広すぎてスイープできない日もあれば、ニュースがサイクル全体を上書きする日もあります。プレイブックが教えるのは何を探すかであって、何が起きるかではありません。
練習課題

🎯 セッションを追う練習

練習：5日間、セッションの流れを追う

  1. 毎晩、アジアセッションの高値と安値を引く（東部時間19時〜2時）
  2. 東部時間2時に、ロンドンのキルゾーンのスイープを見る（どちら側がスイープされたか）
  3. スイープのあとの反転方向を書き留める
  4. 9時30分に観察する：ニューヨークはロンドンを確認したか、反転させたか
  5. 一日の終わりに：セッションの型がどれだけ当たったかを記録する

目的： 5日たてば、セッション同士がどう噛み合うかがはっきり見えてきます。これがあなたの日々の道しるべになります。

⚡ 明日からできること（クリックで展開）

抱え込みすぎないこと。まずはこの3つから：

  1. 今夜、アジアセッションのレンジを引く ——東部時間19時から2時まで、ESまたはNQのチャートで高値と安値に水平線を引きます。これが明日のスイープ目標です。
  2. 東部時間2時にアラートを設定する ——起きて（あるいは起きたままで）ロンドンのキルゾーン（東部時間2時〜5時）を見ます。どちら側がスイープされましたか。アジアの高値ですか、安値ですか。スクリーンショットを残しましょう。
  3. 反転を待つ ——スイープそのものは取引しません。ロンドンが片側をスイープしたあと、反転の確認（order block＋Janusのシグナル）を待ちます。それがエントリーです。

アジア→ロンドン→ニューヨークの流れを5日追えば、型が見えてきます。アジアがレンジを作り、ロンドンがそれをスイープし、ニューヨークが確認する。これが機関投資家のプレイブックです。

理解度の確認

🎮 かんたん確認

Q：ロンドンのキルゾーンとは何で、なぜそう呼ばれるのですか。

A）ロンドンのトレーダーが昼食に出る時間帯のこと
B）東部時間2時〜5時の時間帯で、ロンドンがアジアレンジをスイープして個人の損切りを誘発し、その日の残りが向き合う方向を決める時間帯のこと
C）スキャルピングの戦略のこと
D）為替でしか機能しないもの
正解です。 ロンドンのキルゾーン（東部時間2時〜5時、ピークは3時〜4時）では、ロンドンの機関投資家が巨大な流動性とともに参入し、損切りを取るためにアジアセッションのレンジをスイープし、そのうえでその日の方向を決めます。「キルゾーン」とは、スイープのあいだに個人の損切りが薙ぎ払われることを指しています。

Q：なぜ毎日アジアセッションの高値と安値を引くべきなのですか。

A）アジアセッションが最も流動性の高い取引時間だから
B）アジアレンジがひと月ぶんの支持と抵抗を決めるから
C）ロンドンとニューヨークの機関投資家が流動性を取るためにその水準を狙うから——これから12〜24時間の道しるべになる
D）引くべきではない。アジアセッションは米国のトレーダーには関係がない
正解です。 アジアセッション（東部時間19時〜2時）は、流動性が低いなかで狭いレンジを作ります。そのため高値の上と安値の下に損切りが積み上がります——流動性プールです。ロンドンは東部時間2時〜3時に巨大な機関投資家の流れとともに開き、（たいてい）片側をスイープします。9時30分のニューヨークの寄り付きは、それを確認するか反転させることが多いのです。型はこうです：アジアが作る → ロンドンがスイープする → ニューヨークが確認する。アジアの高値と安値を毎日引きましょう。例：アジアレンジは4,550ドル〜4,560ドル（ES）。3時30分にロンドンが4,560ドルの高値をスイープし、損切りをつけて4,545ドルまで反転します。ニューヨークの寄り付きが4,535ドルまでの下落を確認します。その動きを取れたかどうかは別の話です。アジアレンジがあなたに与えたのは、見張る価値のある二つの水準と、そのどちらかが破られる瞬間に画面の前にいる理由でした。

Q：1日3時間しか取引できないなら、どの時間帯が最適ですか。

A）東部時間19時〜22時（ボラティリティが低いアジアセッションの序盤）
B）東部時間2時〜5時（ロンドンのキルゾーンだけ）
C）東部時間13時〜16時（気が楽な午後のセッション）
D）東部時間8時〜11時（流動性と優位性が最も高いロンドンとニューヨークの重複）
そのとおり！ 東部時間8時〜11時（ときに12時まで延ばす）が黄金の時間帯です。なぜか。(1) ロンドンがまだ動いている（東部時間11時30分に引ける）、(2) 9時30分のニューヨーク現物の寄り付きが米国の機関投資家の流れを連れてくる、(3) 重複＝流動性が最大＝スプレッドが最も狭く約定も最良、(4) 大きな動きの多くがここで起きる。1日3時間しか取引できないなら、東部時間8時〜11時は譲れません。2時〜5時のロンドンのキルゾーンは強力ですが、早起きが要ります。8時〜11時なら、通常の睡眠のままで同じ優位性が得られます。例：9時30分のニューヨークの寄り付きがロンドンのスイープ後の反転を確認 → 9時32分に入る → 10時45分に動きが完結。11時には取引を終えています。

問：ジェイソンの4か月は、325ドルの勝ち64回と500ドルの負け104回でした。6時〜8時の取引は勝ち17回と負け55回です。残りの時間帯はどうなったでしょう？

A) 収支ゼロ。デッドゾーンで損失のすべてが説明できる
B) 9,225ドルの損失。時間帯は問題の大部分だが、すべてではない
C) 21,975ドルの損失。被害が集中したのはそこ
D) 与えられた数字からは計算できない
正解です。 記録からデッドゾーンを引くと、勝ち47回と負け49回が残ります。47 x 325ドル - 49 x 500ドル = -9,225ドルです。6時〜8時の窓は取引の43%で31,200ドルのうち21,975ドルを担っていました。これがこのレッスンの要点です。残る9,225ドルは、セッションのタイミングでは届かない部分です。325ドル対500ドルなら損益分岐の勝率は61%で、残った時間帯は49%でした。取引をオーバーラップに移せば、最悪の取引は消えます。ほかの取引がいくら払うかは変わりません。
