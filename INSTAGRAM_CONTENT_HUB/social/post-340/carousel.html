Alert Types

TradingView supports several alert conditions. Understanding each type lets you build precise triggers for Signal Pilot indicators.

X
Crossing
Fires when a value crosses a specific level in either direction.
value crosses level
↑
Crossing Up
Fires only when a value crosses above a threshold from below.
value crosses up over level
↓
Crossing Down
Fires only when a value crosses below a threshold from above.
value crosses down under level
>
Greater Than
Fires continuously while a value remains above a given threshold.
value > threshold
↪
Entering Channel
Triggers when price enters a defined range between two levels.
entering channel [lo, hi]
↩
Exiting Channel
Triggers when price leaves a defined range in either direction.
exiting channel [lo, hi]

Setting Up Pentarch Alerts

P
Pentarch
Phase Alerts
Phase shift: Accumulation to Markup
Phase shift: Distribution to Markdown
Any phase change (universal trigger)
1
Open Alert Dialog
Right-click the Pentarch indicator on your chart and select "Add Alert on Pentarch..."
2
Select Condition
Choose "Phase" from the first dropdown, then "Crossing Up" and select target phase value.
3
Set Frequency
Use "Once Per Bar Close" for confirmed signals. Avoid "Once Per Bar" to reduce false fires.
4
Name Your Alert
e.g., "Pentarch Markup Entry — BTC 4H". Clear naming prevents confusion with multiple alerts.

Slide 7 — Pro Tips + Homework
07 / 08

Pro Tips + Mistakes

⚡
Use "Once Per Bar Close"
This ensures the condition is confirmed before the alert fires. Intra-bar alerts often produce false signals that disappear before the candle closes.
📚
Name Alerts Clearly
Include indicator name, condition, symbol, and timeframe. Example: "Pentarch Markup — ETH 4H". You will thank yourself when managing 20+ alerts.
⚠️
Do Not Stack Identical Alerts
Multiple alerts on the same condition and timeframe create noise. One alert per unique condition is sufficient.
🚫
Avoid "Every Time" on Noisy Indicators
For oscillators and volume metrics, "Every Time" can fire hundreds of alerts per day. Use threshold-based conditions instead.
📝 Homework
Set up a Pentarch phase-change alert on your primary chart
Add a Volume Oracle climax alert on the same timeframe
Configure a Janus Atlas support-level alert
Enable mobile push notifications in TradingView settings
