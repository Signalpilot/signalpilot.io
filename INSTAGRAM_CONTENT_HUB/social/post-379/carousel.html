→ Behind key level (support/resistance)

→ Logical invalidation point

→ Respects price action

→ May vary in size

→ Based on Average True Range

→ Adjusts to volatility

→ Wider in volatile markets

→ Tighter in quiet markets

→ Prevents dead trades

Clear level → Structure stop

No clear level → Fixed or ATR

Trade not working → Time stop
