BEST PRACTICES
Symbol Setup Guidelines
L
Limit Initial Symbols
Start with 5-10 symbols maximum. More signals does not mean better signals. Focus breeds clarity.
ESSENTIAL
G
Group by Correlation
Do not scan BTC and ETH together — they move in tandem. Diversify your grid for independent signals.
CORRELATION
T
Match Timeframe to Style
Scalpers use 5m/15m. Swing traders use 1H/4H. Do not mix trading styles in a single grid view.
TIMEFRAME
V
Verify Volume Requirements
Low-volume symbols generate noisy signals. Only add symbols with sufficient daily trading volume.
QUALITY
R
Review and Rotate Weekly
Markets shift. Review your symbol list weekly and rotate underperformers for fresh opportunities.

CONFIGURATION
Step-by-Step Setup
1
Open Grid Settings
Navigate to the Augury Grid panel and click the gear icon in the top-right corner to access configuration.
2
Add Symbol List
Enter symbols one per line or paste a comma-separated list. Start with your most-traded instruments.
3
Select Timeframes
Choose 1-4 timeframes that match your trading style. Each column represents one timeframe.
4
Set Alert Thresholds
Define minimum confidence scores for notifications. Higher thresholds mean fewer but stronger signals.
5
Save and Monitor
Save your configuration. The grid begins scanning immediately. Green cells indicate active signals above threshold.
PRO TIP
Create separate grid profiles for different sessions — a crypto grid for Asia hours, a forex grid for London, an equities grid for New York. Swap profiles in one click.
