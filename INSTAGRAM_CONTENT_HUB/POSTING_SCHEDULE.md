# SCHEDULING TOOLS

## Instagram Native
- Use **Professional Dashboard** → **Scheduled Content**
- Schedule up to 75 posts in advance

## Third-Party (Recommended)
- **Later.com** - Visual grid preview before posting
- **Planoly** - Drag-and-drop grid planning
- **Buffer** - Simple scheduling
- **Hootsuite** - Multi-platform

## Best Practice
1. Batch create content (make 9 posts = 1 full cycle)
2. Schedule the entire cycle at once
3. Check grid preview before confirming
4. Maintain consistent posting times

---

# THE RULE

> **Post in order. Never skip. Never double-post a type.**
>
> The 9-grid only works if you maintain the strict rotation:
> BLOG → EDU → QUOTE → CHRON → EDU → PROD → DOCS → EDU → MKTG → (repeat)

If you miss a day, pick up where you left off. Don't try to "catch up" by posting multiple at once — that breaks the grid visual.
