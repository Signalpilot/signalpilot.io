Parte 1: os order blocks, pontos de decisão institucionais
📖 Aprofundamento: como o smart money se move de facto (e como vê-lo) →

O que são order blocks?

Termo: order block é a última vela contrária antes de um movimento forte no sentido oposto.

Representa uma zona de preço onde as instituições colocaram ordens significativas (acumulação ou distribuição) que mais tarde provocaram o movimento explosivo.

Porque é que os order blocks importam

Quando o preço volta a um order block, as instituições defendem muitas vezes essa zona porque:

  • Têm ordens por executar à espera ali (querem acrescentar mais)
  • Têm posições em lucro abertas nessa zona (vão defendê-las para não devolver os ganhos)
  • Representa a sua tese original (se valia a pena acumular na altura, vale a pena defender agora)

É por isto que os order blocks funcionam como suporte e resistência de alta probabilidade, mas não são suporte e resistência. São pontos de decisão institucionais.

Identificar order blocks válidos

Nem toda a vela é um order block. São precisos três requisitos essenciais:

Requisito #1: movimento direcional forte a seguir

O order block tem de ser seguido por um movimento seco e impulsivo no sentido contrário. Esse movimento chama-se deslocamento, e o termo é usado no resto da lição: o deslocamento é o mercado a afastar-se da zona com força e rapidez, que é o que distingue um order block de qualquer outra vela que por acaso antecedeu uma subida.

Exemplo de order block de alta:

  • a última vela vermelha (de baixa) antes de o preço explodir para cima
  • O movimento explosivo deve ter pelo menos 3 a 5 velas de forte momentum de alta
  • Correções mínimas: as instituições estão a comprar de forma agressiva

Exemplo de order block de baixa:

  • a última vela verde (de alta) antes de o preço desabar
  • O movimento explosivo deve ter pelo menos 3 a 5 velas de forte momentum de baixa
  • Recuperações mínimas: as instituições estão a vender de forma agressiva

Porque é que isto importa: A força do movimento mostra o compromisso institucional. Movimentos fracos = retalho. Movimentos explosivos = posicionamento institucional.

Requisito #2: desequilíbrio / Fair Value Gap (FVG)

A maioria dos order blocks cria Fair Value Gaps (FVG): zonas de preço saltadas por causa de compras ou vendas agressivas.

Como detetá-lo:

  • olha para 3 velas consecutivas
  • Se o máximo da vela 1 estiver abaixo do mínimo da vela 3 (gap de alta), há um desequilíbrio
  • O «gap» é a zona que a vela 2 não preencheu: saltada na correria

Lógica institucional: quando o preço volta para preencher o FVG, está também a voltar ao order block. Confluência dupla.

🎓 Integração com o Janus Atlas

O Janus Atlas deteta FVG e order blocks automaticamente. Quando o preço volta a um FVG por preencher que coincide com um order block, o Janus assinala zonas de reequilíbrio de alta probabilidade.

Requisito #3: alinhamento com a estrutura de mercado

Os melhores order blocks acontecem em mudanças de estrutura de mercado (vamos ver isso a seguir).

Exemplo:

  • O preço fazia fundos e topos descendentes (tendência de baixa)
  • Depois rompeu o último topo descendente (mudança de estrutura)
  • O order block é a última vela de baixa antes desse rompimento

É aqui que a tendência de baixa passa a tendência de alta: foi desta zona que as instituições inverteram todo o sentido do mercado.

Parte 2: os breaker blocks, quando o smart money muda de ideias

Order blocks falhados = nova oportunidade

Eis o que o retalho não percebe: os order blocks podem falhar.

Quando um order block falha — o preço atravessa-o em vez de o respeitar — torna-se um breaker block. E os breaker blocks são ainda mais poderosos do que os order blocks.

Por quê? Porque as instituições acabaram de ser APANHADAS DO LADO ERRADO. Agora têm de sair. E isso cria movimentos explosivos no sentido oposto.

Anatomia de um breaker block

Passo a passo

Passo 1: forma-se um order block de alta (foi aqui que as instituições ficaram longas)

Passo 2: o preço volta ao order block (reação esperada)

Passo 3: em vez de ressaltar, o preço ATRAVESSA-O e fecha abaixo

Passo 4: o order block está agora «partido»: falhou

Passo 5: essa zona vira de suporte → resistência (agora é um breaker block)

O que aconteceu: as instituições estavam longas. O preço rompeu o order block delas. Agora estão presas. Vão colocar ordens de venda nessa zona para sair. O antigo suporte passa a resistência.

Analogia do mundo real:

imagina que compraste uma casa por 500.000 $ (o teu «order block»). O mercado colapsa e a tua casa vale agora 400.000 $. Se os preços chegarem a voltar aos 500.000 $, o que fazes? Vendes para ficar a zero. É exatamente o que as instituições fazem nos breaker blocks: estão desesperadas por sair sem perder nem ganhar.

Operar breaker blocks

Os breaker blocks costumam oferecer entradas de menor risco do que os order blocks, porque tens mais confluência:

Reação no order block

  • Instituições a defender posições
  • A reforçar operações vencedoras
  • Acumulação confiante

Mentalidade: «Tínhamos razão, vamos acrescentar mais»

Reação no breaker block

  • Instituições presas e do lado errado
  • Desesperadas por sair das posições
  • Pressão de liquidação forçada

Mentalidade: «Estávamos errados, tirem-me daqui sem perdas»

Parte 3: a estrutura de mercado, os únicos padrões que importam

BOS e ChoCH: ler a intenção institucional

Esquece o ombro-cabeça-ombro. Esquece os triângulos. Esquece todos os padrões gráficos que aprendeste.

As instituições só se preocupam com duas coisas:

  • BOS — Break of Structure (continuação)
  • ChoCH — Change of Character (reversão)

É isso. Tudo o resto é ruído.

Break of Structure (BOS): a tendência continua

BOS em tendência de alta: o preço rompe o máximo de swing mais recente

BOS em tendência de baixa: o preço rompe o mínimo de swing mais recente

O que significa: A tendência está saudável. As instituições continuam no controlo. Espera continuação.

🎯 Operar o BOS

Configuração: Depois do BOS, espera que o preço corrija até ao order block que causou o BOS

Exemplo (BOS de alta):

  1. o preço rompe o máximo de swing anterior (BOS confirmado)
  2. O preço corrige até ao order block de alta (a última vela vermelha antes do rompimento)
  3. Entra longo na correção com o stop abaixo do order block
  4. Alvo: o próximo máximo estrutural ou uma bolsa de liquidez acima

Change of Character (ChoCH): a tendência está a inverter

ChoCH em tendência de alta: o preço rompe o mínimo de swing mais recente (não conseguiu fazer um fundo mais alto)

ChoCH em tendência de baixa: o preço rompe o máximo de swing mais recente (não conseguiu fazer um topo mais baixo)

O que significa: A tendência está a desfazer-se. As instituições estão a mudar de sentido. Prepara-te para a reversão.

Sinais de aviso do ChoCH

Antes de o ChoCH acontecer, é frequente veres:

  • Momentum a enfraquecer (movimentos mais pequenos no sentido da tendência)
  • Divergência no Harmonic Oscillator (o preço a fazer máximos, o oscilador a fazer mínimos)
  • Volume a secar nos movimentos de tendência (instituições a sair)
  • Spreads a alargar (os market makers veem aí qualquer coisa)

Jogada de profissional: não esperes que o ChoCH se confirme por completo. Se vires estes avisos, aperta os stops ou realiza lucros parciais.

Combinar order blocks e estrutura de mercado

É aqui que tudo se junta:

Setup #1: BOS + reteste do order block (continuação de alta probabilidade)

Checklist completa do setup:

  • ✓ Preço em tendência de alta clara (topos e fundos ascendentes)
  • ✓ Ocorre um BOS (o preço rompe o máximo de swing mais recente)
  • ✓ Identifica o order block: a última vela de baixa antes do BOS
  • ✓ O preço corrige até à zona do order block
  • ✓ O Janus Atlas confirma um FVG no order block (confluência)
  • ✓ O Plutus Flow mostra absorção, não exaustão (instituições a comprar)

Entrada: Ordem limitada dentro da zona do order block

Stop: Abaixo do mínimo do order block

Objetivo: O próximo máximo estrutural ou o máximo de swing recente + 1,5-2R

Setup #2: ChoCH + breaker block (reversão de alta probabilidade)

Checklist completa do setup:

  • ✓ O preço estava em tendência de baixa (fundos e topos descendentes)
  • ✓ Ocorre um ChoCH (o preço rompe o máximo de swing mais recente: não conseguiu fazer um topo mais baixo)
  • ✓ O anterior order block de alta que foi partido é agora um breaker block
  • ✓ O preço sobe e depois corrige até ao breaker block (antigo suporte, agora resistência)
  • ✓ O Janus Atlas confirma uma varredura de liquidez acima do breaker block
  • ✓ O Harmonic Oscillator mostra divergência de baixa

Entrada: Venda curta com ordem limitada dentro da zona do breaker block

Stop: Acima do máximo do breaker block

Objetivo: O mínimo estrutural recente ou um FVG abaixo

Novo enquadramento:

Parte 4: erros comuns (e como evitá-los)

Porque é que as tuas operações com order blocks continuam a falhar

Erro #1: operar todos os order blocks

A evitar: «Vejo um order block, estou a entrar!»

Porque falha: Nem todos os order blocks são iguais. Os fracos são atravessados.

Melhor: Só opera order blocks alinhados com:

  • a estrutura do tempo gráfico superior (o diário confirma, order block em 4H)
  • BOS ou ChoCH (confirmação da estrutura de mercado)
  • a confluência do Janus Atlas (FVG ou varredura de liquidez)

Erro #2: ignorar o volume

A evitar: «O preço tocou no order block, vou longo!»

Porque falha: Sem confirmação de volume, estás a adivinhar.

Melhor: Usa o Plutus Flow para confirmar a absorção (volume comprador) no order block. Se vires exaustão em vez disso, deixa passar a operação.

Erro #3: stops apertados por baixo dos order blocks

A evitar: «Stop um tick abaixo do mínimo do order block!»

Porque falha: As instituições fazem muitas vezes um pavio por baixo dos order blocks para apanhar liquidez antes de inverterem.

Melhor: Usa stops de 1,5-2× ATR PARA ALÉM do order block, ou coloca os stops abaixo de uma estrutura de tempo gráfico inferior dentro da zona do order block.

Erro #4: confundir order blocks com suporte e resistência

A evitar: «Este nível aguentou duas vezes, portanto é um order block!»

Porque falha: Os order blocks exigem DISPLACEMENT. Sem displacement = sem order block.

Melhor: Procura velas agressivas e direcionais logo a seguir à vela do order block. Se não vires displacement, não é um order block: é apenas suporte ou resistência.

💡 Como ler aquela tabela

  • A frequência é um aviso, não uma qualidade. Uma linha de suporte de retalho aparece cinquenta vezes por mês porque a única coisa necessária para a traçar é o preço já lá ter estado. Um breaker block aparece duas a quatro vezes porque têm de acontecer três coisas distintas, e por ordem.
  • Cada linha mais abaixo na tabela retira uma maneira de estares errado. Um order block isolado pede-te que acredites que uma vela contou. Juntar-lhe uma quebra de estrutura pede ao mercado que o confirme. Juntar-lhe deslocamento pede que tenha contado o suficiente para mover o preço com força.
  • Os setups mais raros têm mais espaço para correr. Não porque o padrão seja mágico, mas porque um breaker block fica onde um grupo de pessoas está preso e quer sair, e esse grupo tem de acabar de sair antes de o preço acabar de se mexer.
  • Os fair value gaps são outra ferramenta. Enchem-se ou não, normalmente dentro da sessão. Trata-os como reversão à média intradiária, ou como mais uma confluência sobre um order block, não como razão para segurar algo durante dias.
  • Por onde começar. Order block mais quebra de estrutura é o mais frequente dos setups que obrigam o mercado a confirmá-los, o que faz dele o único em que vais ter repetições suficientes para aprender alguma coisa. Os breaker blocks valem a espera quando já souberes ver o resto.
💡

Pontos principais

  • Os order blocks são pontos de decisão institucionais, não suporte e resistência de retalho
  • Os breaker blocks são order blocks falhados que invertem a polaridade (mais poderosos do que os order blocks normais)
  • BOS = continuação, ChoCH = reversão (os únicos dois padrões de estrutura de mercado que importam)
  • Combina order blocks + estrutura de mercado + Janus Atlas para entradas baseadas em confluência
  • O displacement é obrigatório — sem movimento agressivo = não é um order block
Exercício prático

🎯 Prática de reconhecimento de padrões

Exercício: identifica order blocks e estrutura de mercado

Antes da tua próxima sessão de trading:

  1. Abre um gráfico num mercado ativo (ES, BTC ou uma ação líquida)
  2. Identifica o sentido da tendência atual (topos e fundos ascendentes ou topos e fundos descendentes)
  3. Marca no gráfico o BOS ou o ChoCH mais recente
  4. Encontra o order block que antecedeu essa mudança estrutural
  5. Espera que o preço corrija até esse order block e observa a reação
  6. Regista no diário: o preço respeitou-o? Houve confirmação de volume? Qual foi o resultado?

Objetivo: Depois de marcares 10 a 15 order blocks, vais ganhar intuição para saber quais têm qualidade e quais não têm. Aprende-se muito mais a observar do que na teoria.

⚡ Ganhos rápidos para amanhã (clica para abrir)

Não te sobrecarregues. Começa por estas três ações:

  1. Marca a última vela antes do displacement — antes de QUALQUER operação com order block, pergunta: «é esta a ÚLTIMA vela antes de um displacement agressivo?» Se não houver displacement, não é um order block.
  2. Identifica a estrutura de mercado atual — abre o gráfico. Marca os últimos 3 máximos e mínimos de swing. O preço está a fazer topos ascendentes? (continuação BOS) Ou fundos descendentes? (reversão ChoCH?)
  3. Espera pelo regresso ao order block — não operes o primeiro toque. Marca 3 order blocks com displacement. Espera que o preço volte. Regista no diário: aguentou? Porquê ou porque não?

Depois de marcares 10 order blocks com confirmação de displacement, vais ver o padrão: o retalho opera ressaltos no «suporte», as instituições defendem ordens por executar nas zonas de displacement.

P: o que faz de uma vela um order block?

A) O preço já ressaltou ali várias vezes
B) Está num nível de número redondo
C) Tem um pavio longo
D) É a última vela antes de um displacement direcional agressivo
Certo! Os order blocks identificam-se pelo displacement agressivo que vem a seguir. O order block é onde as instituições colocaram as suas ordens limitadas e o preço se afastou de forma agressiva. Sem displacement = sem order block.

P: qual é a diferença entre BOS e ChoCH?

A) BOS = continuação de tendência (rompe o máximo/mínimo de swing no sentido da tendência), ChoCH = reversão de tendência (rompe o máximo/mínimo de swing contra a tendência)
B) O BOS é para ações, o ChoCH é para forex
C) São a mesma coisa
D) O ChoCH só acontece no tempo gráfico diário
Exatamente! O BOS confirma que a tendência continua (em alta o preço rompe o máximo de swing, em baixa rompe o mínimo). O ChoCH assinala a reversão da tendência (em alta o preço rompe o mínimo de swing, em baixa rompe o máximo). São os dois únicos padrões estruturais com que as instituições se importam.

P: o que é um breaker block e porque é mais poderoso do que um order block normal?

A) É um order block num tempo gráfico superior
B) É um order block FALHADO que inverteu a polaridade (as instituições mudaram de ideias)
C) É um nível de suporte que aguentou 3 ou mais vezes
D) É um order block com volume extra
Certo! Um breaker block é um order block falhado: as instituições colocaram ordens, o preço voltou para o testar, mas ele FALHOU e foi atravessado. Isto assinala que as instituições mudaram de ideias ou ficaram presas. Agora esse antigo suporte passa a resistência (ou vice-versa). Porque é mais poderoso? Porque as instituições que ficaram presas estão agora motivadas a SAIR das posições perdedoras quando o preço volta, o que cria uma pressão forte no novo sentido. Exemplo: um order block de alta a 100 $ falha quando o preço rompe abaixo de 98 $. Nessa altura os 100 $ passam a resistência (breaker block), porque os compradores presos nos 100 $ querem sair sem perdas.
