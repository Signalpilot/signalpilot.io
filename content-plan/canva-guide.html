#EA580C
Blur: 30
Opacity: 40%

How to Create the Glow in Canva

  1. Select your border rectangle
  2. Click "Effects" in the top menu (or click the element and find Effects)
  3. Select "Shadow"
  4. Click the color picker and enter the glow color:
    • Teal: #0D9488
    • Orange: #EA580C
  5. Set Blur to 25-35
  6. Set Transparency to 40-60%
  7. Set Distance to 0 (this centers the glow)
