# THE GLOW BORDER EFFECT IN CANVA

## Method 1: Shadow Effect (Easiest)
1. Select your border rectangle
2. Click "Effects" in top menu
3. Select "Shadow"
4. Settings:
   - **Color**: Use the glow color (#0D9488 for teal, #EA580C for orange)
   - **Blur**: 25-35
   - **Transparency**: 40-60%
   - **Distance**: 0 (centered glow)
   - **Angle**: Any (doesn't matter at distance 0)

## Method 2: Duplicate Rectangle (More Control)
1. Create your main border rectangle
2. Duplicate it (Ctrl/Cmd + D)
3. Send duplicate to back
4. Make duplicate slightly larger (+10px each side)
5. Remove stroke, add fill with glow color
6. Lower opacity to 20-30%
7. Apply blur effect

## Method 3: Gradient Border
1. Create rectangle
2. Use border with gradient from glow color to transparent
3. Add subtle blur
