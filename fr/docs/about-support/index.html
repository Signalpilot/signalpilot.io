    Assistance et accès¶

    Cette page rassemble les moyens de nous joindre, de quoi dépanner et ce que vous pouvez régler vous-même si vous utilisez la suite Signal Pilot. Pour la plupart des soucis, ce qui suit vous tirera d'affaire plus vite qu'un courriel.

    Comment nous joindre¶

    • Site web : https://www.signalpilot.io
    • E-mail : support@signalpilot.io
    • Documentation : https://www.signalpilot.io/docs
    • GitHub Issues : Signaler un problème technique

    Obtenir l'accès¶

    Une fois la Signal Pilot Suite achetée :

    1. Donnez votre nom d'utilisateur TradingView : Envoyez votre nom d'utilisateur TradingView à l'identique à support@signalpilot.io
    2. Attendez l'invitation : L'activation prend en général moins de 24 heures, et bien moins aux heures de bureau
    3. Regardez votre liste d'indicateurs : Une fois invité, les indicateurs apparaissent dans TradingView sous « Invite-only scripts »
    4. Ajoutez-les au graphique : Cherchez « Signal Pilot » dans votre liste d'indicateurs et posez-les sur le graphique

    Note : L'accès est rattaché à votre nom d'utilisateur TradingView. Si vous en changez, prévenez l'assistance pour qu'elle mette l'accès à jour.

    Essayez d'abord ces quelques étapes. La plupart des soucis se règlent vite, sans attendre de réponse par courriel :

    À vérifier avant d'écrire¶

    • Consultez le page des questions fréquentes pour les questions qui reviennent souvent
    • Parcourez le Guide de dépannage si le problème est technique
    • Consultez la documentation de l'indicateur concerné pour les réglages
    • Cherchez dans cette documentation avec la barre en haut de page
    • Videz le cache du navigateur et rechargez TradingView
    • Essayez l'indicateur sur un autre symbole ou une autre unité de temps pour cerner le problème
    • Vérifiez que votre formule TradingView permet ce que vous tentez ; certaines fonctions demandent Premium ou Pro+

    Régler les problèmes courants¶

    Problèmes d'installation et d'accès¶

    Problème : les indicateurs Signal Pilot restent introuvables

    Causes possibles et solutions :

    • L'invitation n'est pas encore passée : Regardez si le courriel de confirmation est arrivé. Les invitations se traitent en général sous 24 heures.
    • Mauvais compte TradingView : Vérifiez que vous êtes connecté au compte TradingView que vous avez donné pour l'accès.
    • Vous cherchez au mauvais endroit : Ils se trouvent dans « Invite-only scripts », pas parmi les indicateurs publics. Cherchez « Signal Pilot » dans le menu des indicateurs.
    • Le nom d'utilisateur ne correspond pas : Vérifiez que vous avez bien donné le nom d'utilisateur TradingView, pas l'adresse courriel. Si besoin, écrivez à l'assistance.

    Problème : les indicateurs ne se chargent pas

    Causes possibles et solutions :

    • Limites de la formule TradingView : La formule gratuite plafonne à 3 indicateurs par graphique. Avec Premium, il y en a plus.
    • Le navigateur : Videz le cache, coupez les extensions, essayez la navigation privée.
    • Navigateur trop ancien : Mettez Chrome, Firefox, Safari ou Edge à jour.
    • Erreur dans le script : Ouvrez la console de TradingView (F12 → onglet Console) et transmettez le message à l'assistance.

    Problème : l'indicateur affiche « Script could not be loaded »

    Causes possibles et solutions :

    • Accès retiré ou expiré : Écrivez à l'assistance pour qu'elle vérifie l'état de votre abonnement.
    • Panne chez TradingView : Vérification TradingView Status pour voir si la plateforme est en panne.
    • Réseau ou pare-feu : Coupez le VPN, vérifiez le pare-feu, essayez une autre connexion.

    Problèmes au réglage des alertes¶

    Problème : les alertes ne se déclenchent pas

    Causes possibles et solutions :

    • Vous avez atteint la limite d'alertes : TradingView plafonne les alertes selon la formule. Dans Paramètres → Alertes, vous voyez celles qui tournent.
    • Mauvaise condition : Reprenez le réglage de l'alerte. Vérifiez que la bonne sortie de l'indicateur est choisie.
    • Alerte expirée : Les alertes expirent si vous fermez le graphique. Laissez-le ouvert ou réglez la fréquence sur « Once Per Bar Close ».
    • Mauvaise unité de temps : L'alerte a été créée sur une unité de temps et vous en regardez une autre. Alignez les deux.
    • L'indicateur a été retiré : Si vous retirez un indicateur, ses alertes cessent. Remettez-le et recréez-les.

    Problème : trop d'alertes

    Causes possibles et solutions :

    • Mauvaise fréquence : Passez la fréquence à « Once Per Bar Close » plutôt que « Once Per Bar ».
    • Réglages trop sensibles : Ajustez la sensibilité de l'indicateur (seuils, filtres, etc.).
    • Plusieurs alertes identiques : Regardez si des alertes font double emploi sur la même condition et supprimez le surplus.
    • Unité de temps trop basse : Montez d'unité de temps (H1 au lieu de M5) : moins de signaux, mais meilleurs.

    Problème : le webhook de l'alerte ne marche pas

    Causes possibles et solutions :

    • URL invalide : Vérifiez que l'URL du webhook est bonne et commence par https://.
    • Le service du webhook est hors service : Testez le point d'accès avec un outil comme Postman ou RequestBin.
    • Erreur dans le JSON : Vérifiez la syntaxe JSON du message avec un validateur.
    • TradingView Premium requis : Les webhooks demandent au moins TradingView Premium.
    • Requêtes bridées : Certains services de webhook brident les requêtes. Consultez leurs journaux.

    Voyez le guide des webhooks pour la configuration détaillée.

    Problèmes de rapidité et d'affichage¶

    Problème : l'indicateur met du temps ou le graphique se fige

    Causes possibles et solutions :

    • Trop d'indicateurs : Réduisez le nombre d'indicateurs actifs. Essayez OmniDeck, qui les réunit, plutôt que plusieurs séparés.
    • Trop d'historique : Raccourcissez la plage du graphique. Six mois ou moins, c'est le plus fluide.
    • Machine modeste : Fermez les autres onglets, prenez l'application de bureau TradingView, ou changez de machine.
    • Réglages gourmands : Certaines combinaisons coûtent cher en ressources. Commencez par les réglages par défaut.

    Problème : quelque chose ne s'affiche pas comme il faut

    Causes possibles et solutions :

    • Masqué par d'autres indicateurs : Changez l'ordre des couches ou coupez un instant ceux qui se superposent.
    • Réglages de couleur : Revoyez les couleurs de l'indicateur. Jouez sur la luminosité et l'opacité.
    • Conflit avec le thème du graphique : Passez du thème clair au thème sombre pour tester.
    • Affichage désactivé : Vérifiez dans les réglages que les éléments visibles sont bien activés (lignes, étiquettes, cadres, etc.).

    Problème : les signaux diffèrent des captures ou de la documentation

    Causes possibles et solutions :

    • Réglages différents : La documentation part des réglages par défaut. Comparez les vôtres.
    • Autre unité de temps ou autre symbole : Les signaux dépendent du marché. Reprenez les exemples de la documentation, symbole et unité de temps compris.
    • Soupçon de redessinage : Les indicateurs Signal Pilot ne redessinent pas. Ce qui semble bouger vient de données nouvelles. Voyez Politique de non-redessinage.
    • Mauvaise version : Vérifiez que vous êtes sur la dernière version (v1.0). Les anciennes peuvent se comporter autrement.

    Messages d'erreur fréquents¶

    Message d'erreur Signification Solution
    « Study Error » L'exécution du script a échoué Rechargez le graphique, vérifiez qu'il y a des données pour ce symbole, essayez-en un autre
    « Too many requests » La limite de requêtes est atteinte Attendez 60 secondes et réduisez le nombre d'indicateurs actifs
    « Cannot access this symbol » Pas de données L'indicateur ne gère peut-être pas ce type de données (futures crypto, etc.). Essayez un autre symbole
    « Script has too many calculations » Cela dépasse les limites de TradingView Raccourcissez l'historique du graphique et coupez les fonctions les plus lourdes
    « No data » Pas assez d'historique Le symbole est trop récent ou trop peu traité. Prenez des valeurs établies (BTC, ES, EURUSD)

    Pour d'autres messages d'erreur et leurs solutions, voyez le Guide de dépannage.

    Écrire à l'assistance¶

    Si rien de ce qui précède ne règle votre souci, écrivez à l'assistance en joignant ceci ; ce sera plus rapide :

    Comment l'assistance priorise¶

    Priorité haute (objectif : répondre sous 24 heures) :

    • Pas d'accès aux indicateurs alors que l'achat est confirmé
    • Des indicateurs qui font planter TradingView ou le ralentissent fortement
    • Problèmes de facturation ou de paiement
    • Inquiétudes de sécurité

    Priorité normale (2 à 3 jours ouvrés) :

    • Aide aux réglages et questions de type « comment faire »
    • Aide pour monter des alertes
    • Demandes et suggestions
    • Précisions sur la documentation
    • Signalements de bogues possibles, non critiques

    Note : Ces délais sont des objectifs, pas des engagements. Le temps réel dépend de l'affluence et de la complexité du cas.

    Comment signaler un problème¶

    En écrivant, joignez :

    1. Votre nom d'utilisateur TradingView : Cela permet de vérifier l'accès et l'abonnement
    2. Nom et version de l'indicateur : par exemple « Pentarch v1.0 » ou « OmniDeck v1.0 »
    3. Symbole et unité de temps : par exemple « BTCUSDT en 15 minutes »
    4. Description du problème : Clairement et en détail : ce qui se passe et ce que vous attendiez
    5. Comment le reproduire : Quelles actions y mènent ?
    6. Captures : Les images aident énormément (par courriel, passez par imgur.com ou équivalent)
    7. Réglages employés : Une capture du panneau de réglages si vous avez modifié quelque chose
    8. Navigateur et machine : par exemple « Chrome 120 sous Windows 11 » ou « Safari sur un MacBook Pro »
    9. Formule TradingView : Free, Essential, Plus, Premium ou Premium+

    Avertissements importants¶

    À visée pédagogique uniquement : La Signal Pilot Suite n'existe qu'à des fins pédagogiques. Les signaux, indicateurs et outils servent à apprendre l'analyse technique. Ce n'est pas un conseil financier.

    Aucune garantie : Les performances passées ne garantissent rien pour l'avenir. Les indicateurs techniques peuvent signaler des occasions, ils ne prédisent pas le marché. Chacun répond de ses propres décisions.

    Avertissement sur le risque : Trader comporte un risque de perte important. N'engagez que de l'argent que vous pouvez perdre. Pesez votre situation et votre tolérance au risque avant d'employer ces outils en réel.

    Plateforme tierce : Les indicateurs Signal Pilot fonctionnent sur TradingView, une plateforme tierce. Ce qui relève de la plateforme TradingView se règle avec l'assistance de TradingView.

    Ce que l'assistance ne couvre pas : L'assistance traite les problèmes techniques, l'installation et les questions sur la documentation. Elle ne donne pas de conseil de trading, ne développe pas de stratégie et ne fait pas de recommandation personnalisée.
