    🎛️ Master Toggle

    A single switch at the top of the Main settings group to instantly hide/show all chart overlays.

    StateBehavior
    OFFHides all overlays (EC counts, SuperTrend, EMAs, zones, sweeps, patterns, regime background). Confluence Panel stays visible.
    ONRespects individual toggles — enable/disable each system independently.

    Tip: Confluence Panel has its own toggle in the Confluence settings group — run minimal setup with just the score panel and no chart clutter.

    📊 Confluence Score Panel

    Display Modes:

    • Badge: Compact score (e.g., "7/10") — clean charts
    • Table: Detailed breakdown — shows each system's contribution

    Score Interpretation:

    • 8-10: Elite confluence — multiple systems strongly aligned
    • 5-7: Moderate confluence — consider context
    • 1-4: Low confluence — systems in disagreement

    Weighted Systems:

    • Regime Box: 2.0 | Exhaustion Counter: 1.5 | Squeeze: 1.5
    • SuperTrend, BMSB, EMA Trio, S/D Zones, Patterns: 1.0 each

    📊 System Layers

    Layer Systems Purpose
    Layer 1: Trend EMA Trio, SuperTrend, BMSB Direction analysis
    Layer 2: Patterns Exhaustion Counter, Squeeze, Candlesticks Signal detection
    Layer 3: Zones Regime Box, Supply/Demand, Liquidity Sweeps Key areas
    Layer 4: Integration Meta Tools Coordination

    ⚡ Quick Interpretation Guide

    Getting Started (First 2 Weeks)

    • Enable ONLY 3 systems: EMA Trio + Regime Box + Exhaustion Counter
    • Watch for alignment: All 3 agree = high-confidence setup
    • Disable the rest: Add more systems gradually as learning progresses

    Reading the 4 Layers

    • Layer 1 (Trend): Which direction? Use EMA Trio/SuperTrend/BMSB
    • Layer 2 (Patterns): Signal present? Look for EC/Squeeze/Candlesticks
    • Layer 3 (Zones): At key level? Check Regime/Supply-Demand/Liquidity
    • Layer 4 (Meta): All systems aligned? Meta Tools show confluence

    System Combination Examples

    • Trend + Pattern: SuperTrend green + Exhaustion Counter 9 = Continuation setup
    • Pattern + Zone: Squeeze breakout + Supply Zone = High-probability entry
    • All 3 Layers: EMA crossover + Count 9 + Regime shift = Maximum confluence

    🤝 Best System Combinations (Within OmniDeck)

    Beginner Stack (3-4 Systems)

    • EMA Trio + Regime Box + Exhaustion Counter: Trend + mood + exhaustion
    • SuperTrend + Squeeze + Supply/Demand: Trend + breakout + zones
    • Exhaustion Counter + Candlestick + BMSB: Exhaustion + patterns + support

    Intermediate Stack (5-6 Systems)

    • Trend Set: EMA Trio + SuperTrend + BMSB
    • Signal Set: Exhaustion Counter + Squeeze + Candlesticks
    • Zone Set: Regime Box + Supply/Demand + Liquidity Sweeps

    Advanced Stack (7+ Systems)

    • All 10 enabled: Use Meta Tools to filter confluence
    • Focus on layer alignment: Trend + Pattern + Zone all agree
    • Toggle on/off as needed: Disable visual clutter, keep key systems

    With Other Signal Pilot Indicators

    • OmniDeck + Pentarch: OmniDeck trend + Pentarch cycle phase
    • OmniDeck + Janus Atlas: OmniDeck signals + Janus price levels
    • OmniDeck + Volume Oracle: OmniDeck patterns + Volume confirmation

    ⚙️ Recommended Settings

    Default Settings (v1.3.1)

    ON by default: Exhaustion Counter, Squeeze Detector, SuperTrend, Regime Box, Confluence Score
    OFF by default: Liquidity Sweeps, EMA Trio, BMSB, Supply/Demand Zones, Candlestick Patterns, Dynamic RCS Lookback, Show Alert Prefix, Auto Adjust Confluence

    Beginner Configuration ⭐

    • Enable: EMA Trio, Regime Box, Exhaustion Counter, Supply/Demand (4 systems)
    • Disable: All others
    • Why: Clean chart, easy to understand, covers trend/mood/exhaustion/zones
    • Best for: First 2-4 weeks, learning curve gentle

    Day Trader Configuration

    • Enable: SuperTrend, Squeeze, Exhaustion Counter, Liquidity Sweeps (4 systems)
    • Disable: Long-term systems (BMSB, weekly-focused)
    • Why: Fast signals, breakout detection, exhaustion, stop hunts
    • Best for: 5m-1H charts, intraday trading

    Swing Trader Configuration

    • Enable: EMA Trio, BMSB, Regime Box, Supply/Demand, Exhaustion Counter (5 systems)
    • Disable: Fast signals (Squeeze, Liquidity Sweeps)
    • Why: Trend confirmation, zone analysis, cycle exhaustion
    • Best for: 4H-Daily charts, multi-day holds

    Advanced Configuration (All 10 Systems)

    • Enable: All 10 systems
    • Adjust opacity: Lower visual clutter with transparency settings
    • Use Meta Tools: Let Meta layer filter for confluence
    • Best for: Experienced users, larger screens, complex analysis

    ⚠️ When NOT to Use

    ❌ As first indicator ever (too complex for absolute beginners)
    ❌ Enabling all 10 systems at once (information overload)
    ❌ On slow devices with all systems enabled (performance issues)
    ❌ Without understanding individual systems first (learn components before combining)

    🔧 Troubleshooting

    "Chart looks too cluttered"
    → Disable half the systems - start with 3-5 systems max
    → Use opacity settings to reduce visual weight
    → Focus on one layer at a time (Trend OR Pattern OR Zone)

    "Systems giving conflicting signals"
    → Normal - not all systems agree at once
    → Wait for 2-3 systems to align before acting
    → Meta Tools layer helps filter for confluence

    "Indicator running slowly"
    → Disable unused systems (only enable what's needed)
    → Reduce bars loaded in TradingView settings
    → Use higher timeframes (Daily faster than 1m)

    "Not sure which systems to use"
    → Start with beginner stack (EMA + Regime + EC + Supply/Demand)
    → Add one system per week as learning progresses
    → Match systems to trading style (see Settings section)

    🎯 OmniDeck Success Tips

    1. Start with 3-5 systems max — Add more gradually, avoid overload
    2. Wait for layer alignment — Trend + Pattern + Zone all agree = best setups
    3. Disable visual noise — Only enable systems actively using
    4. Learn individual systems first — Understand components before combining
    5. Use system stacks — Beginner/Day Trader/Swing Trader configurations (see Settings)

    📖 Key Concepts

    10 Systems: Exhaustion Counter, Squeeze, Liquidity Sweeps, EMA Trio, SuperTrend, BMSB, Regime Box, Supply/Demand, Candlesticks, Meta Tools
    4 Layers: Trend Analysis (Layer 1), Pattern Detection (Layer 2), Zone Analysis (Layer 3), Integration (Layer 4)
    Confluence: When multiple systems align and agree (strongest signals)
    Meta Tools: Behind-the-scenes system that coordinates all 10 systems and prevents conflicts
