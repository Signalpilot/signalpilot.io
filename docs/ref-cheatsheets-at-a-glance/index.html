    🎯 When to Use Each Indicator

    Use Pentarch When...

    • ✅ You want to identify market cycle phase
    • ✅ Looking for early-cycle (TD, IGN) or late-cycle (WRN, CAP, BDN) signals
    • ✅ Day trading or swing trading volatile assets
    • ❌ Avoid: Scalping <15m, low volatility periods

    Use Janus Atlas When...

    • ✅ You need specific price levels for entries/exits
    • ✅ Setting stop losses and take profits
    • ✅ Any trading style, any timeframe
    • ❌ Avoid: Parabolic moves, newly listed assets

    Use OmniDeck When...

    • ✅ You want comprehensive 10-system analysis
    • ✅ You're an advanced trader with 100+ hours to invest
    • ✅ You understand Exhaustion Counter, VWAP, oscillators
    • ❌ Avoid: Beginners, visual complexity intolerance
    • 💡 Tip: Use Master Toggle to hide all overlays instantly — keep just Confluence Panel for minimal setup

    Use Augury Grid When...

    • ✅ You trade multiple assets and need daily screening
    • ✅ Morning market scan to find best setups
    • ✅ Crypto altcoin trading, sector rotation analysis
    • ❌ Avoid: Single-asset focus, position users

    Use Volume Oracle When...

    • ✅ You need volume confirmation for patterns/levels
    • ✅ Identifying breakout vs fake-out
    • ✅ Tracking open position P&L
    • ❌ Avoid: Spot forex (use futures), very long timeframes

    Use Harmonic Oscillator When...

    • ✅ You want real-time momentum confirmation
    • ✅ Need to know if market is overbought/oversold
    • ✅ Filtering setups with momentum agreement
    • ❌ Avoid: Very long timeframes (too noisy)

    Use Plutus Flow When...

    • ✅ You want to spot price-volume divergences
    • ✅ Identifying accumulation/distribution
    • ✅ Swing trading reversal setups
    • ❌ Avoid: Scalping, spot forex (use futures)

    🔗 Best Indicator Combinations

    The Trinity ⭐⭐⭐⭐⭐ (Most Popular)

    Pentarch + Janus Atlas + Volume Oracle

    • Cycle phase + Price levels + Volume confirmation
    • Highest probability when all 3 align
    • Best for: Day trading, swing trading

    The Foundation ⭐⭐⭐⭐ (Beginner-Friendly)

    Janus Atlas + Volume Oracle

    • Price levels + Volume confirmation
    • Simple, visual, intuitive
    • Best for: Beginners, level users

    The Momentum Stack ⭐⭐⭐⭐

    Pentarch + Harmonic Oscillator

    • Cycle phase + Momentum confirmation
    • Early-cycle with momentum = strong setup
    • Best for: Day trading, capturing moves with momentum

    The Divergence Hunter ⭐⭐⭐⭐

    Plutus Flow + Pentarch + Janus Atlas

    • Divergence + Cycle shift + Entry level
    • Excellent for spotting reversals
    • Best for: Swing trading tops/bottoms

    The Scanner ⭐⭐⭐⭐

    Augury Grid + Any Indicator

    • Screen 20-50 assets, detailed analysis on filtered
    • Morning routine: Grid scan → Trinity on best 3
    • Best for: Multi-asset users

    📋 Signal Quick Reference

    Pentarch (5 signals)

    • 🟣 TD - Accumulation (early bullish)
    • 🩵 IGN - Markup (bullish momentum)
    • 🟡 WRN - Distribution (late-cycle caution)
    • 🟠 CAP - Climax (exhaustion)
    • 🔴 BDN - Decline (bearish shift)

    Harmonic Oscillator (4 signals)

    • 🟢 BUY - 3+ oscillators bullish
    • 🔴 SELL - 3+ oscillators bearish
    • 🔵 STRONG - 5+ oscillators agree (extreme)
    • ⚪ NEUT - Neutral (no consensus)

    Janus Atlas (60+ level types)

    • Core 5: dH, dL, wH, wL, dVWAP
    • All 60+: Daily, Weekly, Monthly, Quarterly, Yearly, Session, VWAP, Volume Profile, Naked POC, Market Structure, Opening Range, Killzones, Gap Levels, Fibonacci Levels

    Volume Oracle (5 systems)

    • System 1: Regime Detection (background colors: green/red/gray/gold)
    • System 2: Signal Generation (BULL/BEAR with ⭐ quality ratings)
    • System 3: Risk Management (auto Entry/Stop/T1/T2)
    • System 4: HTF Confirmation (higher timeframe alignment)
    • System 5: Strategy Modes (Trend Following/Mean Reversion/Hybrid)

    Key Features:

    • Regime Meter: Shows 6 things at once (State, Strength, Health, Confirm, Flow, Duration)
    • Health Status: Early warnings (STRONG/FADING/WEAKENING/CRITICAL)
    • Confirmation Counter: Bars building toward change (↑4 = 4 bars)
    • Volume Bar Coloring: Brighter = stronger signal
    • 17 Alerts: Entry, Position, Regime, Health, HTF

    Plutus Flow (divergences)

    • Bullish Divergence: Price ↓, OBV ↑ (accumulation)
    • Bearish Divergence: Price ↑, OBV ↓ (distribution)

    🎓 Learning Order Recommendations

    Path 1: Beginner (Start Here)

    1. Janus Atlas (2 weeks) - Learn levels
    2. Volume Oracle (1 week) - Add volume
    3. Pentarch (4-6 weeks) - Master cycles

    Total: 7-9 weeks

    Path 2: Intermediate

    1. Janus Atlas (2 weeks)
    2. Volume Oracle (1 week)
    3. Harmonic Oscillator (2 weeks)
    4. Pentarch (4 weeks)

    Total: 9 weeks

    Path 3: Advanced (OmniDeck Only)

    1. OmniDeck Systems 1-4 (4 weeks)
    2. OmniDeck Systems 5-8 (4 weeks)
    3. Integration (2 weeks)
    4. Augury Grid (2 weeks)

    Total: 12 weeks

    ⚠️ Common Mistakes to Avoid

    ❌ Using too many indicators at once
    ✅ Start with 1-2, add gradually
    ❌ Skipping the learning curve
    ✅ Observe 20-30 signals before trading
    ❌ Trading every signal
    ✅ Wait for high-confluence setups (multiple confirmations)
    ❌ Ignoring timeframe suitability
    ✅ Pentarch needs 15m minimum, Janus works on all
    ❌ No paper trading
    ✅ Practice 2-4 weeks before risking capital

    Recommended Combos:

    • Chart: Pentarch + Janus + Volume Oracle
    • Or: OmniDeck alone (all-in-one)
    • Grid: Augury Grid with 20-30 assets

    🎨 Pentarch Signal Visual Guide

    BULLISH (Bottom Signals):          BEARISH (Top Signals):
🟣 TD  - Below candle               🟡 WRN - Above candle
🩵 IGN - Below candle               🟠 CAP - Above candle
                                   🔴 BDN - Above candle

Pilot Line Colors:
🔵 Blue  = Bearish regime
🟢 Green = Bullish regime
⚪ Gray  = Neutral

    📊 Volume Oracle Visual Guide

    Regime Detection (Background Colors):
🟢 Green = Accumulation regime (bullish)
🔴 Red   = Distribution regime (bearish)
⚪ Gray  = Neutral regime (no direction)
🟡 Gold  = Weakening regime (trend fading)

Regime Meter Table (6 rows):
State    | Accumulation, Distribution, Neutral
Strength | 78% (regime strength)
Health   | ✓ STRONG, ⚠️ FADING, 🔴 CRITICAL
Confirm  | ↑4 (bars confirming)
Flow     | Bullish, Bearish, Mixed
Duration | 23 bars

Health Status (Leading Indicators):
✓ STRONG     = Regime healthy
⚠️ FADING    = Early warning
🟠 WEAKENING = Tighten stops
🔴 CRITICAL  = Exit warning

Volume Bar Coloring:
Bright Green = Accumulation >70%
Soft Green   = Accumulation 50-70%
Bright Red   = Distribution >70%
Soft Red     = Distribution 50-70%
Gold/Amber   = Weakening regime
Gray         = Neutral <50%

Signal Quality Ratings:
⭐⭐⭐ = High quality (80-100%)
⭐⭐   = Medium quality (60-79%)
⭐     = Lower quality (40-59%)

Risk Management Lines:
💙 Blue line   = Entry price
🔴 Red line    = Stop loss
🟢 Green line  = Target 1 (T1)
💚 Bright green = Target 2 (T2)

    🎯 Harmonic Oscillator Visual Guide

    Signals (based on 7-oscillator voting):
🟢 BUY    = 3-4 oscillators bullish
🔴 SELL   = 3-4 oscillators bearish
🔵 STRONG = 5+ oscillators agree (very strong)
⚪ NEUT   = <3 votes (no consensus, choppy)

    📈 Janus Atlas Visual Guide

    Level Line Colors (customizable):
Daily levels:     Usually yellow/orange
Weekly levels:    Usually blue/purple
Monthly levels:   Usually red/pink
VWAP:             Usually green
POC/VAH/VAL:      Usually gray/white

Labels show level type (dH, WL, POC, etc.)

    🔄 Plutus Flow Visual Guide

    OBV Line:
🟢 Rising OBV  = Accumulation
🔴 Falling OBV = Distribution

Divergences:
📈 Price up + 📉 OBV down = Bearish divergence (distribution)
📉 Price down + 📈 OBV up = Bullish divergence (accumulation)

Trend Ribbons:
🟢 Green ribbons = Bullish OBV trend
🔴 Red ribbons   = Bearish OBV trend

    🚦 High-Probability Setup Checklist

    The Trinity Setup (Pentarch + Janus + Volume)

    • [ ] Pentarch signal appeared
    • [ ] Janus level cluster within 1-2% of signal
    • [ ] Volume Oracle spike >1.5x average
    • [ ] All 3 aligned? → High-probability setup

    Momentum Confirmation (Add Harmonic)

    • [ ] Trinity setup complete
    • [ ] Harmonic Oscillator agrees with Pentarch direction
    • [ ] 4-factor confluence → Highest probability

    Divergence Setup (Plutus + Pentarch + Janus)

    • [ ] Plutus Flow showing divergence
    • [ ] Pentarch cycle shift signal (BDN→TD or CAP→BDN)
    • [ ] Janus level at divergence zone
    • [ ] Reversal setup identified

    📝 Daily Workflow Example

    Morning (Market Open):

    1. Open Augury Grid → Scan 30 assets for setups
    2. Identify top 3 with Pentarch signals + Janus levels
    3. Switch to detailed chart on best setup

    Intraday (Monitoring):

    1. Watch for Volume Oracle confirmation
    2. Check Harmonic Oscillator for momentum
    3. Enter if all factors align (Trinity + Harmonic)

    Exit Planning:

    1. Set alerts at next Janus resistance level
    2. Watch for Pentarch late-cycle signals (WRN, CAP)
    3. Exit at confluence of level + late-cycle signal
