    🎯 Consejos para buscar

    Para dar con lo que buscas:

    ✅ Busca por:

    • Nombres de señal: «TD», «IGN», «WRN», «CAP», «BDN»
    • Nombres de indicador: «Pentarch», «Janus», «Volume Oracle»
    • Conceptos: «level cluster», «volume spike», «cycle phase»
    • Términos: «accumulation», «distribution», «exhaustion»

    📚 Navega en vez de buscar:

    • Las chuletas (usa los enlaces directos de arriba)
    • Fichas de consulta rápida
    • Comparaciones visuales

    🔗 Usa el glosario:

    • Glosario completo de términos - definiciones buscables de más de 50 términos de trading

    📞 ¿Sigues sin encontrarlo?

    Soporte por correo: support@signalpilot.io

    Cuéntanos:

    • Qué estás buscando
    • Dónde esperabas encontrarlo
