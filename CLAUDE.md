# Signal Pilot

## Curriculum work: read the guidebook first

Any work on the Learn curriculum — writing a lesson, editing one, translating
one, touching the index or the tier pages — starts by reading
**`scripts/curriculum/GUIDEBOOK.md`** end to end. It is the single source for
what a lesson has to be, how each of its seven parts is written, the checklist
that runs before a lesson is committed, the locale conventions, the build
commands and their traps, and where the work currently stands.

Do not work from memory of it. Read it. It is one file and it is kept current.

The two things it says that are easiest to skip and most expensive to get
wrong:

- **Recompute, do not read.** Rebuild every figure in Python from the stated
  inputs before trusting it.
- **Translate per lesson, immediately after the rebuild, by hand.** Never
  batch translation across lessons.

## The corpus

- Lessons: `education/curriculum/<tier>/<slot>-<slug>.html`, tiers `beginner`,
  `intermediate`, `advanced`, `professional`.
- Locales: eleven, built to `<lang>/education/...` by `scripts/i18n/build.py`.
  Never edit a built locale page directly.
- Catalogue: `education/curriculum/index.json`.
- The index at `education/index.html` is generated by
  `scripts/curriculum/hubs.py` and must never be typed by hand.
- Ledger: `scripts/curriculum/academy-ledger.tsv`, one row per lesson pass.

## Standing constraints

- Develop on `claude/soro-website-feedback-bemz3i` and push to both that
  branch and `main`.
- Keys and secrets go in Vercel environment variables, never into chat.
- Update `sitemap.xml` when a lesson changes; do not discuss resubmitting it.
