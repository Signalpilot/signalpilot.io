ポジションサイジング101：ゲームに残り続ける数学

7分で読めるSignal Pilot チーム
共有:

素晴らしいセットアップを見つけました。高確率、明確な無効化ポイント、完璧なエントリー。自信があるのでサイズを大きくします。

負けました。口座が15%の打撃を受けます。今、ブレイクイーブンに戻るだけで17.6%の利益が必要です。

これがほとんどのトレーダーが破綻する理由です。悪いトレードではなく、悪いサイジングのせいです。

なぜポジションサイズがエントリーより重要か

受け入れがたい真実：70%の勝率があっても口座を飛ばす可能性があります。逆に、40%の勝率でも一貫して利益を上げられます。

違いはポジションサイズです。

勝ちトレードが平均$100、負けトレードが平均$300なら、70%の勝率は：(0.7 x $100) - (0.3 x $300) = $70 - $90 = 1トレードあたり-$20。

ほとんどのトレードで勝ちながらお金を失っています。

ポジションサイジングは方程式の残り半分をコントロールします - どれだけ頻繁に勝つかだけでなく、勝ったり負けたりした時にいくら勝ち負けするかも。

固定パーセンテージ法

実際に機能する最もシンプルなアプローチ：各トレードで口座の固定パーセンテージをリスクにさらす。

ほとんどのプロトレーダーは1-2%を使用。1%を使いましょう。

計算式：

ポジションサイズ =（口座リスク）/（1株あたりのリスク）

例：

  • 口座：$50,000
  • トレードあたりのリスク：1% = $500
  • エントリー価格：$100
  • ストップロス：$95
  • 1株あたりのリスク：$5
  • ポジションサイズ：$500 / $5 = 100株

ストップアウトされた場合、$500を失います - 口座のちょうど1%。5%でも10%でもない。1%です。

なぜ1-2%？

これは恣意的ではありません。生存のための数学です。

1トレードあたり1%リスクなら、10回連続で負けても資本の90%が残ります。悪い連敗ですが、まだゲームに残っています。

1トレードあたり5%リスクなら、10回の損失で資本のわずか60%になります。回復には67%の利益が必要です。

1トレードあたり10%リスクなら、10回の損失で資本の35%になります。回復には186%の利益が必要です。

数学は急速に残酷になります。小さなリスクは生存へと複利します。大きなリスクは破滅へと複利します。

ケリー基準（そしてなぜフルケリーを使うべきではないか）

ケリー基準は、あなたのエッジに基づく最適な賭けサイズの公式です：

ケリー% = (勝率 x 平均利益 - 負け率 x 平均損失) / 平均利益

理論上、これは長期的な成長を最大化します。実際には、トレーダーにとって危険です：

  • 正確な勝率を知っていると仮定している（知らない）
  • 各トレードが独立していると仮定している（そうではない）
  • フルケリーは大規模なドローダウンを生む

ケリーを使うなら、「ハーフケリー」か「クォーターケリー」を使ってください - 公式の結果を2-4で割ります。これは理論的な成長の一部を犠牲にして、劇的に滑らかなエクイティカーブを得ます。

アンチマーチンゲール原則

マーチンゲールは損失後に倍賭けします。カジノがギャンブラーからお金を抜き取る方法です。

賢いトレーディングは逆：アンチマーチンゲール。勝っている時に多くリスク、負けている時に少なくリスク。

固定パーセンテージサイジングでは、これが自動的に起こります。$50,000の1%をリスクにさらすと$500です。勝って$55,000に成長した後、1%は$550になります。負けて$45,000に減った後、1%はわずか$450です。

エッジが機能している時は自然にスケールアップし、機能していない時はスケールダウンします。感情的な決定は必要ありません。

サイズを調整する時

固定パーセンテージはほとんどの状況に対応しますが、以下の場合は縮小を検討：

  • 相関： 同じセクターや相関のある資産での複数ポジション。テックが暴落し、5つのテック株を持っている場合、5つの別々のポジションではなく1つの大きなポジションを持っています。
  • ボラティリティスパイク： VIXが高いか株が大きくギャップする場合、ストップが指定価格で約定しない可能性があります。スリッページリスクを考慮してサイズを縮小してください。
  • 不確実性： 決算、FRB会議、選挙。結果が不明な既知のイベント。スキップするか、大幅にサイズを縮小してください。
  • ドローダウン： ドローダウン中にリスクを減らすトレーダーもいます（例：10%のドローダウン後に半分のサイズ）。これは出血を止めるのに役立ちますが、回復速度も遅くする可能性があります。

要点

ポジションサイジングは、悪いトレードが教訓になるか災害になるかの違いです。

ルールはシンプルです：

  • 1トレードあたり最大1-2%のリスク
  • ストップからサイズを計算、逆ではない
  • 数学にエクスポージャーを自動スケールさせる
  • 相関のあるポジションや不確実な環境ではサイズを縮小

間違いから回復することはできる。破産から回復することはできない。それに応じてサイズを決めよう。

品質スコアリングシステムはサイジングの決定をさらに知らせることができる。強いコンフルエンスを持つセットアップ—サイクルフェーズの整列、ボリューム確認、複数のインジケーターの一致—はフルポジションサイズを正当化するかもしれない。相反するシグナルを持つマージナルなセットアップはハーフサイズまたはパスを正当化するかもしれない。データドリブンのサイジングは方程式から感情を取り除く。
