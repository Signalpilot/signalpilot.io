# Quick Start Checklist

*Signal Pilot Education — a setup tracker, and the first lessons to read beside it.*

> **Educational only.** Trading involves substantial risk of loss. Not financial
> advice. Past performance does not guarantee future results.

---

## Phase 1: Account and access

- [ ] TradingView account created (Pro+ recommended)
- [ ] Signal Pilot subscription active
- [ ] Invite-only indicator access confirmed
- [ ] Discord community joined

## Phase 2: Indicator installation

**Core.** Add Pentarch first and nothing else until you can read it.

- [ ] Pentarch added, appears in Invite-Only Scripts
- [ ] Signals drawing on the chart
- [ ] Pilot Line visible
- [ ] Bar colouring active

**Secondary.** Add these one at a time, and only after Pentarch reads clearly.

- [ ] Janus Atlas added; liquidity pools visible; sweep signals appear
- [ ] Plutus Flow added in a lower panel; OBV line visible; delta histogram showing
- [ ] Volume Oracle added; volume bars coloured; profile zones visible
- [ ] Harmonic Oscillator added; voting system active; vote count displayed
- [ ] Augury Grid added (optional); symbols configured; grid displaying

## Phase 3: Chart configuration

- [ ] Timeframe set — 1H is a reasonable place to start
- [ ] Asset selected, and liquid: lesson 12 ranks instruments by what a round
      trip costs as a share of what they move, and the answer runs from 0.2 per
      cent of a day's range to 52
- [ ] Candlestick chart, clean layout
- [ ] Pentarch on the main chart, Plutus Flow in the lower panel
- [ ] Panel heights adjusted, colours legible
- [ ] Layout saved and named in TradingView

## Phase 4: Settings verification

Pentarch has few user-adjustable settings by design.

| Setting | Options | Yours |
|---|---|---|
| Alert toggles | On or off per signal | |
| Colour palette | Five presets | |
| Label size | Small, medium, large | |

Confirm each of the five cycle events appears somewhere in the visible history:

- [ ] TD  - [ ] IGN  - [ ] WRN  - [ ] CAP  - [ ] BDN

## Phase 5: Can you read it

- [ ] Bull regime and bear regime, by bar colour
- [ ] The Pilot Line's direction and colour
- [ ] NanoFlow crosses
- [ ] All five event signals by colour

Check yourself: what colour is a TD signal, which regime does it fire in, what
follows it in a reversal, what does an orange Pilot Line mean, and what are
NanoFlow crosses for?

## Phase 6: Practice

**Week 1, observation only.**

- [ ] Watched twenty or more signals without trading
- [ ] Noted what happened after each
- [ ] Found five that failed and five that worked

**Week 2, on paper.**

- [ ] Paper account set up
- [ ] Ten or more signals traded on paper
- [ ] Results recorded at the time, not afterwards — lesson 23 names the ten
      fields, two of which cannot be recovered later at any price
- [ ] Your own win rate and average win and loss computed from that record

**Week 3, small and live.**

- [ ] Position size defined before the first order — lesson 20 gives it as
      account times the fraction you risk, divided by the distance to the stop
- [ ] Five or more small trades taken
- [ ] A stop on every one
- [ ] Each reviewed afterwards

## Phase 7: The first lessons

The curriculum is 85 lessons in four tiers. These five are Module 1, and every
figure in them is reproducible from the numbers printed on the page.

- [ ] Lesson 1: What a Market Solves
- [ ] Lesson 2: The Order Book
- [ ] Lesson 3: What a Fill Actually Is
- [ ] Lesson 4: The Spread Is the Price of Immediacy
- [ ] Lesson 5: Why Anyone Quotes At All

Each module ends in a quiz that hands you numbers and asks for a number back.
They are linked from every tier page and from the education index.

**Resources worth having open**

- [ ] Pentarch Cheatsheet
- [ ] Market Cycle Cheatsheet
- [ ] Position Sizing Calculator Template
- [ ] Trade Journal Template

## Phase 8: Community

- [ ] Discord joined and verified
- [ ] Introduced yourself
- [ ] Pinned messages read
- [ ] First question asked

## Phase 9: Ongoing

**Weekly.** Review the week's trades, complete the journal entries, read one
lesson, check in on Discord.

**Monthly.** Recompute your win rate and payoff ratio from your own record.
Identify the best and worst setups. Note what you changed and why.

Lesson 19 is the one to read before drawing a conclusion from any of it: fifty
trades cannot tell a method making 0.35R a trade apart from one with no edge at
all.
